# The Lua kernel table: for each binding of Flick's own kernel (each
# `flick:` specifier of flick-backend-support/src/kernel/manifest.txt, and
# the JS globals of `[global]` a built-in module binds), what the Lua target
# does with it, and whether calling it suspends the fiber.
#
# `[specifier] status` gives every export of a specifier its row; a line
# `export status` below it gives one export a row of its own. Every kernel
# primitive of the manifest has a line of its own, and so does every
# export that suspends. A test keeps the table equal to the manifest.
#
#   refused      the Lua target refuses it with P012 wherever it is reached
#   suspends     (after `refused`) a call suspends the fiber until it resumes
#   implemented  the Lua kernel (`kernel/*.lua`) implements it as `K.<export>`,
#                which generated code calls with every argument at once
