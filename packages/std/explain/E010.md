A `server fn` (the plugin `server` of the module `Server`) runs on the
server and is called over the network, so its signature, right above it,
says what crosses it: the parameters, each named, then the services and the
errors listed on the last arrow, `A -> B ->{r; e} S`, and nothing generic.
Only the last arrow runs; the errors are a closed row, as each crosses the
network with its codec. `server name` names the implementation of a
`server fn`: a name, maybe qualified, and nothing else.

What the checker finds in the code the plugin writes is on the `server fn`
too: a payload, a success or an error without a Schema witness is
`FLICK-D001`, and `server name` of a value that is no `server fn` is
`FLICK-E010`.

```flick
module App.Api exposing (greet)

import Server

type error Unknown = Unknown String
  deriving Schema

greet : String ->{Server.Server; Unknown} String
server fn greet name = if name == "" then from_result (Err (Unknown name)) else "Hello, " ++ name
```
