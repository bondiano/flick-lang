A `suite` block names its case and holds `test` and `suite` blocks; a
`test` block names its case and holds its body, the lines of an effectful
test or one expression. Either may be `.skip` or `.only`, and either starts
a top-level declaration.

```flick
suite "Users" {
  test "trims the name" {
    Test.check (Test.equal "Ada" (String.trim "  Ada  "))
  }

  suite.skip "storage" {
    test "keeps a user" {}
  }
}
```
