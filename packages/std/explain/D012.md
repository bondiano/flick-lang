The codec a field of a `codec` block (the plugin `codec` of the module
`Codec`) gives decodes another type than the field of the record has: the
block would build a record with a field of the wrong type.

```flick
profile_json : PureCodec Json Profile
let profile_json =
  codec Profile.schema {
    email = field "email" String.json;
    age = field "age" Float.json_finite;
  }
```
