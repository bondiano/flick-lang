A case has a full name, its suites' names and its own, `Users > trims the
name`, which `flick test --filter` and the reports name it by. Two suites or
tests of one suite, or two blocks of one module, with the same name would
have one full name: give each a name of its own.

```flick
suite "Users" {
  test "trims the name" {}
  test "trims the email" {}
}
```
