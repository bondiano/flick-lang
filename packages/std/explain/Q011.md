Without a codec a column holds the Flick type of its SQL type: `bigint` is
`BigInt`, `numeric` is `BigDecimal`, `integer` is `Int`, `double precision`
is `Float`, `text` is `String`. An enum of that type's literals needs no
codec; another type needs a `via` codec from that type.

```flick
import Sql

type UserId = UserId BigInt

user_id : PureCodec BigInt UserId
let user_id = Sql.codec (fun n -> Ok (UserId n)) (fun (UserId n) -> n)

sql table Users "users" {
  id : bigint primary key generated always as UserId via user_id
}
```
