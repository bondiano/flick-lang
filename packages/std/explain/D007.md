A `codec` block (the plugin `codec` of the module `Codec`) describes the wire form of a record, field by field, so
its schema must be the schema of a record type. A variant type uses
`Codec.json` or `Codec.transform`.

```flick
import Codec

type alias Point = { x : Float; y : Float }
  deriving Schema

point_json : PureCodec Json Point
let point_json =
  codec Point.schema {
    x = field "x" Float.json_finite
    y = field "y" Float.json_finite
  }
```
