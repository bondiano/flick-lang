A `codec` block (the plugin `codec` of the module `Codec`) gives every field of the record its schema describes, once:
a missing field is an error, as decoding could not build the record.

```flick
import Codec exposing (plugin codec)

profile_json : PureCodec Json Profile
let profile_json =
  codec Profile.schema {
    email = field "email" String.json
    nickname = optional_field "nickname" String.json
  }
```
