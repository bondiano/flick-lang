A `codec` block (the plugin `codec` of the module `Codec`) gives only fields of the record its schema describes; a
wire key of its own goes in the wire name of a field: `field "email_address"`.

```flick
import Codec exposing (plugin codec)

profile_json : PureCodec Json Profile
let profile_json =
  codec Profile.schema {
    email = field "email_address" String.json
  }
```
