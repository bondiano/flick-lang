A record that derives `HttpApi` (see the module `HttpApi.Derive`) is a
group of endpoints, and std's plugin cannot read one of them: each field is
`Get`, `Post`, `Put`, `Patch` or `Delete` with a path, the request as a
record of its parts (`path`, `query`, `headers`, `payload`) or `{}`, the
success and the errors as a row, optionally inside `Authed` or
`MaybeAuthed`; when one endpoint of a group is guarded, every one is. What
the checker finds in the code the plugin writes is on the endpoint too: a
part without a codec is `FLICK-D011`, an error without a `Problem` instance
or a path whose `:name` parameters are not the fields of the `path` part is
`FLICK-C001`.

```flick
import HttpApi.Derive exposing (..)

type alias Profiles = {
  profile : Get "/profiles/:username" { path : ProfilePath } ProfileBody {NotFound};
} deriving HttpApi
```
