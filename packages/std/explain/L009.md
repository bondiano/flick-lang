A `cli` block names its command and holds clauses, each starting with its
word: `description text`, `flag name "alias" : T = default`,
`arg name : T = default`, `subcommand command` or `handle f`, one per line or
separated by `;`.

```flick
let greet =
  cli "greet" {
    description "Prints a greeting"
    flag loud : Bool
    arg name : String
    handle fun { loud; name } -> Platform.stdout_line name
  }
```
