A column of a table names a SQL type of the dialect, then its attributes:
`not null`, `null`, `primary key`, `unique`, `default`, `generated always`
or `generated by default`, then `as` and its Flick type. A column with an
unknown word is left out of the table.

```flick
import Sql exposing (plugin sql)

sql table Users "users" {
  id : bigint primary key generated always as BigInt
  email : text unique as String
}
```

A migration holds `create table`, `create index`, `alter table`, `drop
table` and `drop index`; another statement, or a column type outside the
dialect, is outside the DDL the plugin reads.

```flick
import Sql exposing (plugin sql)

sql migration 1 "people" {
  create table people (id bigint primary key generated always as identity, name text not null);
  create index people_by_name on people (name);
}
```

The construct is not part of the checked SQL subset: an expression SQL
cannot compute, or a clause in the wrong place. Raw SQL is available
through `Sql.unsafe_query` with an explicit decoder.

```flick
from user in Users
where user.name == $name
select { id = user.id }
```
