A fixture is made when code first `await`s it, from the fixtures in sight
of its expression, so its expression may use only the fixtures declared
before it: one that uses itself, or a later one, would wait for itself. A
shared fixture is made once for its suite, so it may use only shared
fixtures, not one that each test makes anew; nor may a `before_all` or an
`after_all` hook, which runs for no test. Declare what a fixture uses
before it, or share it:

```flick
suite "Users" {
  fixture shared names = SynchronizedRef.make ["Ada"]
  fixture count = List.length (SynchronizedRef.get (await names))
  test "counts the names" { Test.check (Test.equal 1 (await count)) }
}
```
