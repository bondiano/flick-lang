A table gives each column once: a second column of the same name would
hide the first from queries. The table is declared without it.

```flick
import Sql exposing (plugin sql)

sql table Users "users" {
  id : bigint primary key generated always as BigInt
  name : text not null as String
}
```

A column a query names does not exist in its table, or a `values` or
`set` record gives a field the table has no column for.

```flick
from user in Users
select { name = user.name }
```
