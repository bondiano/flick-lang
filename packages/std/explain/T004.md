The tests of a `parallel` suite run at once, so a fixture they share is
used by several at a time. Say that it is safe to share so, as a pool or
read-only data is, with `fixture shared concurrent`; or drop `parallel`,
and the suite runs its tests one at a time, as a suite with a shared
fixture does by default:

```flick
suite parallel "Search" {
  fixture shared concurrent words = ["ada", "grace"]
  test "finds a word" { Test.expect (Test.equal true (List.contains "ada" (await words))) }
}
```
