Every field, long name and short name of a command is used once, and
`--help`, `-h`, `--version` and `--completions` belong to the CLI. A field
`dry_run` is the flag `--dry-run`; an alias of one character is `-n`, a
longer one `--name`.

```flick
import Cli exposing (plugin cli)

let tool =
  cli "tool" {
    flag verbose "v" : Bool
    flag version_tag "t" : String
    handle fun { verbose; version_tag } -> Platform.stdout_line version_tag
  }
```
