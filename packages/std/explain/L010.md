`deriving Cli.Value` parses a value of a choice among constructors without
fields, by their names in kebab case (`GreenLight` is `green-light`), or of
a refined type, whose base it parses and whose predicate it checks. Any
other type has no such value to parse.

```flick
type Shape = Circle Float | Square Float
  deriving Cli.Value
```

```flick
instance Cli.Value Shape =
  let parse text = …
```
