# do, each with what stops it: `<case> # <reason>`. `just model` holds the list
# to what the model does: a case that begins to run moves to model.txt, a new
# case is run or is written here, and a reason that changes is written again.
# Unsupported callables remain cold until their actual host invocation;
# reasons name the first unsupported boundary, not mere callable lookup.
