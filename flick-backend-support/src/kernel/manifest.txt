# The primitive kernel: what every backend implements itself, and the class
# of every binding a `foreign` of `packages/*/src` names. The reference is
# docs/src/content/docs/reference/kernel.md.
#
# `version` is the kernel's version. A build request names it as the runtime
# ABI `flick.kernel`, and a backend declares the versions it implements.
#
# `[specifier] class` gives every export of a specifier its class, `global`
# being the JS globals of `from global`; a line `export class` below it
# gives one export another. A kernel export always has its own line.
#
#   kernel   a primitive every backend implements
#   flick    expressible in Flick over the kernel
#   host     a capability of the host, which host packages provide
#   adapter  a binding to the values of one host library, kept by its adapter
