`scope { … }` releases what it acquired when its body ends, so a region is
live only inside its scope. A function or a `task` that uses a resource of
the scope cannot be returned from it or stored in a cell created outside it:
using it there needs the region live. A value whose type names the region
cannot leave the scope at all, nor can an error carry one. A value that only
holds a handle and never uses it may leave. Finish the work inside the scope,
or move the scope into the deferred work so each run acquires its own
resource.

```flick
# import File exposing (File, Path, OpenError, ReadError, FileSystem)
// was: scope { let file = File.open_scoped path
//              task { File.read_all file } }
deferred_read : Path -> Eff {FileSystem, Async} {OpenError, ReadError} String
let deferred_read path =
  task {
    scope {
      let file = File.open_scoped path
      File.read_all file
    }
  }
```
