Every named function has its full signature right above its `let` (§3): at the
top level and locally, in instances and for a function obtained by partial
application. The signature states every argument type, the result and the
effect of each arrow; the body is checked against it.

```flick
greet : String -> String -> String
let greet prefix name =
  prefix ++ ", " ++ name

hello : String -> String
let hello = greet "Hello"
```
