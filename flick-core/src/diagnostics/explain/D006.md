`T.parse` of a constant is checked when the program compiles if the compiler
knows the check: a `Checks` function or a `fun` over the constant built from
literals. A constant that fails it cannot become a `T`.

```flick
refined type Port = Number where fun n -> n > 0 && n < 65536

default_port : Result SchemaError Port
let default_port = Port.parse 8080
```
