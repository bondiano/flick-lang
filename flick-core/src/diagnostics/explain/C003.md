Two instance heads describe a common constraint: after aliases are expanded,
their heads unify. Instances are canonical: there is no priority between a
general and a specific one, and the context does not choose. Keep one, or
give the special case a nominal wrapper.

```flick
instance Show a => Show (List a) =
  show : List a -> String
  let show items = "[…]"

type Numbers = Numbers (List Float)

instance Show Numbers =
  show : Numbers -> String
  let show numbers = "numbers"
```
