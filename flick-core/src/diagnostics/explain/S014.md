A component declares its props, then at most one `setup` section, run once
per mounted instance, and then one `render` section, run on every render.
`render` must come after `setup`, and a component without `render` shows
nothing:

```flick
component counter (props : { start : Number }) =
  setup
    let count = Atom.local props.start
  render
    ui { text (show (Atom.get count)) }
```
