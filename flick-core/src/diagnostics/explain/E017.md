A task that `spawn`, `parallel` or `race_first` runs is in a fiber of its
own. The handler of an effect with a `control` operation is in the fiber
that installed it, and so is the rest of the computation `resume` holds: a
child cannot reach it. Handle such an effect inside the task, or collect
the children's results with `join` or a `Channel`.

```flick
effect Emit a =
  control emit : a ->{} Unit

collect : forall a r e. (Unit ->{Emit a | r; e} Unit) ->{r; e} List a
let collect body =
  try
    body ()
  with
  | Emit.emit x -> [x] ++ resume ()
  | return () -> []

both : Unit ->{} (List Int, List Int)
let both () =
  // was: collect (fun () -> parallel (task { Emit.emit 1 }) (task { Emit.emit 2 }))
  parallel (task { collect (fun () -> Emit.emit 1) }) (task { collect (fun () -> Emit.emit 2) })
```
