A package's `.iface` records the fingerprint of every interface its module
was compiled against. When the installed interface of such a dependency has
a different fingerprint, a type, a constructor id, a dictionary or a summary
the compiled code relies on may have changed, so the package cannot be used
with it.

Install the versions the package was built with, or a release of the package
built against the installed dependency:

```sh
flick install
```
