A `server fn` declaration uses the server-only `Rpc`, `HttpApi` and
`Server` standard libraries. This compiler was built without the
`server-stdlib` Cargo feature.

Use a compiler built with `server-stdlib`, or replace the declaration
with an ordinary function that does not need the disabled modules. The
default WASM build includes this feature; a `--no-default-features` WASM
build does not.
