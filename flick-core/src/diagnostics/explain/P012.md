`flick build` compiles every construct the checker accepts except the
blocks whose elaboration comes with later parts of the compiler: `sql`,
`ui`, `cli`, `codec` and `schema`. They are checked, and `flick check`
accepts them, but no code is generated for them yet.

Until then, keep such a block out of the modules you build, or call the
library functions it would elaborate to directly:

```flick
names : Unit ->{Db; DbError} List String
let names () =
  Db.query_names ()
```

The go target (`emit = "go"`) compiles a smaller part of the language for
now: pure code, functions, data, classes and direct calls to the platform.
What `main` reaches beyond that, such as a `task`, a service, `try` or a
`foreign` binding without a Go implementation, is reported here with the
construct it names; the JS target builds the same program.
