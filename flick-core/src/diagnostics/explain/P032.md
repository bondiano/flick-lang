A dependency in `[dependencies]` does not name exactly one source, or
`[package]` has a version or a `flick` requirement that is not semver.
A dependency comes from a directory, a tag of a git repository, or a
tarball with its checksum:

```toml
[package]
name = "ids"
version = "0.2.0"
flick = ">=0.1, <0.2"

[dependencies]
geo = { path = "../geo" }
std = { git = "https://github.com/bondiano/flick-lang", tag = "std-v0.1.0", subdir = "packages/std" }
text = { url = "https://example.com/text-1.0.0.tgz", sha256 = "<64 hexadecimal digits>" }
```
