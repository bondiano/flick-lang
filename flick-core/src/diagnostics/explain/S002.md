Not reported by `flick check`, which uses the full parser. Only the bootstrap
code generator behind the e2e harness reports it: that generator compiles an
entry module whose `main` is a sequence of `Platform.stdout_line`,
`Platform.stderr_line` and `App.fail` calls with string literals, and nothing
else.

```flick
module App.Main exposing (main)

main : Unit ->{; AppError} Unit
let main () =
  Platform.stdout_line "hello"
```
