A build writes its output directory and `flick clean` removes it, so the
output directory may not be the project's root, the directory of its
sources or tests, or a directory above one of them: the build would replace
`package.json` with its own and `clean` would delete the project's files.
Nothing is written when the build is refused.

```toml
[build]
out-dir = "dist"
# was: out-dir = ".", the project's root
```
