The project's manifest does not let a plugin handle this block or class:

```toml
[plugins.std]
disable = ["sql", "Cli.Value"]
```

`disable` names the heads of blocks, as `sql`, and the classes a plugin derives,
as `Cli.Value`, under the package that provides the plugin. The plugins of the
packages that come with the compiler count too: `std` provides `sql`, `cli`,
`codec` and `server`. A block of a disabled head has no code, and a disabled class
derives nothing.

Remove the name from `disable`, or write the code the block or class stood for.
