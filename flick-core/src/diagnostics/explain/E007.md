`try … with` handles expected errors (§7 "Ожидаемые ошибки"): every arm
matches a type declared with `error`, or a variable or `_` that matches any
error of the body. Other values are matched with `match` on the result.

```flick
safe : UserId ->{Users; none} Option User
let safe id =
  try
    Some (Users.get id)
  with
  | NotFound _ -> None
```
