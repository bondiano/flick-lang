The construct comes from other ML languages and Flick does not have it: generic
`do` notation, `let*` binding operators, `of` before constructor fields and
JSX `<…>`. Effectful calls are written directly, deferred work uses
`task { … }` and `await`, constructor fields follow the name as in a pattern
(`Rect Number Number`), UI uses `ui { … }`.

```flick
load_pair : UserId ->{Users; NotFound} (User, User)
let load_pair id =
  let first = Users.get id
  let second = await (task { Users.get id })
  (first, second)
```
