A record that derives `HttpApi` (see the module `HttpApi.Derive`) is a
group of endpoints, and one of them cannot be served as written: each field
is `Get`, `Post`, `Put`, `Patch` or `Delete` with a path, the request as a
record of its parts (`path`, `query`, `headers`, `payload`) or `{}`, the
success and the errors, optionally inside `Authed` or `MaybeAuthed`. Every
`:name` of the path is a field of the `path` part; every part and success
has a codec, the value named after its type in its module or the JSON codec
of its schema; every error has a `Problem` instance; the guarded endpoints
of a group read the same `headers`.

```flick
import HttpApi.Derive exposing (..)

type alias Profiles = {
  profile : Get "/profiles/:username" { path : ProfilePath } ProfileBody {NotFound};
} deriving HttpApi
```
