A `tail` arm is the value of its operation and runs on the stack of the
caller, which may be Sync: nothing it calls may suspend. Calling an effect
with a `control` operation, `Async` or a row variable there is an error,
unless the row of the operation declares it or a handler inside the arm
catches it. Otherwise declare what the arm needs, or make the operation
`control`.

```flick
effect Clock =
  // was: now : Unit ->{} Float
  now : Unit ->{Async} Float

fetch_time : Unit ->{Async} Float
foreign fetch_time from "./time.mjs" "fetchTime"
  arity 0

timed : forall a. (Unit ->{Clock, Async; none} a) ->{Async; none} a
let timed body =
  try body () with
  | Clock.now () -> fetch_time ()
```
