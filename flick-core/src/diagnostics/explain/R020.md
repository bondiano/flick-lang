A `let mut` variable that no statement assigns never changes, so it needs
no `mut`: a reader of the code would look for the assignment. The safe fix
removes `mut` when there is no inline annotation. An annotated function value
may need its type moved to a preceding signature first.

```flick
module App.Area exposing (area)

area : Float -> Float -> Float
let area width height =
  let size = width * height
  size
```
