The runner of an application starts `main` with `()` and either calls it as
a plain function or runs it as an effect. So `main` is `Unit -> Unit`, or a
runtime function such as `Unit ->{Host.Console; AppError} Unit`: it may need
the `Host` services its entry provides (with a runner, the services its
`Main` names), every other service it uses is provided inside it, and the
only failure it lets out is `AppError`, which the runner reports.

```flick ignore
module App.Main exposing (main)

main : Unit ->{; AppError} Unit
let main () = provide Users.live { App.run () }
```
