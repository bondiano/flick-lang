A block of one of the plugins that come with the compiler, such as
`cli "name" { … }`, is a block only in a file that imports the plugin's
head. The file names the module that exposes it:

```flick
module App.Main exposing (tool)

import Cli exposing (plugin cli)

tool : Cli.Command none none
let tool = cli "tool" {
  handle fun {} -> Platform.stdout_line "hi"
}
```

`flick check --fix` adds the import.
