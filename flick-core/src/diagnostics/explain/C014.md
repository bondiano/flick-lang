`@implicit` marks a one-step conversion instance. Its class must have exactly
two parameters and one pure method `a -> b`, with no additional constraints.
The instance must have no context or type variables, and its two ground types
must differ.

```flick
class Convert a b =
  convert : a -> b

type Meters = Meters Float
type Feet = Feet Float

@implicit
instance Convert Meters Feet =
  let convert (Meters n) = Feet n
```
