The construct is not part of the checked SQL subset: an expression SQL
cannot compute, or a clause in the wrong place. Raw SQL is available
through `Sql.unsafe_query` with an explicit decoder. A column of a
`sql table` is the plugin of std's to check: see `flick explain std/Q010`.
