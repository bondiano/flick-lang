The payload of an error is data that outlives the code that raised it: it may
not hold a cell (`Ref`), a computation (`Eff`), a layer, a runtime function or
an `Unknown` that could hide one. Pass a path, an id or a copy of the data
instead of the live value.

// was: type error ReadFailed = ReadFailed (Ref String)
