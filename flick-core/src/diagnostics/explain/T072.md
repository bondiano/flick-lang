A value of a type marked `@cell` holds one value: a state a pure call
makes, such as an atom. A binding built purely is generalized, so a cell
made with no type in sight would have a type with variables: one cell that
one reader takes for a list of numbers and another for a list of strings,
each reading what the other wrote. A value that is no function therefore
has a type without variables inside a cell's type: annotate it with the
type of what it holds. In a block, a cell without a type is not
generalized, and a signature, annotation or higher-rank argument that gives
it variables is rejected the same way. A function that makes a cell per
call may stay polymorphic.

```flick
@cell
type Slot a

empty : Unit -> Slot a
foreign pure empty from "./slot.js" "empty"

numbers : Slot Float
let numbers = empty ()
```

The plugin of a library words this refusal for its own cells: for an atom
it is `FLICK-U005`.
