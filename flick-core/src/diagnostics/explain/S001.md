A Flick source file must be valid UTF-8. The diagnostic points at the first
byte sequence that is not valid UTF-8; the file is not checked further.

Re-save the file as UTF-8 (without changing its text encoding by hand):

```sh
iconv -f WINDOWS-1251 -t UTF-8 src/App/Main.fl > Main.fl && mv Main.fl src/App/Main.fl
```
