`emit = "go"` builds the program with the Go toolchain: `flick build` writes
a Go module per entry under `go/<entry>/` in the output directory and runs
`go build` on it. Either `go` is not on `PATH`, or `go build` failed on the
generated code.

Install Go (1.23 or later) and make sure `go version` works in the shell that
runs `flick`. A failure of `go build` itself is a bug of the compiler: the
message keeps the end of its output to report.

```sh
go version
flick build --emit go
```
