A `server fn` runs on the server and is called over the network, so its
signature, right above it, must say what crosses it: one parameter, the
services and the errors listed, `P ->{r; e} S`, and nothing generic. The
payload `P`, the success `S` and each error in `e` travel as JSON, so each
needs a Schema witness (`deriving Schema`). `server name` serves the
implementation of a `server fn`; any other name has none.

```flick
module App.Api exposing (greet)

type error Unknown = Unknown String
  deriving Schema

greet : String ->{Server; Unknown} String
server fn greet name = if name == "" then from_result (Err (Unknown name)) else "Hello, " ++ name
```
