`flick schema export` writes only a strict JSON Schema 2020-12: no `{}` or
`any`. A codec whose node has no such form (an effectful transformation, a
check the exporters do not know, a redacted value without a policy) is
refused with the path of that node.

```flick
user_json : PureCodec Json User
let user_json = Codec.json User.schema
```
