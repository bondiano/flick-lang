A backend or a plugin asked the compiler to run a host tool that the
project does not allow. Host tools run only with the project's consent:
`[tools]` in `flick.toml` names, for each backend id or plugin package,
the tools its build steps and commands may run.

```toml
[tools]
"flick/go" = ["go"]
```

The compiler finds each allowed tool on `PATH` and pins its digest and
version for the build. A tool the backend only launches the program with,
as `node` for `flick run`, needs no entry.
