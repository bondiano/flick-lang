An entry with `target = "client"` in `flick.toml` runs in a browser, so
nothing its `main` reaches may need `Server`: not a function whose row has
`Server`, nor a value that provides it with `Server.node`. The message shows
the path from `main` to what needs it. Call that code from a server entry
and reach it from the client over HTTP or RPC.

```flick
// flick.toml: entries = { web = { module = "App.Web", target = "client" } }
module App.Web exposing (main)

main : Unit ->{; AppError} Unit
let main () = ()
```
