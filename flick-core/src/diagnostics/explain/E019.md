A handler finds a service by its name, not by its arguments. `provide` of a
layer of `Store Int` answers every `Store` operation of its body, so a row
variable of the body that may hold `Store` at other arguments, `Store String`
say, would get the `Store Int` of the layer for it. Take the service out of
the variable, `{-Store | s}`, so a caller cannot pass a task that needs it,
or name the instance the body needs, `{Store Int | s}`.

```flick fail
service Store a =
  get : Unit ->{} a

answered : Layer none none {Store Int} -> Eff s none a ->{s} a
let answered layer t = provide layer { await t }
```

```flick
service Store a =
  get : Unit ->{} a

apart : Layer none none {Store Int} -> Eff {-Store | s} none a ->{s} a
let apart layer t = provide layer { await t }

named : Layer none none {Store Int} -> Eff {Store Int | s} none a ->{s} a
let named layer t = provide layer { await t }
```
