An expression has a type other than the one its position requires. Flick has
no implicit conversions (§9): `1 + 1n` mixes `Number` and `BigInt`, `"a" ++ 1`
mixes `String` and `Number`. Records are exact: a record with extra fields does
not pass for a smaller closed record type (no width subtyping); accept the
extra fields with an open row `{ name : String | fields }` or project them away.

```flick
label : Number -> String
let label n = "count: " ++ Number.to_string n
```
