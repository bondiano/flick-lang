An inline module belongs only to its source file. Its `exposing` list lets the
enclosing module use selected members; it does not create an importable file
module. Use `Child.member` in the enclosing file. To import the child from
another file, move it to its own `A/Child.fl` file and give that file a module
header. Move or pass any private parent declarations it needs; a direct
parent–child import cycle is still rejected.
