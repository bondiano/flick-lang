Выбранный бэкенд обнаружил синтаксическую ошибку во встроенном коде хоста,
записанном через `from inline` или преамбулу `foreign module inline`.
Компилятор считает встроенный текст хоста непрозрачным и передаёт его с
диапазоном в исходнике бэкенду, который проверяет код и отображает ошибку на
нужную строку файла `.fl`.

Исправьте синтаксис языка хоста внутри строкового литерала или поместите
привязку в модуль с `@when` для того бэкенда, который понимает этот язык хоста.

```flick
cos : Float -> Float
foreign pure cos from inline "(d) => Math.cos(d)"
```
