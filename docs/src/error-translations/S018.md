В выражении `_` допускается только как прямой аргумент применения функции
(`f a _ c`, что означает `fun h -> f a h c`). Он не может стоять сам по себе,
на месте вызываемой функции, с любой стороны конвейера (`x |> _`), в литерале
списка или записи, в скобках (`(_)`), а также как секция поля или оператора
(`_.name`, `(_ + 1)`).

Запишите `fun`, когда нужна функция от значения, или `todo` для ещё не
написанного кода. Подстановочные знаки в образцах (`| _ -> …`) и дырки типов
в сигнатурах (`x : _`) не меняются.

```flick fail
module App.Example exposing (pair)

pair : List String
let pair = [_, "world"]
```

Запишите `fun` вместо дырки:

```flick
module App.Example exposing (with_world)

with_world : String -> List String
let with_world name = [name, "world"]
```
