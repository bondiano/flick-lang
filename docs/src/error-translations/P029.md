`emit = "go"` собирает программу с помощью инструментария Go: `flick build` создает модуль Go для каждой записи в `go/<entry>/` в выходном каталоге и запускает на нем `go build`. Либо `go` отсутствует в `PATH`, либо `go build` завершился с ошибкой на сгенерированном коде.

Установите Go (версии 1.23 или новее) и убедитесь, что `go version` работает в оболочке, которая запускает `flick`. Сбой самого `go build` является ошибкой компилятора: сообщение сохраняет конец его вывода для отчета.

```sh
go version
flick build --emit go
```
