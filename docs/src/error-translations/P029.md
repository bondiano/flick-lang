`target = "go"` собирает программу официальным бэкендом Go: он пишет модуль Go для каждой записи в `go/<entry>/` выходного каталога и просит хост запустить на нём `go build`. У хоста нет `go`, который он мог бы дать: либо `go` отсутствует в `PATH`, либо проект не разрешает бэкенду его запускать.

Установите Go (версии 1.23 или новее) и убедитесь, что `go version` работает в оболочке, которая запускает `flick`. Разрешите инструмент в `flick.toml` или флагом `--allow-tool go` при сборке файла вне проекта. Сбой самого `go build` — это `FLICK-P050` с концом его вывода.

```toml
[tools]
"flick/go" = ["go"]
```
