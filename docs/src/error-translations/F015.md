`FuncRef (a -> b)` ссылается на функцию без захвата, которую хост без замыканий принимает как обычный указатель на функцию. Там, где ожидается `FuncRef`, значением должно быть имя функции верхнего уровня или лямбда, которая ничего не захватывает. Захваченная локальная переменная, частичное применение, локальная функция, метод класса и функция, которой при её типе нужны словари классов, требуют окружения во время выполнения и отклоняются. Словарь класса, который лямбда берёт у окружающей функции, тоже считается захватом.

```flick fail
apply : FuncRef (Int -> Int) -> Int -> Int
let apply r x = FuncRef.fun r x

shift : Int -> Int -> Int
let shift by x = apply (fun n -> n + by) x
```

Передайте то, что нужно функции, аргументом или вынесите её на верхний уровень:

```flick
apply : FuncRef (Int -> Int -> Int) -> Int -> Int -> Int
let apply r by x = FuncRef.fun r by x

shift : Int -> Int -> Int
let shift by x = apply (fun step n -> n + step) by x
```
