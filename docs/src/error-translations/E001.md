Вызов во время выполнения происходит там, где может выполняться только чистый код: в функции, сигнатура которой содержит чистую стрелку `->`, в обратном вызове, который ожидается как чистый, или во время инициализации модуля. Пустая строка не делает вызов чистым: `->{}` по-прежнему является стрелкой времени выполнения. Сделайте стрелку стрелкой времени выполнения или отложите вызов с помощью `task { … }`.

```flick
# type UserId = UserId String
# type User = User { name : String }
# type error NotFound = NotFound String
service Users =
  get : UserId ->{; NotFound} User

// was: load_user : UserId -> User
load_user : UserId ->{Users; NotFound} User
let load_user id =
  Users.get id
```
