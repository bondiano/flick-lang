`Module Sig` может переносить класс или сервис только тогда, когда `Sig` фиксирует его номинальное тождество явным требованием, например `class Eq = Prelude.Eq` или `service Clock = Time.Clock`. Абстрактной формы класса или сервиса достаточно для статического параметра функтора, но `pack` не сможет восстановить её тождество после `unpack`.
