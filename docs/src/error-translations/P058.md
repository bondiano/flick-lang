Командная строка или таблица `[target.<name>]` в `flick.toml` передала опцию,
которую выбранный бэкенд не объявляет для этой команды, указала значение
неверного типа или вне списка `choices`, либо пропустила обязательную опцию.

Выполните `flick <command> --target <name> --help`, чтобы увидеть опции,
которые выбранный бэкенд объявляет для этой команды, и проверьте написание и
типы в `[target.<name>]`.

```sh
flick build --target js --help
flick build --target go --help
```
