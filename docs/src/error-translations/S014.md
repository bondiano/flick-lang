Атрибут неизвестен, имеет неверные аргументы или расположен не на своём месте.
Допустимые атрибуты: `@lang`, `@derive`, `@maker`, `@cell` и `@implicit`.
`@lang` называет один lang item компилятора; `@derive` может назвать пакет
плагина; `@maker` не принимает аргументов; `@cell` не принимает аргументов и
стоит перед объявлением типа; `@implicit` не принимает аргументов и допустим
только перед объявлением экземпляра класса.

```flick fail
@inline
double : Float -> Float
let double x = x * 2
```

Сообщается о неправильно написанном элементе, таком как `@lang integer`, или о неизвестном атрибуте, таком как `@inline`.
