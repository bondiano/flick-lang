Атрибут не является `@lang`, за которым следует один lang item, известный компилятору.  
`@lang` — единственный атрибут: он отмечает в встроенных модулях объявление, на которое сам компилятор опирается, например, тип целых чисел.

```flick fail
@inline
double : Float -> Float
let double x = x * 2
```

Сообщается о неправильно написанном элементе, таком как `@lang integer`, или о другом атрибуте, таком как `@inline`.
