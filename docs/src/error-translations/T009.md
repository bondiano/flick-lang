`match` должен покрывать каждое значение своего исследуемого выражения; диагностика показывает значение,
которое не покрывается ни одним из вариантов. Ветки с охранными выражениями `when` ничего не покрывают,
поскольку охранное выражение может быть ложным. Шаблон в `let` или в параметре должен соответствовать каждому значению: используйте `match`
для шаблона, который может не совпасть.

```flick
describe : Option Float -> String
let describe value =
  match value with
  | Some 0 -> "zero"
  | Some _ -> "number"
  | None -> "nothing"
```
