Плагины двух пакетов заявляют, что загружают файлы с одинаковым расширением:

```toml
# protos/flick.toml
[package]
name = "protos"
version = "0.1.0"
plugin = "protos.wasm"
load = ["proto"]
```

и у другой зависимости `[package]` также есть `load = ["proto"]`. Файл
`App/User.proto` должен принадлежать модулю одного из плагинов, поэтому проект использует
плагин зависимости, названной первым, и сообщает об этом.

Оставьте только один из пакетов или сделайте так, чтобы один из них загружал другое расширение.
