Внешняя функция с параметром, который доходит до региона области видимости (возможность вроде `File s` или квалификатор захвата `^c`), должна выполнять стадию. Элизия `Live` держит регион живым только там, где выполняется стадия: чистую внешнюю стрелку над ресурсом можно вызвать после закрытия её `scope` через вспомогательную функцию или сохранённое замыкание и прочитать то, что область уже освободила, и никто не проверит, что регион ещё открыт.

```flick fail
type File (s : Region)

peek : File s -> Int
foreign pure peek from "./file.js" "peek"
  retention call
```

Дайте функции стадию: строку эффектов (`->{}`, если эффектов нет), и объявите её `foreign effect`. Тогда каждому вызову нужен живой регион, а замыкание, которое её вызывает, не может покинуть свой `scope`:

```flick
type File (s : Region)

peek : File s ->{} Int
foreign effect peek from "./file.js" "peek"
  retention call
```
