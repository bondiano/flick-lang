Два пакета зависимостей проекта указывают один и тот же npm-пакет с разными версиями в `[js.dependencies]`, или один из них отличается от `package.json` проекта. Проект устанавливает одну копию npm-пакета, поэтому требования должны совпадать дословно: измените `package.json` проекта или используйте версии пакетов, которые согласованы.

```toml
[js.dependencies]
left-pad = "^1.3.0"
```
