Проверка `proof` вычисляет обе стороны в пределах фиксированного бюджета шагов и глубины, одинакового на всех платформах. Этому доказательству нужно больше: ничего не доказано, даже для верного утверждения, и доказательство, исчерпавшее бюджет, никогда не считается верным. Сформулируйте свойство для меньших выражений.

```flick fail T084
proof costly (f : Bool -> Bool) (x : Bool)
where equal ((fun t -> t (t (t (t (t (t (t (t (t f))))))))) (fun g y -> g (g y)) x) ((fun t -> t (t (t (t (t (t (t (t (t f))))))))) (fun g y -> g (g y)) x) =
  refl
```

это

```flick
proof cheap (f : Bool -> Bool) (x : Bool)
where equal ((fun g y -> g (g y)) f x) (f (f x)) =
  refl
```
