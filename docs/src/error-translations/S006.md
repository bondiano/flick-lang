Числовой литерал не соответствует грамматике JavaScript `NumericLiteral`, так как Flick накладывает ограничения: отсутствует ведущий ноль (`010`; используйте `0o10`), `_` допускается только между двумя цифрами, цифры после `0x`/`0o`/`0b` и в экспоненте, BigInt `n` разрешён только для целых чисел, и после числа не должно быть букв. В отличие от JavaScript, `.5` и `5.` отклоняются, поскольку `.` является доступом к полю.

```flick
let ratio = 0.5
let million = 1_000_000
let big = 9007199254740993n
```
