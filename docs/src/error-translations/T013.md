Обобщаются только значения, построенные полностью. Результат вызова во время выполнения (даже
`->{}`) является мономорфным, поэтому полиморфная сигнатура, аннотация или аргумент с высшим рангом над ним отклоняются, а значение верхнего уровня, тип которого остаётся неизвестным,
требует сигнатуры. Сигнатура с ограничениями класса также отклоняется:
ее словари превратят значение в функцию, которая будет выполняться заново при каждом использовании. Создайте фабричную функцию или опишите вычисление с помощью `task` и выполните его там, где известен каждый тип.

```flick
make_empty : forall a. Unit ->{} Ref (Option a)
let make_empty () =
  Ref.make None

fresh_cell : forall a. Eff none none (Ref (Option a))
let fresh_cell =
  task { Ref.make None }
```
