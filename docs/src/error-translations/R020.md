Переменная `let mut`, которой не присваивает ни один оператор, никогда не меняется, поэтому `mut` ей не нужен: читатель кода стал бы искать присваивание. Безопасное исправление убирает `mut`, если нет встроенной аннотации типа. Для аннотированного значения-функции сначала может потребоваться перенести тип в отдельную сигнатуру перед объявлением.

```flick
module App.Area exposing (area)

area : Float -> Float -> Float
let area width height =
  let size = width * height
  size
```
