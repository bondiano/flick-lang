Плагин, чей пакет указан как `hooks = ["ir"]`, передал сборке IR, который не согласован: модуль с одинаковым именем встречается дважды, локальная переменная используется там, где она не связана, глобальная переменная из модуля, которого нет в сборке, диапазон файла, который сборка не читала, или программа другой версии IR. Сборка останавливается, указывая плагин, вместо того чтобы компилировать.

Ошибка на стороне плагина: он должен вернуть `Program` той версии, которую получил, в котором каждая локальная переменная связана там, где используется.
