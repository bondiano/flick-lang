Быстрое исправление удаляет её; `flick check --fix` удаляет все такие аннотации. Отключите предупреждение с помощью `allow = ["FLICK-T021"]` под `[lint]` в `flick.toml`.

let kinds = [Tracer.internal, Tracer.server]
