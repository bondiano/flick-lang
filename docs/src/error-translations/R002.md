Два файла объявляют один и тот же полное имя модуля, например, модуль в корне теста с именем исходного модуля или локальный модуль с именем модуля из установленного пакета. Имена модулей глобальны в пределах проекта: переименуйте один из них.

```flick
// test/App/UsersTest.fl, not test/App/Users.fl
module App.UsersTest exposing (tests)
```
