`let` или `<-`, которые связывают имя локальной переменной, всё ещё находящейся в области видимости, скрывают эту локальную переменную на остальную часть блока, и читателю приходится разбираться, к чему относится каждое использование. Дайте этому собственное имя. Повторное связывание значения самого с собой, `let total = total + tax`, не сообщается, как и параметры `fun` или переменные ветви `match`.

```flick
area : Float -> Float -> Float
let area width height =
  let w = width * 2
  w * height
```
