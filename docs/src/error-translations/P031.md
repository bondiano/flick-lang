Нельзя использовать зависимость рабочего пространства или путь. `flick.toml` с `[workspace]` и без `[project]` является корнем рабочего пространства, а не проекта: команды, выполняемые там, проходят через каждого участника или через один `--package <name>`, который указан. Зависимость `[dependencies] name = { path = "…" }` указывает на каталог с `flick.toml` типа `kind = "lib"`, исходники которого компилирует проект; зависимости не должны образовывать циклы.

```toml
# the root of the workspace
schema-version = 1

[workspace]
members = ["contract", "server"]
```

```toml
# server/flick.toml
[dependencies]
contract = { path = "../contract" }
```
