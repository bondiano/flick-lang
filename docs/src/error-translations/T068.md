# Статический функтор или вложенный модуль нельзя упаковать

`Module Sig`, `pack` и `unpack` передают структуры во время выполнения.
Функтор строит модули статически, в том числе когда он вложен в структуру.
Сначала примените функтор, затем упакуйте структуру с runtime-контрактом.

Runtime-запись модуля пока передаёт плоский набор значений и свидетелей типов.
Сигнатуру с `module Child : Inner` тоже нельзя упаковать: запись не представляет
вложенное пространство имён. Сделайте runtime-контракт плоским и явно откройте
значения и свидетелей типов, которые должны передаваться вместе.
