Плагин не предоставил код для блока: он обнаружил, что блок неверен (его сообщение объясняет почему), произошла ошибка во время выполнения (ловушка, исчерпание топлива или памяти), либо предоставленный код не подходит для данного блока. Ошибки в коде пользователя внутри блока сообщаются отдельно; данное сообщение касается плагина или того, как блок написан для него.

```flick
import Pairs exposing (plugin pairs)

let point = pairs { x = 1.0; y }
```
