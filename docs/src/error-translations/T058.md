Сопоставление с конструктором, написанным с `: R`, научит проверяющий механизм тому, чему он не учится:

- что два региона — это один и тот же регион: регион передается через конструктор как переменная и никогда не уточняется;
- равенству рядов сервисов, ошибок или захватов;
- равенству из шаблона, который не является ветвью `match`, например, шаблона `let` или параметра. Вместо этого сопоставляйте его в `match`.

```flick
type Expr a =
  | IntLit Int : Expr Int
  | BoolLit Bool : Expr Bool

as_int : Expr Int -> Int
let as_int e =
  match e with
  | IntLit n -> n
```
