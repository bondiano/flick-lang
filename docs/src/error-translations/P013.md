`flick build` не смог создать выходной каталог или записать в него файл. В сообщении указаны путь и причина, которую вернула система: например, нет прав доступа или вместо каталога обнаружен файл.

Исправьте путь или права доступа либо выберите другой каталог:

```sh
flick build --out-dir build
```
