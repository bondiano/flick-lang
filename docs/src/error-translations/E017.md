Задача, которую выполняет `spawn`, `parallel` или `race_first`, находится в отдельном фибере. Обработчик эффекта с операцией `control` находится в том же фибере, который его установил, как и остальная часть вычисления, которую держит `resume`: дочерний элемент не может к нему обратиться. Обрабатывайте такой эффект внутри задачи или собирайте результаты дочерних элементов с помощью `join` или `Channel`.

Работа, которую поддерживает регион, требует того же: финализатора, освобождения ресурса, слушателя. Она выполняется при закрытии области видимости, когда обработчик мог уже отпустить тело. Никто не ответит на операцию, и финализатор остановится там.

```flick
effect Emit a =
  control emit : a ->{} Unit

collect : forall a r e. (Unit ->{Emit a | r; e} Unit) ->{r; e} List a
let collect body =
  try
    body ()
  with
  | Emit.emit x -> [x] ++ resume ()
  | return () -> []

both : Unit ->{} (List Int, List Int)
let both () =
  // was: collect (fun () -> parallel (task { Emit.emit 1 }) (task { Emit.emit 2 }))
  parallel (task { collect (fun () -> Emit.emit 1) }) (task { collect (fun () -> Emit.emit 2) })
```

Функция, которая запускает или поддерживает такую работу с сервисами переменной строки с именем `Detached r` в своей сигнатуре.
