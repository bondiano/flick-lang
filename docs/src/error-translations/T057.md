Ветка `match` в конструкторе, написанном с помощью `: R`, узнаёт, каков тип сопоставляемого значения: в ветке `IntLit` сопоставления по `Expr a`, `a` имеет тип `Int`. Проверяющий использует это только тогда, когда типы известны:

- функция вокруг `match` имеет полную сигнатуру (в ней нет `_`);
- тип сопоставляемого значения известен там, где происходит сопоставление, а не выводится из веток;
- внутри ветки ничего снаружи не получает свой тип из того, что узнала ветка. Тип, который снаружи всё ещё неизвестен, например результат неаннотированного `let`, требует аннотации.

```flick
type Expr a =
  | IntLit Int : Expr Int
  | BoolLit Bool : Expr Bool

eval : forall a. Expr a -> a
let eval e =
  match e with
  | IntLit n -> n
  | BoolLit b -> b
```

Без сигнатуры `eval` сообщается об ошибке `match`.
