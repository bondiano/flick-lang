Модуль определяет имя дважды в одном пространстве имён: два значения, два типа или два конструктора с одинаковым именем. Сигнатура и её `let` считаются одним определением. Переименуйте или удалите одно из них.

```flick fail
type Light = Green | Red
type Stop = Red | Amber
```

Блоки `suite` и `test` модуля объявляют его `tests`, поэтому модуль с блоками, который ещё и объявляет `tests` вручную, определяет его дважды: перенесите написанные вручную тесты в блок или уберите блоки.

```flick fail
tests : List Test.Test
let tests = [Test.test "by hand" (fun () -> Test.Pass)]

test "a block" {}
```
