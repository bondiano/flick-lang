Обработчик находит сервис или эффект по имени, а не по аргументам.
`provide` слоя или записи `Store Int` и `try` с ветками для `Store Int`
отвечают на каждую операцию `Store` в своём теле, поэтому переменная ряда
тела, которая может содержать `Store` с другими аргументами, например
`Store String`, получила бы вместо него `Store Int` обработчика. Исключите
сервис из переменной, `{-Store | s}`, чтобы вызывающий код не мог передать
работу, которой он нужен, или назовите экземпляр, нужный телу,
`{Store Int | s}`. Функция с переменной ряда там, где ожидается функция с
`{Store Int | s}`, получает ту же ошибку.

```flick fail
service Store a =
  get : Unit ->{} a

answered : Layer none none {Store Int} -> Eff s none a ->{s} a
let answered layer t = provide layer { await t }
```

```flick fail
effect Ask a =
  ask : Unit ->{} a

hidden : (Unit ->{r; e} Int) ->{r; e} Int
let hidden body =
  try body () with
  | Ask.ask () -> 41
```

```flick
service Store a =
  get : Unit ->{} a

apart : Layer none none {Store Int} -> Eff {-Store | s} none a ->{s} a
let apart layer t = provide layer { await t }

named : Layer none none {Store Int} -> Eff {Store Int | s} none a ->{s} a
let named layer t = provide layer { await t }
```
