`~` помечает параметр функции, которая принимает аргумент как вычисление, `~(Eff r e a)`: при вызове прямой runtime-вызов, записанный этим аргументом, передаётся незапущенным, как передал бы его `task { … }`, и функция сама решает, когда его выполнить. Маркер ставится только слева от `->` и только на параметр типа `Eff`.

```flick
or_else_zero : ~(Eff r e Int)^c ->{r} Int
let or_else_zero job = Effect.or_die job
```
