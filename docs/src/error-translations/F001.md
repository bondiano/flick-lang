Внешние метаданные должны соответствовать сигнатуре, режиму и правилам
адаптеров активного бэкенда: слова ядра контракта требуют, чтобы `arity` не
превышало число параметров (`arity 0` опускает первый аргумент `()`),
`optional i` указывало на аргумент `Option`, `nullable` сочеталось с
результатом `Option`, `owned i` указывало на существующий аргумент, а `catch`
применялось в режиме, который может завершиться ошибкой. Объявленные бэкендом
слова адаптеров (такие как `this`, `variadic` и `cancel signal` /
`cancel context` в `flick/js` и `flick/go`, либо пользовательские слова другого
бэкенда) проверяются самим бэкендом. `foreign sync` и `foreign async` — устаревшие слова:
без слова режима сигнатура сама определяет, как вызывается хост.

```flick
now_millis : Unit ->{} Float
foreign now_millis from global "Date.now"
  arity 0
```
