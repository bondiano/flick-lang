Внешние метаданные должны соответствовать сигнатуре, режиму и правилам адаптера активного бэкенда: `arity` подсчитывает аргументы хоста и не превышает количество параметров, `arity 0` опускает первый аргумент `()`, `optional i` именует аргумент `Option`, `owned i` называет индекс параметра в пределах `arity`, `nullable` создаёт результат `Option`, `catch` — для режима, который может выбрасывать исключения, а слова адаптера бэкенда (например, `this`, `variadic` и `cancel signal` для `flick/js` и `flick/go`) должны соответствовать объявленной форме аргументов и проверкам цели. `foreign sync` и `foreign async` — прежние слова: без слова режима сигнатура указывает, как вызывается хост.

```flick
now_millis : Unit ->{} Float
foreign now_millis from global "Date.now"
  arity 0
```
