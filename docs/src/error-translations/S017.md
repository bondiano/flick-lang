В одном применении функции может быть не больше одной дырки `_`. Одна дырка
захватывает один аргумент как анонимную функцию (`f a _ c` означает
`fun h -> f a h c`); если пропущено два или больше аргументов, запишите `fun`
явно либо оставьте отдельную дырку во вложенном вызове в скобках (`f (g _) _`).

```flick fail
module App.Example exposing (wrap)

label : String -> String -> String -> String
let label open mid close = open ++ mid ++ close

wrap : String -> String -> String
let wrap = label _ _ "]"
```

Запишите `fun`, когда открыто больше одного аргумента:

```flick
module App.Example exposing (wrap)

label : String -> String -> String -> String
let label open mid close = open ++ mid ++ close

wrap : String -> String -> String
let wrap = fun open mid -> label open mid "]"
```
