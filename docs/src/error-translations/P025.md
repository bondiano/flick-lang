`flick diff` выполняет проверку ревизии git в временном рабочем дереве и
сравнивает публичное API там с API в рабочем дереве. Для этого требуется `git` — ревизия, которая существует (последний тег, если имя не указано), и проект, который
собирается без ошибок в обоих деревьях.

```text
flick diff v1.2.0
```
