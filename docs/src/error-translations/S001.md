Исходный файл Flick должен быть в корректной кодировке UTF-8. Диагностика указывает на первую последовательность байтов, которая не является допустимой в UTF-8; дальнейшая проверка файла не выполняется.

Сохраните файл заново в кодировке UTF-8 (не меняя кодировку текста вручную):

```sh
iconv -f WINDOWS-1251 -t UTF-8 src/App/Main.fl > Main.fl && mv Main.fl src/App/Main.fl
```
