Импорт раскрывает заголовок плагина `plugin head`, плагин которого компилятор не может загрузить: импортируемый модуль является одним из модулей проекта или встроенным модулем, у которых нет плагина, его пакет не содержит плагина, либо плагин не загружается. Блоки заголовка остаются непроверенными до тех пор, пока плагин не загрузится.

```flick
import Pairs exposing (plugin pairs)
```
