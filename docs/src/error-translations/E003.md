Аргументы вычисляются до применения функции. Функция, которая принимает `Eff`, решает, когда выполняется вычисление, например, после установки окружения; вызов времени выполнения, записанный в качестве её аргумента, к тому моменту уже выполнен. Передайте вычисление в не запущенном виде с помощью `task { … }` или, если вы автор функции, пометьте её параметр `~(Eff r e a)`: тогда runtime-вызов, записанный этим аргументом, при каждом вызове передаётся незапущенным.

```text
// was: with_users users_layer (load_request id)
with_users users_layer (task { load_request id })
```
