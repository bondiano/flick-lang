`flick run` и `flick dev` делегируют точки входа с `target = "client"`
командам `run-client` и `dev-client` выбранного бэкенда. Бэкенд этого проекта
не объявляет исполнитель клиентских точек входа для запрошенной команды,
поэтому `flick` не может запустить клиентскую точку входа на этой цели.

Запустите точку входа с целью, бэкенд которой поддерживает клиентские точки
входа, или выберите неклиентскую точку входа проекта:

```sh
flick run --target js <entry>
```
