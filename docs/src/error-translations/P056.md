Проект собирается официальным бэкендом `flick/js` или `flick/go`, которого нет в самом компиляторе: это ассет релиза. Если `[build.backend]` не задан, сборка берёт бэкенд, закреплённый в `flick.lock`, из хранилища пакетов (скачивая его один раз) или самый новый релиз из индекса бэкендов, который принимает API бэкендов и IR этого компилятора, и закрепляет его.

Ошибка возникает, если с `--offline` нужного бэкенда нет в хранилище, если индекс не читается или в нём нет релиза, который принимает этот компилятор, или если скачанный компонент не совпадает с хешем из lock-файла или индекса. Другой бэкенд вместо него не подставляется. Соберите проект один раз с сетью или выполните `flick install`, чтобы закрепить и сохранить бэкенд; `flick update` переводит закрепление на более новый релиз.

```sh
flick install
flick build --offline
```
