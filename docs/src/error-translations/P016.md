Команды зависимостей запускают закрепленные версии pnpm версии `package.json` в
`packageManager`, проверяемые перед записью любых данных. Другая версия или отсутствие
pnpm полностью останавливает выполнение команды с кодом выхода 2.

```sh
corepack enable
corepack prepare pnpm@12.16.1 --activate
```
