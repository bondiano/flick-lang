Приложение остановилось, но закрытие его областей не удалось: финализатор завершился с ошибкой или так и не завершился. `flick dev` прекращает его перезапуск, поскольку следующая версия может обнаружить ресурсы, которые старое приложение всё ещё удерживает; причина указана выше.

```flick
Resource.acquire_release open (fun file -> File.close file)
```
