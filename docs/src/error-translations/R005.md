Конструкторы типа экспортируются только тогда, когда модуль перечисляет их с помощью
`Type(..)`; экспортирование только `Type` оставляет их приватными, а непрозрачный тип никогда
не экспортирует их. Импортируйте только тип и создавайте значения с помощью функций модуля,
или экспортируйте конструкторы из модуля, который определяет тип.

```flick
module App.Shapes exposing (Shape(..), area)

import App.Shapes exposing (Shape(..))
```
