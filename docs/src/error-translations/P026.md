Запуск приложения начинается с `main` с `()` и либо вызывается как обычная функция, либо выполняется как эффект. Таким образом, `main` является `Unit -> Unit`, или `Unit ->{; AppError} Unit`: каждый сервис, который он использует, предоставляется внутри него, и единственная ошибка, которую он пропускает наружу — это `AppError`, о которой сообщает раннер.

```flick
module App.Main exposing (main)

main : Unit ->{; AppError} Unit
let main () = provide Users.live { App.run () }
```
