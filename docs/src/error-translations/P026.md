Раннер приложения запускает `main` с `()` и либо вызывает его как обычную функцию, либо выполняет как эффект. Поэтому `main` — это `Unit -> Unit` или эффектная функция вроде `Unit ->{Host.Console; AppError} Unit`: ей могут быть нужны сервисы `Host`, которые предоставляет её вход (с раннером — сервисы, названные в его `Main`), все остальные сервисы она предоставляет себе сама, а наружу выпускает только ошибку `AppError`, о которой сообщает раннер.

```flick ignore
module App.Main exposing (main)

main : Unit ->{; AppError} Unit
let main () = provide Users.live { App.run () }
```
