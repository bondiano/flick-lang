Определение верхнего уровня, которое модуль не экспортирует, никогда не используется экспортируемыми определениями, ни напрямую, ни через другие приватные определения. Удалите его или экспортируйте.

```flick fail
module App.Prices exposing (net)

net : Float -> Float
let net price = price * 0.8

gross : Float -> Float
let gross price = price * 1.2
```

`gross` никогда не используется. Приватные определения, которые используют только друг друга, сообщаются вместе.
