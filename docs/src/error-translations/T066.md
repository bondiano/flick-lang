# Неоднозначные локальные словари модулей

Два статических аргумента одного применения параметризованного модуля дают словари для одного и того же ограничения класса. Компилятор не выбирает словарь по порядку аргументов.

Оставьте в области параметризованного модуля одно требование `instance C T from value`. Если нужны обе политики, передавайте значения словарей явно в использующие их операции либо создайте два именованных применения.
