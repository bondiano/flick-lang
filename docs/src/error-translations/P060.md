`flick new` или `flick init` запросили шаблон, которого нет у выбранного
бэкенда или пакета `--from`, либо пропустили `--template`, когда контрибьютор
не предоставляет шаблон по умолчанию.

Диагностика перечисляет шаблоны, которые предоставляет контрибьютор. Передайте
одно из этих имён через `--template`, выберите другой `--target` или загрузите
сторонний пакет шаблонов через `--from`.

```sh
flick new my-app --target go --template app
```
