Цель go (`target = "go"`) компилирует то, что достигает `main`, и сообщает здесь о конструкции, которую она ещё не компилирует, называя её: ленивым `for`, который читает сервисы, уточнённые типы или `foreign`-привязку без реализации на Go, в стандартной библиотеке или рядом с программой. Также сообщается о `main`, который не принимает один параметр, приложении без точки входа и модуле пакета, недоступном для цели go. Цель js собирает ту же программу.

Если конструкция — это собственная `foreign`-привязка программы, добавьте её реализацию на Go рядом с программой (см. справочник FFI). В противном случае исключите конструкцию из того, что достигает `main`, или собирайте с `target = "js"`.

Доступность модулей, пакетов и привязок адаптера Effect в выбранной среде сообщается кодом `FLICK-P064`.
