Используемый в этом запуске `std` был написан для другого компилятора, и один из его модулей не совместим с этим. Выпущенный компилятор использует `std` своей собственной версии, поэтому это происходит с компилятором, собранным из исходников, или когда `FLICK_STD_PATH` или `[dependencies]` указывает на `std` другой версии.

Компилятор, собранный из checkout, использует `std` этого checkout, пока checkout находится там, где он был собран. В противном случае укажите `std` того же исходного кода:

```toml
[dependencies]
std = { path = "../flick-lang/packages/std" }
```

или установите `FLICK_STD_PATH` в этот каталог.
