Цикломатическая сложность функции, равная 1 плюс каждое `if`, каждый `match`
ветвь после первой, каждый guard и каждый `&&` и `||`, превышает
`[lint] max-complexity` в `flick.toml` (по умолчанию 10). Каждая ветвь — это
путь для тестирования. Вынесите группы ветвей в отдельные функции или
замените цепочку условий на `match`.

Повышайте лимит с помощью `max-complexity = 15` в `[lint]` или отключайте
предупреждение с помощью `allow = ["FLICK-T038"]`.
