`[build] environment = "<backend>/<host>"` указывает хост, который не
предоставляет ни выбранный бэкенд, ни один из загруженных пакетов-хостов
`[host]`, два загруженных пакета-хоста объявляют один и тот же хост для одного
бэкенда, либо условие `[host] requires` выбранного хоста не выполняется для
активных тегов бэкенда.

Проверьте написание хоста по встроенным хостам бэкенда и зависимостям проекта
или включите опции бэкенда, которых требует хост:

```toml
[build]
environment = "js/node"
```
