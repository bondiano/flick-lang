`proof` утверждает, что две стороны равны при любых значениях параметров. Здесь checker вычислил обе стороны и получил разные значения: разные конструкторы или разные литералы. Утверждение ложно, и никакое доказательство его не закроет. Проверьте, что утверждение говорит то, что вы имели в виду.

```flick fail T080
proof always_some (x : Bool)
where equal (Some x) None =
  refl
```

это

```flick
proof always_some (x : Bool)
where equal (Some x) (Some x) =
  refl
```
