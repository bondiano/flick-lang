`_` в сигнатуре или аннотации оставляет эту часть типа для проверки. Предупреждение показывает тип, который был выведен, а исправление записывает его вместо `_`.

```flick
module App.Pairs exposing (swap)

swap : (Float, String) -> _
let swap (a, b) = (b, a)
```

Исправление записывает `(String, Float)`.

Редактор предлагает замену только тогда, когда может определить полный тип; для сопоставления с GADT он проверяет предложенную сигнатуру перед её предложением.
