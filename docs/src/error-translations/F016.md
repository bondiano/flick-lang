У `type` есть `@native when <cond>`, но нет конструкторов.

`@native` у типа говорит, где он собственный тип бэкенда, значения которого
создают только привязки бэкенда; в остальных местах его конструкторы — его
представление на Flick, которое строят и разбирают тела его функций на Flick.
Типу без конструкторов не на что опереться: он непрозрачен везде, и `@native`
ему не нужен.

Дайте типу конструкторы, которыми пользуются его тела там, где условие не
выполняется, или уберите `@native`:

```flick
type Box a =
  | Box a
  @native when js || go
```
