---
title: "FLICK-P052"
---

`flick` has no core command of this name, and neither the project's
backend nor the plugins of its dependencies add one. Outside a project only
the core commands and those of the official backends run: other
contributed commands need the project whose backend or dependency adds
them. When an official backend or a backend or
plugin the store has seen adds it, the message names that one.

`flick --help` lists the core commands and, in a project, the commands
each contributor adds.
