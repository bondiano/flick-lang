The chapter's exercise. `main` opens a resource with `open_res` outside every
scope, so nothing would ever close it, and the compiler reports
`FLICK-G004`.

Give it a scope, then press **Check answer**. The resource writes what
happens to it in a list, which `main` prints on one line.
