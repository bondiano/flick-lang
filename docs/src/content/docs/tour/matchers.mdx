**Where it runs:** in an isolated browser worker. Tests mode shows the real report; List tests prints names without running bodies or hooks. Locally: a project's `test/Main.fl` and `flick test`. CI checks both.

`expect actual |> to.equal expected` compares values with `Eq` and shows
them with `Show`. Boolean, ordering and containment matchers name the property
being checked. `to.fail_with` runs an `Eff` and checks its typed failure.
The old assertion-taking operation is `Test.check`, not `Test.expect`.

The final test deliberately fails: a multiline equality failure shows
removed expected lines and added actual lines. This run exits 1, with five
passed cases and one assertion failure; CI checks that failure too.

**Try:** change `actual` to `expected`, then rerun `flick test`. Do not delete
the assertion to make a suite green.
