<TourLesson locale="en" id="arrows">

Signatures tell two kinds of functions apart. `double : Int -> Int` has a
plain arrow: it is pure, it only computes a result from its arguments, and
the same arguments always give the same result.

`announce : Int ->{Host.Console} Unit` has braces after the arrow: it runs,
and running can do things, such as print. The braces list what it needs
before a `;` and how it may fail after it, as in `->{Users, Log; NotFound}`:
`announce` prints, so it needs the console, `Host.Console`. Empty braces
need nothing. A pure function cannot call one that runs.

A `foreign` binding is taken on trust: its braces say what it needs only as
far as it is declared.
[Why Flick](../../start/why/#where-the-promise-stops) says where the promise
stops.

**Try:** make `double` print a line before it returns. The compiler reports
`FLICK-E001`: `double` is pure.

</TourLesson>
