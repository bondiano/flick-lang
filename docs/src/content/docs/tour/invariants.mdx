**Where it runs:** browser and locally.

The `Ports` module hides construction, not the invariant. A `Port`'s
underlying value is positive, so `Positive.prove` needs no new guard.
In a project the invariant also travels through `.iface`, aliases and
re-exports; changing it rechecks consumers.

**Guarantee:** the checker can reuse a refined value's declared invariant
across a module boundary, not an arbitrary claim made by foreign code.
