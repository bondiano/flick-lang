**Where it runs:** in an isolated browser worker. Tests mode shows the real report; List tests prints names without running bodies or hooks. Locally: a project's `test/Main.fl` and `flick test`. CI checks both.

A suite groups tests; each case gets its own scope and live host services.
`.skip` never runs its body. `.only` keeps only focused cases in the selected
files; a skipped case stays skipped. Here only `focus` runs.

`flick test --list` prints `Main > names > focus` and runs nothing.
`flick test --forbid-only` exits 1 for this intentional focus. CI checks both
behaviors. Remove `.only` before committing real project tests.

Choose List tests and press Run, then return to Tests.
The filter selects cases by their full names. Each run uses a fresh worker.
