The tour shows Flick one idea at a time. Each lesson is a short text and a
program beside it. The real compiler checks the program as you type, and once
you stop typing the program runs. Change it, break it on purpose, and read
what the compiler says.

The chapters build on each other, and each one ends with an exercise that
checks your answer. Your edits stay in this browser. To install Flick and
work on your own project, see [Getting started](../start/getting-started/).
