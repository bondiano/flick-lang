<TourLesson locale="en" id="release-on-failure">

`Resource.own` gives the scope exclusive ownership of a value with a
`Close` instance. `close_exit` commits this transaction on success and rolls
it back otherwise. `Resource.make` and `Scope.defer` also receive the `Exit`.

`check (-3)` fails. Cleanup runs last registered first: flush, close, rollback,
then the handler prints `handled -3`. All three run exactly once.
See [ownership and outcome](../../reference/resources/).

**Try:** use `check 3`. The same cleanup now reports success and commits.

</TourLesson>
