<TourLesson locale="en" id="scope-type">

`Scope s` says that `open_res` acquires into its caller's scope.
`Resource.make` registers cleanup there. `Fiber.Provided {Host.Console} s`
ensures that the console used by that cleanup outlives the scope.

Here the resource is a string, which holds no region. Handles that capture
resources carry `^{s}` and cannot escape. See [resources](../../reference/resources/).

**Try:** call `both ()` without `scope`: `FLICK-G004` reports the missing owner.
