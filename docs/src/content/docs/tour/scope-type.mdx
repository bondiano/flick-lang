A function that opens a resource in its caller's scope says so:
`Scope s` in the row of `open_res` needs a scope `s` from whoever calls it.
Its release prints when `s` closes, so it also asks for a `Host.Console`
that lasts as long: `Fiber.Provided {Host.Console} s`. `both` passes these
needs on, and `main` provides the scope, which closes both resources once
`both ()` is done.

This is how a signature tells you that a function opens something that has
to be closed.

**Try:** call `both ()` in `main` without `scope { … }`. The compiler reports
`FLICK-G004`: nothing owns the resources.
