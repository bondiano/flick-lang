**Where it runs:** in an isolated browser worker. Tests mode shows the real report; List tests prints names without running bodies or hooks. Locally: a project's `test/Main.fl` and `flick test`. CI checks both.

Setup runs outer to inner; cleanup runs inner to outer. `before_all` and
`after_all` belong to the suite; `before_each` and `after_each` surround each
selected case. Unselected and skipped cases run no hooks. CI checks every
`hook:` line in order, including cleanup after the timed-out case.

`timeout 5` interrupts this never-ending body after 5 ms. Cleanup still runs;
the report says `timeout` and exits 1. A suite timeout supplies its cases'
default and bounds hooks too. `Test.timeout` wraps tests built by hand;
`flick test --timeout 500ms` supplies a run-wide default, otherwise absent.
