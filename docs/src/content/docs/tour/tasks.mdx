<TourLesson locale="en" id="tasks">

A `task { … }` is cold: building `counted` changes nothing. Each `await`
runs it again, so the first two reads give 1 and 2.

`~` on `twice` says that its `Eff` argument is passed unstarted.
`twice (count runs)` needs no `task` wrapper: it runs at each `await`, giving
3 and 4, whose sum is 7. `Effect.or_die (count runs)` works the same way.
A pipe still evaluates its left side first.
See [suspended parameters](../../reference/effects/#task-and-await).

```flick fail T076
wrong : ~Int -> Int
let wrong n = n
```

**Try:** await `counted` again, then compare it with a [lazy](../lazy/).
