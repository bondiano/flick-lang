The chapter's exercise. `count_coins` counts the fewest coins that make an
amount: as many quarters as fit, then dimes, nickels and pennies. It uses a
variant type, a `match` and a `for` loop.

The `match` in `cents` forgets a coin, so the compiler reports `FLICK-T009`.
Cover every coin, then press **Check answer**.
