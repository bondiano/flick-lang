<TourLesson locale="en" id="scope">

A resource needs cleanup even when its user fails. `scope s { … }` owns
resources, and `Resource.make acquire release` acquires one and registers
its release. The release receives the value and the scope's `Exit`.

The socket closes before the file, in reverse acquisition order.
`Resource.acquire_release` is the low-level form that ignores the outcome.
See [resources](../../reference/resources/#acquiring-and-deferring).

**Try:** move an acquisition outside the scope: `FLICK-G004` says that
nothing owns it.

</TourLesson>
