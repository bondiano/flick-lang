<TourLesson locale="en" id="handlers">

An effect is like a service whose meaning its caller decides, with a
handler. `effect Ask =` declares an operation, `total` calls it twice, and
`try total () with` answers: `| Ask.ask "apples" -> 3` for apples and
`| Ask.ask _ -> 4` for anything else. The second handler answers 0 to
everything.

So one function runs under different handlers, which suits tests and
interpreters. An effect can also stop the rest of the body or go on with it,
with `abort` and `control` operations; `control` compiles only to Go for now,
so it is not in this tour.

**Try:** delete the arm `| Ask.ask _ -> 4`. The compiler reports
`FLICK-E002`: the question about pears is not handled, so `Ask` stays in the
signature of `main`.
