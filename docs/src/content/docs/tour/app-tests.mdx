`suite` groups cases, `test` names one, and `test.each` makes a case for each
command script. `expect actual |> to.equal expected` fails a case when its
result differs. `left_after` gives each case a fresh `Ref` and a fake `Shelf`
layer, so cases cannot change each other's state.

**Where it runs:** the editor runs `main`, a short demonstration of the same
scripts. It does not run `tests`. Locally, put this module in `test/Main.fl`
of a Flick project and run `flick test --forbid-only`. CI runs that entry
point and checks **3 passed, 0 failed**. The [Testing chapter](../suites/)
explains this split; see also the [reference](../../reference/testing/).

**Try:** set `read = false` in `Books.finish`. The second local case fails;
the browser demonstration prints `FAILED`.
