<TourLesson locale="en" id="retry">

`flaky calls` is a direct effectful call. Because `Effect.retry` marks its
parameter `~`, the call is passed unstarted, without `task { … }`.
`Schedule.recurs 5` allows five retries after the first attempt. The same
`Ref` counts them; `try` handles the final failure.
See [effects](../../reference/effects/#task-and-await).

**Try:** use `Schedule.recurs 1`: two attempts fail and the handler gives up.

</TourLesson>
