**Where it runs:** in an isolated browser worker. Tests mode shows the real report; List tests prints names without running bodies or hooks. Locally: a project's `test/Main.fl` and `flick test`. CI checks both.

`flick test` provides `Host.Live`. A nested layer replaces just the clock
and random ports; `ticket` is unchanged and still declares both dependencies.
This test asserts an exact time and draw, not a range that occasionally fails.
The clock's three operations are explicit; elapsed time is not wall-clock time.

Never print environment secrets to make a test deterministic. Replace the
port or provider and provide only the data the case needs.
