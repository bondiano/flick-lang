---
title: "1. Цель и подтверждённые требования"
---

| Требование | Смысл |
| - | - |
| Имя и инструменты | Flick, CLI `flick`, исходники `.fl`; общее ядро на Rust для компилятора и LSP |
| ML-подобный синтаксис | Функции, `let`, ADT, сопоставление с образцом и компактная запись прикладного кода |
| HKT | Абстракции над конструкторами типов, включая `Functor`, `Foldable`, `Traversable` |
| Классы типов | Ограничения в сигнатурах, экземпляры классов и выбор реализации по типам |
| Единственный бэкенд на Effect | Исполнение через Effect, его стандартные типы и контракты среды выполнения; чистые участки оптимизируются до обычного JS/TS |
| Семантика Effect в языке | Встроенные правила восстановления после типизированных ошибок, предоставления сервисов, лексического владения и структурированной конкурентности |
| Прямые эффектные вызовы | Обычный `let` связывает результат выражения; эффект вызова учитывается в типе функции |
| Эффект в стрелке | `a -> b` для чистого вызова; `a ->{r; e} b` для эффектного вызова |
| Единый стиль функций | Полная сигнатура непосредственно над каждой именованной функцией |
| Полиморфизм высших рангов у функций обратного вызова | Полиморфные параметры функций с явным вложенным `forall` |
| Числа JavaScript | `Number` и `BigInt` с соответствующей арифметикой JS; BigDecimal и другие специальные типы отдельно |
| Полноценный deriving Schema | Генерация схем для всех поддерживаемых форм данных, включая обобщённые и рекурсивные типы, с явными правилами и расширениями |
| Значения вычислений | `task { ... }` создаёт Eff; `await` исполняет его в текущем файбере; приложение запускается в точке входа |
| Статическая безопасность ресурсов | Значения, зависящие от области владения, и связанные задачи не могут выйти за её пределы; выбраны свежие регионы, транзитивные захваты и двухфазное закрытие |
| Доступ к экосистеме JS | Явные привязки и фиксированный ABI; генерация привязок из проверяемого подмножества `.d.ts` |
| Оптимизация | Применимые проходы оптимизации и приёмы ReScript с сохранением выбранной семантики Effect и Number |
| Интеграции Schema | Расширяемые компиляторы и экспортёры; если формат обмена не поддерживается, выдаётся явная диагностика |
| Проверка выразительности системы типов | SQL и типизированный UI eDSL как реальные задачи для строк, классов, функций обратного вызова и времени жизни |

Обобщённые `do`, `let*` и единый полиморфный по эффектам `map` не входят в первую версию. Блоки функций задаются отступами, специальные блоки `task`, `scope`, `sql`, `ui`, `cli` — фигурными скобками; последнее выражение возвращает результат. Имена `task` и `await`, а также явная точка входа зафиксированы.

Фронтенд Flick проверяет программу, единый бэкенд на Effect генерирует исполняемый JS/TS, а Content Mapper создаёт TS-проекцию и обеспечивает интеграцию с инструментами. Чистые вызовы и вызовы Effect проходят через один типизированный IR. Система типов Flick развивается независимо от выразительности TypeScript.
