**Рабочая спецификация Flick 0.7. 21 октября 2026. Решения для первой реализации.**

Цель — спроектировать функциональный язык **Flick** с ML-подобным синтаксисом, HKT, классами типов и единственным бэкендом на Effect. Стандартная библиотека и контракты среды выполнения опираются на Effect. Тот же бэкенд компилирует чистые участки в обычный JS/TS.

Прямые эффектные вызовы используют обычный `let`; `task` строит холодное вычисление `Eff`, а `await` выполняет его в текущем файбере. Полная сигнатура стоит над каждой именованной функцией. Для первой версии выбраны многопараметрические классы с функциональными зависимостями (MPTC/FD), полиморфизм высших рангов у функций обратного вызова, обобщение чистых построений, точные записи и `List` на основе массива JavaScript. Также выбраны свежие регионы и учёт захватов, явный FFI с импортёром `.d.ts`, полноценный `deriving Schema`, PostgreSQL eDSL, `ui { ... }` на основе React и `cli { ... }` на основе Effect CLI. Ниже зафиксированы эти контракты и ограничения выбранных решений. Это спецификация ещё не реализованного языка Flick; отметки о принятых решениях не обозначают готовность компилятора.

Документ можно комментировать и править по абзацам и примерам. Раздел «Что требуется решить до реализации» теперь содержит принятые ответы. Сравнения с альтернативами объясняют преимущества и ограничения решений; возможности, явно исключённые из первой версии, не мешают начать реализацию. Раздел «Критерии проверки реализации» сохраняет проверки, которые ещё предстоит пройти компилятору и среде выполнения.
