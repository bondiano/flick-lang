Этот указатель поможет найти точное правило, сигнатуру или контракт инструмента. Справочные страницы остаются по прежним адресам `/ru/reference/`; здесь они сгруппированы по задачам.

Flick — язык семейства ML, который компилируется в JavaScript и использует Effect. Типы языка, встроенные модули и адаптер времени выполнения связаны, но представляют разные уровни API. В частности, стрелка времени выполнения во Flick описывает сервисы и ожидаемые ошибки, а не сигнатуру JavaScript `Promise`.

Чтобы сначала поэкспериментировать, откройте [Play](/ru/play/) или сравните исходный код и сгенерированный JavaScript в [Transpile](/ru/transpile/). Для локального приложения начните с [первых шагов](../start/getting-started/).

## Среда выполнения и библиотеки

Встроенные модули — это интерфейсы Flick поверх адаптера времени выполнения и лежащего в его основе Effect. Они доступны через компилятор: устанавливать каждый модуль как отдельный пакет npm не нужно. Справочник адаптера определяет поведение освобождения ресурсов и конкурентного выполнения, а страницы библиотек описывают операции и специализированные конструкции.

| Справочник | Что искать |
| --- | --- |
| [Стандартная библиотека](../reference/stdlib/) | Prelude, коллекции, строки, числа, платформенные сервисы, расписания, тесты и генераторы. |
| [Адаптер времени выполнения](../reference/runtime/) | Закреплённая версия Effect, владельцы, финализаторы, файберы, параллелизм, причины сбоев, слои и коды завершения запускающей программы. |
| [Покрытие Effect](../reference/effect-surface/) | Классификация и предоставление API закреплённой версии Effect, включая явные исключения. Не следует считать, что любой API Effect доступен во Flick напрямую. |
| [Схемы и кодеки](../reference/schema/) | Уточнённые типы, вывод схем, валидация, кодеки внешнего представления и экспорт JSON Schema. |
| [Типизированные HTTP API](../reference/http-api/) | Описания конечных точек, кодеки запросов и ответов, обработчики, клиенты и документы API. |
| [SQL](../reference/sql/) | Объявления таблиц PostgreSQL, проверяемый синтаксис запросов, допустимость `NULL`, параметры и операции с базой данных. |
| [Пользовательские интерфейсы](../reference/ui/) | Синтаксис `ui`, отрисовка через React, свойства, события и контракты компонентов. |
| [Приложения командной строки](../reference/cli-dsl/) | Синтаксис `cli`, флаги, аргументы, подкоманды и обработчики. Это библиотека приложений, а не CLI компилятора. |

О понятиях и сильных сторонах базовой библиотеки — типизированных ошибках, структурированной конкурентности, безопасной работе с ресурсами, внедрении зависимостей и наблюдаемости — читайте в [официальной документации Effect](https://effect.website/docs/). Версию и доступный во Flick API определяют собственные справочники адаптера и покрытия Effect.
