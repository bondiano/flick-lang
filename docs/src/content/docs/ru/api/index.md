Здесь собраны правила языка, сигнатуры библиотечных функций и описание
инструментов. Выберите нужный раздел в таблицах ниже.

Flick компилируется в JavaScript и использует Effect. При чтении сигнатур
учитывайте различие языков: эффектная стрелка Flick описывает требуемые
сервисы и ожидаемые ошибки, а не возврат JavaScript `Promise`.

Чтобы попробовать язык без установки, откройте [Play](/ru/play/).
В [Transpile](/ru/transpile/) можно сравнить исходный код с результатом
компиляции. Локальный проект создайте по разделу
[Начало работы](../start/getting-started/).

## Среда выполнения и библиотеки

Встроенные модули Flick используют адаптер среды выполнения, построенный
на Effect. Компилятор уже знает их интерфейсы, поэтому устанавливать
каждый модуль отдельным npm-пакетом не нужно. Справочник адаптера
описывает выполнение задач и освобождение ресурсов. Остальные страницы
посвящены отдельным библиотекам и их синтаксису.

| Справочник | Что искать |
| --- | --- |
| [Стандартная библиотека](../reference/stdlib/) | Prelude, коллекции, строки, числа, платформенные сервисы, расписания, тесты и генераторы. |
| [Адаптер среды выполнения](../reference/runtime/) | Версия Effect, владельцы задач, финализаторы, файберы, параллельное выполнение, причины сбоев, слои и коды завершения приложения. |
| [Покрытие Effect](../reference/effect-surface/) | Какие API закреплённой версии Effect доступны во Flick, а какие исключены. Не любой API Effect можно вызвать напрямую. |
| [Схемы и кодеки](../reference/schema/) | Уточнённые типы, автоматическое создание схем, проверка данных, преобразование внешнего представления и экспорт JSON Schema. |
| [Типизированные HTTP API](../reference/http-api/) | Описания конечных точек, кодеки запросов и ответов, обработчики, клиенты и документы API. |
| [SQL](../reference/sql/) | Объявления таблиц PostgreSQL, проверяемый синтаксис запросов, допустимость `NULL`, параметры и операции с базой данных. |
| [Пользовательские интерфейсы](../reference/ui/) | Синтаксис `ui`, отрисовка через React, свойства, события и правила работы компонентов. |
| [Приложения командной строки](../reference/cli-dsl/) | Синтаксис `cli`, флаги, аргументы, подкоманды и обработчики. Это библиотека для ваших CLI-приложений, не команды компилятора. |

Типизированные ошибки, структурированная конкурентность, работа с
ресурсами, внедрение зависимостей и наблюдаемость описаны в
[официальной документации Effect](https://effect.website/docs/).
Поддерживаемую версию Effect и доступный во Flick API уточняйте
в справочниках адаптера и покрытия Effect.
