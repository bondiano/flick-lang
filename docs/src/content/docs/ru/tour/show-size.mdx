Упражнение главы. `size_name` возвращает размер числа текстом через `show`.
Но у `Size` нет экземпляра `Show`, поэтому компилятор сообщает
`FLICK-C001`.

Дайте `Size` этот экземпляр и нажмите **Проверить**.
