Упражнение главы. Функция `size_name` возвращает строковое представление
значения типа `Size`, соответствующего переданному числу. Для этого она
вызывает `show`. У `Size` нет экземпляра класса `Show`, поэтому компилятор
сообщает `FLICK-C001`.

Добавьте экземпляр класса `Show` для `Size` и нажмите **Проверить**.

</TourLesson>
