Кортеж содержит фиксированное число значений, каждое из которых имеет свой
тип. Значения записывают в круглых скобках: `("Ada", 36)` имеет тип
`(String, Int)`. Кортеж позволяет функции вернуть несколько результатов,
как в `min_max`.

Сопоставление с образцом `let (low, high) = …` связывает имена `low` и
`high` с элементами кортежа.

`List.minimum` возвращает `Option`, потому что у пустого списка нет
минимального элемента. В этом случае `Option.with_default 0` возвращает 0.
Типу `Option` посвящён отдельный урок далее в этой главе.

**Попробуйте:** напишите `let (low, high, mid) = …`. Компилятор сообщит
`FLICK-T003`: `min_max` возвращает пару, а не три значения.
