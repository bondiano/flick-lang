Кортеж хранит фиксированное число значений, у каждого свой тип, в круглых
скобках: `("Ada", 36)` имеет тип `(String, Int)`. Он подходит функции,
которая возвращает сразу два результата, как `min_max`.

Образец разбирает кортеж: `let (low, high) = …` даёт имена обеим частям.

`List.minimum` возвращает `Option`, потому что у пустого списка нет
минимума, а `Option.with_default 0` в этом случае берёт 0. Об `Option` будет
отдельный урок дальше в этой главе.

**Попробуйте:** напишите `let (low, high, mid) = …`. Компилятор сообщит
`FLICK-T003`: `min_max` возвращает пару, а не три значения.
