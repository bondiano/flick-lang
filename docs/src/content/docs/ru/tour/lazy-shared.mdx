**Где запускается:** браузер и локально.

Два одновременных ожидания используют одну ячейку, а не две копии тела.
Первая строка показывает один запуск. Прерывание не кешируется: таймаут
прерывает файбер-владелец `slow`, сбрасывая ячейку. Следующее ожидание
запускает тело снова после открытия барьера; вторая строка показывает две попытки.
Другие ожидающие файберы не наследуют прерывание владельца.

Lazy удерживает захваты и сохранённую ошибку, поэтому захваченный ресурс
не может выйти из своего региона. Это наблюдаемые гарантии, а не указания
полагаться на внутренние оптимизации ленивости.
