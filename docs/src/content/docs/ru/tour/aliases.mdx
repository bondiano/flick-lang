Объявление `type alias Point = { x : Int; y : Int }` задаёт типу краткое
имя. Оно не создаёт новый тип: любая запись с такими же полями и типами
полей имеет тип `Point`. Например, при объявлении `start` имя `Point`
не используется.

В сигнатуре `_` обозначает часть типа, которую должен определить компилятор.
Программа компилируется, но компилятор выдаёт предупреждение с найденным
типом. Автоматическое исправление заменяет `_` этим типом. Так можно
узнать тип выражения.

**Попробуйте:** напишите `move : Point -> Int -> _`. Компилятор выдаст
предупреждение `FLICK-T024`: `_` соответствует типу `{ x : Int; y : Int }`.
Примените исправление.
