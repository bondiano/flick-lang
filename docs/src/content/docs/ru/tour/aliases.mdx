`type alias Point = { x : Int; y : Int }` даёт типу короткое имя. Это
только имя: любая запись с такими полями — это `Point`, как показывает
`start`, записанный без него.

Сигнатура может оставить часть компилятору через `_`. Программа всё равно
компилируется, с предупреждением о том, что стоит на месте `_`, а
исправление этого предупреждения вписывает тип. Так быстро спрашивают тип у
компилятора.

**Попробуйте:** напишите `move : Point -> Int -> _`. Компилятор предупредит
кодом `FLICK-T024`, что `_` — это `{ x : Int; y : Int }`. Примените
исправление.
