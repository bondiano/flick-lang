`type alias Lookup = {Log, Store}` даёт имя набору сервисов. `...Lookup`
в строке эффектов добавляет весь набор, а отдельное имя — ещё один сервис:
`lookup` требует `Log`, `Store` и, поскольку журнал печатает,
`Host.Console`.

`quiet` выполняет любое вычисление `Eff r none a`, какая бы строка `r` ему
ни требовалась, и предоставляет ему `Log`. Её строка `{-Log | r}` — это `r`
без `Log`: вызывающий код должен предоставить всё, что нужно вычислению,
кроме журнала. Поэтому `main` предоставляет вокруг `quiet` только `Store`,
и для `"year"` в журнал ничего не пишется.

Полные правила, в том числе для ошибок, приведены в
[справочнике](../../reference/services/#наборы-сервисов-и-ошибок).

**Попробуйте:** оставьте в теле `quiet` только `await work`. Компилятор
сообщит `FLICK-E002`: вычисление может требовать `Log`, а строка `quiet`
его больше не допускает.
