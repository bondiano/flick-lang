Сервис описывает внешнюю зависимость функции: базу данных, журнал или
способ сформировать приветствие. Объявление `service Greeter =`
перечисляет операции сервиса. Сигнатура
`welcome : String ->{Greeter; none} String` указывает, что `welcome`
требует реализацию `Greeter`; `none` после `;` означает, что сигнатура не
допускает типизированных ошибок.

Запись `{ … }` содержит реализации операций сервиса. Вызов
`Layer.succeed Greeter { … }` создаёт слой с этой реализацией, а
`provide layer { … }` предоставляет её коду внутри блока. Одна и та же
функция `welcome` формирует вежливое или неформальное приветствие в
зависимости от реализации, которую предоставляет вызывающий код.

**Попробуйте:** добавьте третий слой с приветствием на другом языке и
предоставьте его через `provide`.
