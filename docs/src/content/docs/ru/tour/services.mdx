Сервис — это то, что нужно функции извне: база данных, журнал, способ
поздороваться. `service Greeter =` перечисляет его операции, а
`welcome : String ->{Greeter; none} String` говорит, что он нужен
`welcome`; `none` значит, что она ни с чем не падает.

`Layer.succeed Greeter { … }` строит реализацию из записи с операциями, а
`provide layer { … }` делает её доступной внутри блока. Одна и та же
`welcome` здоровается вежливо или запросто, в зависимости от того, что
даёт вызывающий.

**Попробуйте:** добавьте третий слой, который здоровается на другом языке,
и передайте его через `provide`.
