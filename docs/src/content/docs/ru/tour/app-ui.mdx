Интерфейс рядом с редактором использует тот же модуль `Books`.

Атом `shelf` содержит список книг. Компонент `reading_list` читает его
через `Atom.value`, отображает строку для каждой книги и количество
оставшихся страниц. Обработчик кнопки непрочитанной книги обновляет атом
через `Atom.update`, применяя к списку функцию `Books.finish`. После
обновления каждый экземпляр компонента, прочитавший этот атом, отображает
изменённые данные.

Функция `main` монтирует представление в элемент `#app`. Интерфейс работает
в изолированном фрейме, отдельно от страницы учебника.

**Попробуйте:** нажмите **finish** рядом с книгой, затем добавьте в атом
третью книгу и нажмите снова.
