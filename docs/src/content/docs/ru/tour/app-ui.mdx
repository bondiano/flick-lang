Тот же модуль `Books` теперь управляет интерфейсом, который показан
рядом с редактором.

`shelf` — атом: значение, за которым следит интерфейс. `reading_list` —
компонент, который читает его через `Atom.value` и показывает строку для
каждой книги и оставшиеся страницы. Кнопка непрочитанной книги обновляет
атом через `Books.finish`, и каждый компонент, который его читал,
показывает изменение.

`main` монтирует представление в элемент `#app` страницы. Интерфейс
работает в изолированном фрейме, отдельно от этой страницы.

**Попробуйте:** нажмите **finish** рядом с книгой, затем добавьте в атом
третью книгу и нажмите снова.
