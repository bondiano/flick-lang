Интерфейс рядом с редактором использует тот же модуль `Books`.

Атом `shelf` содержит список книг. Компонент `reading_list` читает его
через `Atom.value`, отображает строку для каждой книги и количество
оставшихся страниц. В его блоке `ui { … }` после `let` две строки — список
и абзац: это соседние узлы, без `fragment` вокруг. `let` после первого
потомка — `FLICK-T085`, исправление переносит его выше; `fragment` из
потомков в единственной строке блока — предупреждение `FLICK-T086`,
исправление записывает их строками. См. [ui](../../reference/ui/).

```flick fail T085
view : Ui
let view = ui {
  text "a"
  let b = "b"
  text b
}
```

Лишняя обёртка компилируется, но выдаёт `FLICK-T086`:

```flick fail T086
view : Ui
let view = ui {
  fragment
    heading (text "count")
    paragraph (text "one")
}
```

`flick check --fix --only T085,T086` применяет эти безопасные исправления.

Обработчик кнопки непрочитанной книги обновляет атом
через `Atom.update`, применяя к списку функцию `Books.finish`. После
обновления каждый экземпляр компонента, прочитавший этот атом, отображает
изменённые данные.

Функция `main` монтирует представление в элемент `#app`. Интерфейс работает
в изолированном фрейме, отдельно от страницы учебника.

**Попробуйте:** нажмите **finish** рядом с книгой, затем добавьте в атом
третью книгу и нажмите снова.
