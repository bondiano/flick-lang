Список хранит сколько угодно значений одного типа в квадратных скобках.

`[for n <- numbers; if n > 2 yield n * 10]` строит список: для каждого `n`
больше 2 — `n * 10`.

`++` соединяет два списка, а остальное есть в модуле `List`: `List.sort`;
`List.zip`, который составляет пары из двух списков до конца более
короткого; `List.fold_left`, который ведёт накопленный итог от начального
значения.

**Попробуйте:** добавьте в список `"three"`. Компилятор сообщит
`FLICK-T003`: все элементы списка одного типа.
