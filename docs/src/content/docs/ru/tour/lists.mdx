Список содержит произвольное число значений одного типа. Его элементы
записывают в квадратных скобках.

Выражение `[for n <- numbers; if n > 2 yield n * 10]` создаёт список
значений `n * 10` для всех элементов `numbers`, которые больше 2.

Оператор `++` соединяет два списка. В модуле `List` есть и другие
операции: `List.sort` сортирует список; `List.zip` составляет пары из
элементов двух списков до конца более короткого; `List.fold_left`
последовательно накапливает результат, начиная с заданного значения.

**Попробуйте:** добавьте в список `"three"`. Компилятор сообщит
`FLICK-T003`: все элементы списка должны иметь один тип.
