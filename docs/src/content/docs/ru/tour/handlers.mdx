Эффект, как и сервис, объявляет операции. Их поведение задаёт вызывающий
код с помощью обработчика. Объявление `effect Ask =` задаёт эффект с
операцией, которую `total` вызывает дважды. В `try total () with` ветка
`| Ask.ask "apples" -> 3` возвращает 3 для запроса о яблоках, а
`| Ask.ask _ -> 4` — 4 для остальных запросов. Второй обработчик
возвращает 0 при любом вызове этой операции.

Одна и та же функция может выполняться с разными обработчиками. Это
удобно для тестов и интерпретаторов. С помощью операций `abort` и
`control` обработчик также может остановить выполнение оставшейся части
вычисления или продолжить его. Сейчас `control` компилируется только в
Go, поэтому в этом туре он не используется.

**Попробуйте:** удалите ветку `| Ask.ask _ -> 4`. Компилятор сообщит
`FLICK-E002`: вызов `Ask.ask` для груш не обработан, поэтому требование
эффекта `Ask` остаётся, но не разрешено сигнатурой `main`.
