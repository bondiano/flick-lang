**Где запускается:** браузер и локально.

`Config.Config` описывает читаемые значения и их значения по умолчанию;
пока он ничего не читает. `Config.get` читает его через `Host.Environment`,
если не предоставлен `ConfigProvider`. `describe` выполняется трижды: с живым
окружением без этих переменных, поэтому действуют значения по умолчанию;
с фейковым окружением; и с портом вне диапазона, что даёт `ConfigError`.
Префикс `SHOP_` не даёт настоящей переменной `PORT` изменить вывод.
