**Где запускается:** браузер и локально.

`stamp` указывает в строке эффектов только `Host.Clock` и `Host.Random`.
`main` вызывает её дважды: с живыми сервисами, которые среда выполнения даёт
`main`, и внутри `provide` — с фиксированными часами и фиксированной выборкой.
Функция одна и та же, меняется только слой вокруг неё. Тесты подменяют
сервисы хоста так же (см. главу [«Тестирование»](../fakes/)).

**Попробуйте:** верните 0.5 из `fixed_random`: последнее поле строки fake
станет `false`.
