Эта программа намеренно содержит ошибку компиляции. `match` должен
обрабатывать все возможные значения, но в функции `label` нет ветки для
`Paused`. Компилятор сообщает `FLICK-T009` и указывает пропущенный случай.
При добавлении нового конструктора в тип компилятор указывает на все
выражения `match`, в которых не хватает его обработки.

Пока ошибка не исправлена, программа не запускается.

**Попробуйте:** примените в редакторе исправление этой ошибки. Оно добавит
ветку `| Paused -> todo`, и программа скомпилируется с предупреждением
`FLICK-T022`: выполнение `todo` завершается ошибкой. Замените `todo` на
`"paused"`.
