Теперь упражнение. Функция рядом с этим текстом расходится со своей
сигнатурой, и компилятор показывает где.

Исправьте её и нажмите **Проверить**. Ответ сохраняется в этом браузере.
Кнопка **Показать решение** вставляет готовый код, но не отмечает упражнение
выполненным: для этого нажмите **Проверить**.
