Функция в редакторе возвращает значение не того типа, который указан в
сигнатуре. Компилятор указывает место ошибки.

Исправьте тип результата и нажмите **Проверить**. Ответ сохраняется в этом браузере.
Кнопка **Показать решение** вставляет готовый код, но не отмечает упражнение
выполненным: для этого нажмите **Проверить**.

</TourLesson>
