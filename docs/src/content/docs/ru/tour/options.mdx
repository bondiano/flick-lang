Во Flick нет `null`. Тип `Option` представляет значение, которое может
отсутствовать: `Some value` или `None`. Тип `Result` представляет успешный
результат `Ok value` или ошибку `Err problem`.

`Int.parse` возвращает `Option Int`, а функция `age` преобразует его в
`Result`: возвращает число или сообщение об ошибке. Выражение `match`
сопоставляет результат разбора с образцами `Some` и `None`, а условие
`when n >= 0` ограничивает первую ветку неотрицательными числами.

Для пустого списка `List.head` возвращает `None`, а не ошибку выполнения.

**Попробуйте:** напечатайте `Int.parse "36" + 1`. Компилятор сообщит
`FLICK-T003`: сложение требует `Int`, но `Int.parse` возвращает
`Option Int`. Извлеките число с помощью `match` или `Option.with_default`.
