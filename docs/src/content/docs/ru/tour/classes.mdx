Класс типов объявляет набор операций, а экземпляр класса определяет их
реализацию для конкретного типа. Класс `Describe` объявляет одну функцию —
`describe`. Объявление `instance Describe Weather` реализует её для
`Weather`.

Второй экземпляр реализует `Describe` для `List a`, если для `a` есть
экземпляр этого класса. Условие `Describe a =>` задаёт это требование.
Поэтому вызов `describe [Sun, Rain, Sun]` использует оба экземпляра.

**Попробуйте:** вызовите `describe 3`. Компилятор сообщит `FLICK-C001`:
экземпляр класса `Describe` для `Int` отсутствует. В сообщении также
перечислены доступные экземпляры.
