Класс называет то, что умеет тип, а экземпляр говорит, как это делает
конкретный тип. В `Describe` одна функция, `describe`, а
`instance Describe Weather` даёт её для `Weather`.

Второй экземпляр работает для списка любых `a`, которые сами умеют
описываться: `Describe a =>` и есть это условие. Поэтому
`describe [Sun, Rain, Sun]` использует оба экземпляра.

**Попробуйте:** вызовите `describe 3`. Компилятор сообщит `FLICK-C001`:
`Describe Int` нет, и он перечислит, какие экземпляры есть.
