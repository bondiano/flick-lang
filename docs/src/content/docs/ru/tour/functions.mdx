У функции две строки: сигнатура, затем `let`. В
`hypotenuse_squared : Int -> Int -> Int` каждый тип перед стрелкой — это
аргумент, а последний — результат.

Аргументы пишутся после имени через пробел, без скобок и запятых, и в
определении, и при вызове: `square a`. Скобки только группируют:
`show (hypotenuse_squared 3 4)`.

У функции на верхнем уровне модуля всегда есть сигнатура. Это контракт, на
который полагается остальная программа.

**Попробуйте:** удалите строку `square : Int -> Int`. Компилятор потребует её
кодом `FLICK-T004`.
