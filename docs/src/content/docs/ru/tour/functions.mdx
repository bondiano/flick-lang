Для объявления функции указывают сигнатуру, а затем определение с `let`.
В сигнатуре `hypotenuse_squared : Int -> Int -> Int` типы перед стрелками —
типы аргументов, а последний тип — тип результата.

В определении параметры записываются после имени функции через пробел.
При вызове так же передают аргументы, без скобок и запятых: `square a`.
Скобки группируют выражения: `show (hypotenuse_squared 3 4)`.

Каждая функция верхнего уровня модуля должна иметь сигнатуру. Сигнатура
задаёт контракт функции для остальной программы.

**Попробуйте:** удалите строку `square : Int -> Int`. Компилятор сообщит
`FLICK-T004`: отсутствует обязательная сигнатура.
