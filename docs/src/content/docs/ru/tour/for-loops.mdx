<TourLesson locale="ru" id="for-loops">

`for x <- list do …` выполняет тело по разу для каждого элемента. Вместе с
`let mut` он прямо описывает алгоритм в один проход: `max_profit` хранит
самую низкую цену и лучшую прибыль на данный момент.

`match` перед циклом разбирает список: на пустом списке сделки нет, а
первая цена начинает поиск.

`if` без `else` здесь уместен: его ветка — присваивание, а оно имеет тип
`Unit`.

**Попробуйте:** измените цены в первом списке или добавьте ещё один список
цен.
