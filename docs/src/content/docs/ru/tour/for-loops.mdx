`for x <- list do …` выполняет тело один раз для каждого элемента списка.
Вместе с `let mut` эта конструкция позволяет записать алгоритм за один
проход. В функции `max_profit` переменные хранят самую низкую цену среди
уже просмотренных и наибольшую найденную прибыль.

Выражение `match` перед циклом сопоставляет список с образцами. Для пустого
списка функция возвращает 0. Иначе первая цена задаёт начальное значение
для поиска минимальной цены.

Здесь допустим `if` без `else`: в его ветке выполняется присваивание,
результат которого имеет тип `Unit`.

**Попробуйте:** измените цены в первом списке или добавьте ещё один список
цен.
