<TourLesson locale="ru" id="generics">

Тип может принимать другой тип как параметр. `Tree a` — дерево значений
некоторого типа `a`: `Tree Int`, `Tree String` и так далее.

Функция, работающая с таким типом, тоже может быть обобщённой.
`to_list : Tree a -> List a` работает для любого `a`, а `size` подсчитывает
элементы независимо от их типа.

Конкретный тип `a` внутри обобщённой функции неизвестен. Функция может
передавать значения этого типа, но без дополнительных ограничений не может,
например, применять к ним `+`.

**Попробуйте:** напишите `[value + 1]` в `to_list`. Компилятор сообщит
`FLICK-C001`: для типа `a` не задано требование, позволяющее использовать
`+`. Как указать это требование, показано в уроке об ограничениях.
