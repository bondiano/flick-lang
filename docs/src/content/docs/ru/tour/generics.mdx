<TourLesson locale="ru" id="generics">

Тип может принимать другой тип как параметр. `Tree a` — дерево значений
некоторого типа `a`: `Tree Int`, `Tree String` и так далее.

Функция над ним тоже может быть обобщённой. `to_list : Tree a -> List a`
работает для любого `a`, а `size` неважно, что лежит в дереве.

Внутри обобщённой функции об `a` ничего не известно, поэтому его значения
можно только перекладывать.

**Попробуйте:** напишите `[value + 1]` в `to_list`. Компилятор сообщит
`FLICK-C001`: он не может знать, что у `a` есть `+`. Как попросить об этом,
показывает урок об ограничениях.
