Перед вами программа на Flick. Прочитайте её сверху вниз.

- `module Main exposing (main)` объявляет модуль `Main` и экспортирует функцию
  `main`. С неё начинается выполнение программы.
- `type alias Bird = { name : String; seen : Int }` задаёт псевдоним для типа
  записи — значения с именованными полями.
- `total : List Bird -> Int` — это **сигнатура**: функция `total` принимает
  список значений типа `Bird` и возвращает `Int`. Следующая строка с `let`
  начинает определение функции. `total` извлекает поле `seen` из каждой
  записи и суммирует значения.
- Функция `describe` подставляет значения в строку с помощью `\{…}`.
- `main : Unit ->{} Unit` принимает и возвращает `()`, единственное значение
  типа `Unit`. Фигурные скобки после стрелки обозначают функцию с эффектами:
  здесь `main` выводит текст. Обычная стрелка в сигнатуре `total` обозначает
  чистую функцию, которая только вычисляет результат.

В следующих уроках эти части программы разбираются по отдельности.

**Попробуйте:** добавьте в список `{ name = "owl"; seen = 2 }`. Вывод
изменится после завершения ввода.
