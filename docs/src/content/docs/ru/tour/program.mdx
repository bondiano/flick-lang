Перед вами целая программа на Flick. Прочитайте её сверху.

- `module Main exposing (main)` называет модуль и то единственное, чем могут
  пользоваться другие. Программа начинается с `main`.
- `type alias Bird = { name : String; seen : Int }` даёт имя типу записи:
  значению с именованными полями.
- `total : List Bird -> Int` — это **сигнатура**: `total` принимает список птиц
  и возвращает `Int`. `let` под ней — определение. Оно берёт `seen` каждой
  птицы и складывает их.
- `describe` подставляет значения в строку через `\{…}`.
- `main : Unit ->{} Unit` ничего не принимает и ничего не возвращает. Фигурные
  скобки после стрелки отмечают функцию, которая что-то делает при
  выполнении: здесь она печатает. Обычная стрелка, как у `total`, только
  вычисляет результат.

Следующие уроки разбирают эти части по одной.

**Попробуйте:** добавьте в список `{ name = "owl"; seen = 2 }`. Вывод
изменится, как только вы перестанете печатать.
