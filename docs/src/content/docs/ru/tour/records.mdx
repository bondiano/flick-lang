Запись содержит именованные поля. `type alias Book = { … }` задаёт имя
для типа записи. При создании записи значения полей указывают через `=`.
Выражение `book.title` возвращает значение поля `title`.

Записи неизменяемы. `{ book with read = true }` создаёт копию записи
`book`, в которой значение поля `read` заменено на `true`.

Выражение `[for b <- shelf; if not b.read yield b.pages]` строит список
чисел страниц для всех ещё не прочитанных книг на полке. Спискам посвящён
отдельный урок далее в этой главе.

**Попробуйте:** напишите `{ book with red = true }`. Компилятор сообщит
`FLICK-T003`: у `Book` нет поля `red`, а `with` заменяет только
существующие поля.
