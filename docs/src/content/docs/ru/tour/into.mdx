`into` преобразует значение в целевой тип, определяемый контекстом.
В `half` делитель `2.0` имеет тип `Float`, поэтому `into n` преобразует
`n` из `Int` в `Float` без потери значения.

Преобразования между собственными типами задаются экземплярами класса
`Into`. Объявление `instance Into Celsius Fahrenheit` определяет такое
преобразование. Функция `degrees` принимает `Fahrenheit`, поэтому в вызове
`degrees (into (Celsius 100.0))` целевой тип преобразования — `Fahrenheit`.

Тип, объявленный через `unboxed type`, имеет один конструктор и не создаёт
дополнительной обёртки во время выполнения. При этом само преобразование
может требовать вычислений: в примере оно рассчитывает температуру
по формуле.

**Попробуйте:** напишите в `main` `let x = into 3` и напечатайте `x`.
Компилятор сообщит `FLICK-C002`: контекст не определяет целевой тип `x`.
