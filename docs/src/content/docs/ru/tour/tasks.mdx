Конструкция `task { … }` создаёт задачу — отложенное вычисление. При
создании задачи её тело не выполняется. При запуске `counted` увеличивает
значение `runs` на 1 и возвращает новое значение. Строка `before: 0`
показывает, что создание задачи не изменило `runs`.

Оператор `await` запускает задачу и возвращает её результат. Каждый
`await` выполняет задачу заново, поэтому два полученных результата
различаются.

Вызов `Ref.make` создаёт ячейку с изменяемым значением. Переменная
`let mut` из первой главы локальна для одной функции, а ячейку `Ref`
можно использовать совместно. В этом примере к ней обращаются основной
код и задача.

**Попробуйте:** уберите первый `await`. Компилятор сообщит `FLICK-C001`:
для задачи нет экземпляра класса `Show`. Оператор `await` возвращает
результат задачи, который в этом примере можно преобразовать в строку.
