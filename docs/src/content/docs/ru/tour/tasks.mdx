`task { … }` описывает работу, но не выполняет её: задача холодная.
`counted` прибавляет 1 к `runs` и возвращает результат, но `before: 0`
показывает, что при создании ничего не выполнилось.

`await` выполняет задачу и даёт её результат, и каждый `await` выполняет её
заново, поэтому два результата разные.

`Ref.make` создаёт ячейку с изменяемым значением. `let mut` из первой главы
принадлежит одной функции, а `Ref` можно разделить, здесь — с задачей.

**Попробуйте:** уберите первый `await`. Компилятор сообщит `FLICK-C001`:
задачу нельзя показать как значение, а превращает её в результат именно
`await`.
