`task { … }` — холодное вычисление: создание `counted` ничего не меняет.
Каждый `await` запускает его снова, поэтому первые чтения дают 1 и 2.

`~` у `twice` означает, что аргумент `Eff` передаётся незапущенным.
`twice (count runs)` не требует обёртки `task`: каждый `await` запускает его,
получая 3 и 4, в сумме 7. `Effect.or_die (count runs)` работает так же.
Конвейер по-прежнему сначала вычисляет левую часть.
См. [отложенные параметры](../../reference/effects/#task-и-await).

```flick fail T076
wrong : ~Int -> Int
let wrong n = n
```

**Попробуйте:** снова выполните `await counted`, затем сравните с [lazy](../lazy/).
