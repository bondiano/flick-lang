Ограничение позволяет обобщённой функции пользоваться классом.
`square : Numeric a => a -> a` работает для любого числового типа, поэтому
одна функция возводит в квадрат и `Int`, и `Float`. `mean` делит, поэтому
требует `Floating`.

Классы и функции других модулей подключаются через `import`:
`import Numeric exposing (Floating, Numeric)`.

**Попробуйте:** уберите `Numeric a =>` у `square`. Компилятор сообщит
`FLICK-C001`: он не может вывести `Numeric a`.
