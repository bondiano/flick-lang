Ограничение в сигнатуре требует наличия экземпляра класса типов. Оно
позволяет обобщённой функции использовать операции этого класса.
`square : Numeric a => a -> a` работает для любого `a`, у которого есть
экземпляр класса `Numeric`. Одна функция возводит в квадрат значения и
типа `Int`, и типа `Float`. Функция `mean` использует деление, поэтому
требует экземпляр класса `Floating`.

Классы типов и функции из других модулей подключаются через `import`:
`import Numeric exposing (Floating, Numeric)`.

**Попробуйте:** уберите `Numeric a =>` у `square`. Компилятор сообщит
`FLICK-C001`: для умножения значений типа `a` требуется экземпляр класса
`Numeric`.
