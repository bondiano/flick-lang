<TourLesson locale="ru" id="scope-type">

`Scope s` означает, что `open_res` получает ресурс в области вызывающего.
`Resource.make` регистрирует освобождение там же.
`Fiber.Provided {Host.Console} s` гарантирует, что консоль для освобождения
живёт дольше области.

Здесь ресурс — строка без региона. Дескрипторы, захватывающие ресурсы,
несут `^{s}` и не могут выйти наружу. См. [ресурсы](../../reference/resources/).

**Попробуйте:** вызовите `both ()` без `scope`: `FLICK-G004` сообщит об отсутствии владельца.
