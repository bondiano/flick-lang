Вызову `open_res` нужна область владения ресурсами. Это требование указано
в сигнатуре: `open_res : String ->{Scope s} String`. Здесь `s` обозначает
регион этой области.

Функция `both` также требует `Scope s`, поскольку вызывает `open_res`.
В `main` блок `scope { … }` создаёт область владения: после завершения
`both ()` оба ресурса освобождаются.

Так сигнатура позволяет определить, что вызывающий код должен
предоставить область владения ресурсами.

**Попробуйте:** вызовите `both ()` в `main` без `scope { … }`. Компилятор
сообщит `FLICK-G004`: для вызова нет области владения ресурсами.
