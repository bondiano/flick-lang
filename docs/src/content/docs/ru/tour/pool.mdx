**Где запускается:** браузер и локально.

`Pool.make` получает элементы по требованию, здесь не больше одного, и пул
принадлежит внешнему `scope`. `Pool.use` одалживает элемент на один вызов
функции. После успеха или типизированной ошибки элемент возвращается в пул,
поэтому вторая аренда снова получает элемент 1. После дефекта или прерывания
элемент может быть сломан: пул освобождает его и получает элемент 2.

`Effect.exit` превращает дефект в значение, поэтому `main` продолжает работу.

[Справочник](../../reference/resources/#пулы-транзакции-и-серверы).
