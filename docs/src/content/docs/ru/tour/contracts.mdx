`type module Text =` — это контракт: какие имена модуль должен
экспортировать и каких они типов. `module Loud(T : Text) : Banner =` —
параметризованный модуль. Он принимает любой модуль, который выполняет
контракт `Text`, и строит модуль, выполняющий `Banner`. Объявление
`module Shout = Loud(String)` применяет его во время компиляции.

`String` выполняет контракт `Text`: он экспортирует `length` и `to_upper`
нужных типов, а также другие функции, которых `Loud` не видит. В проекте
аргументом обычно служит модуль из отдельного файла. Вложенный модуль
доступен только в своём файле, поэтому в этом примере из одного файла
передаётся `String`.

Контракт может описывать и параметризованный модуль: `Style` описывает
модуль, который строит `Banner` из `Text`. `Framed` принимает такой модуль
и сам его применяет, поэтому `Framed(Loud)` обрамляет результат `Loud`.

Полные правила и примеры из нескольких файлов приведены в
[справочнике](../../reference/modules/#контракты-модулей-и-параметризованные-модули).

**Попробуйте:** добавьте `module Plain(T : Text) : Banner`, в котором
`banner` возвращает слово без изменений, затем `module Bare = Framed(Plain)`,
и напечатайте `Bare.banner "flick"`.
