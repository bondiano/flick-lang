**Где запускается:** браузер и локально.

Модуль `Ports` скрывает создание, но не инвариант. Исходное значение
`Port` положительно, поэтому `Positive.prove` не требует нового условия.
В проекте инвариант также проходит через `.iface`, псевдонимы и реэкспорт;
его изменение перепроверяет потребителей.

**Гарантия:** проверяющий может использовать объявленный инвариант уточнённого
значения через границу модуля, но не произвольное утверждение foreign-кода.

[Справочник](../../reference/schema/#доказательство-уточнения).
