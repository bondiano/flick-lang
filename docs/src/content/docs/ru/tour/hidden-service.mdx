Программа намеренно содержит ошибку компиляции. Функция `report` вызывает
`Log.info`, но в её строке эффектов `->{}` сервис `Log` не указан.
Компилятор сообщает `FLICK-E002` и предлагает добавить `Log` в сигнатуру.

Это пример правила из начала тура: сигнатура указывает, какие сервисы
необходимы функции. После исправления из сигнатуры `report` видно, что
функция требует реализацию сервиса журнала `Log`. Чтобы определить эту
зависимость, не нужно читать тело функции.

**Попробуйте:** примените предложенное исправление, и программа запустится.
