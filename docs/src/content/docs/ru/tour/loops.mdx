Иногда лучше всего подходит цикл. `let mut` создаёт переменную,
`name = value` меняет её, а `while condition do …` повторяет, пока условие
верно. Несколько строк после `do` пишутся в фигурных скобках.

Переменные принадлежат функции, которая их создала. Сигнатура `digits` —
по-прежнему `Int -> Int`: снаружи никто не видит, как они меняются.

**Попробуйте:** уберите `mut` у `count`. Компилятор сообщит `FLICK-T069`:
обычному `let` нельзя присваивать.
