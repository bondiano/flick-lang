`let mut` создаёт изменяемую переменную. Присваивание `name = value` меняет её
значение. Цикл `while condition do …` повторяет выполнение тела, пока условие
истинно. Несколько строк после `do` заключаются в фигурные скобки.

Переменные `left` и `count` локальны для `digits`. Их изменения не видны за
пределами функции, и её сигнатура остаётся `Int -> Int`.

**Попробуйте:** уберите `mut` у `count`. Компилятор сообщит `FLICK-T069`:
повторное присваивание имени, объявленному без `mut`, запрещено.
