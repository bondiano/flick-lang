`Int` — целочисленный тип, `Float` — тип чисел с плавающей точкой.
Арифметические операторы требуют операндов одного типа. Для преобразования
`Int` в `Float` явно вызовите `Int.to_float`.

Тип целочисленного литерала может определяться контекстом: в `3 + 0.5`
литерал `3` имеет тип `Float`. Это не преобразование значения, уже имеющего
тип `Int`.

Для `Int` операция `/` выполняет деление с усечением дробной части к нулю,
а `%` возвращает остаток от деления. `Int` хранит 32-битные знаковые целые
числа. В последней строке `add 2147483647 1` прибавляет единицу к наибольшему
значению и при переполнении возвращает наименьшее: `-2147483648`.

**Попробуйте:** вызовите `add 1 2.5`. Компилятор сообщит `FLICK-T003`:
ожидается `Int`, но передан `Float`.
