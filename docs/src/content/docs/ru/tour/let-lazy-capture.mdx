**Где запускается:** проверяется в редакторе, ожидается ошибка.

Замыкание, как и `task`, не может использовать `let lazy` другого
кадра функции: `FLICK-G005`. Это ограничение позволяет локальную ленивость
без общей ячейки и `Async`.

**Попробуйте:** оставьте оба ожидания внутри функции или используйте
`lazy { 42 }` для общего значения и добавьте `Async` ожидающей функции.

[Справочник](../../reference/effects/#lazy).
