`deriving` просит компилятор написать для типа экземпляры распространённых
классов: `Eq` для `==`, `Ord` для порядка, `Show` для `show`.

Выведенный `Ord` сравнивает сначала по порядку форм, затем по значениям
внутри: черви идут раньше пик, а две карты червей сравниваются по номеру.
`List.sort` нужен `Ord`, а `compare` возвращает `LT`, `EQ` или `GT`.

**Попробуйте:** уберите `Ord` у `Card`. Компилятор сообщит `FLICK-C001` у
`List.sort`: экземпляра `Ord Card` нет.
