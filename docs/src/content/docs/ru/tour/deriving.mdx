<TourLesson locale="ru" id="deriving">

`deriving` задаёт автоматическое построение экземпляров распространённых
классов типов: `Eq` для `==`, `Ord` для порядка, `Show` для `show`.

Автоматически построенный экземпляр `Ord` сравнивает значения по порядку
объявления конструкторов, а при одинаковых конструкторах — по значениям
полей. Поэтому карты червей располагаются перед картами пик, а две карты
червей сравниваются по номеру. `List.sort` и операторы сравнения порядка,
например `<`, требуют экземпляр `Ord Card`.

**Попробуйте:** уберите `Ord` у `Card`. Компилятор сообщит `FLICK-C001` у
`List.sort`: экземпляр `Ord Card` отсутствует.
