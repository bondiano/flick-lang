Тур знакомит с Flick по одной теме за раз. В каждом уроке рядом с коротким
объяснением приведена программа. Компилятор Flick проверяет её во время ввода,
а после паузы во вводе программа запускается. Изменяйте программу, намеренно
вносите ошибки и изучайте сообщения компилятора.

Каждая следующая глава опирается на предыдущие. В конце каждой главы —
упражнение с проверкой решения. Ваши правки сохраняются в этом браузере.
Чтобы установить Flick и работать над собственным проектом, откройте
раздел [Начало работы](../start/getting-started/). Чтобы прочитать тур целиком,
откройте [весь тур на одной странице](./all/).
