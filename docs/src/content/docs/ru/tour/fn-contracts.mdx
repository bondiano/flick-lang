**Где запускается:** браузер и локально.

`require` описывает входы; `ensure` принимает результат. Выражения
проверяются по типам относительно готовой сигнатуры, но сегодня ни одно
не понижается и не выполняется. Второй вызов нарушает требование и всё
равно возвращает -3, как написано в теле.

Для контроля используйте уточнённый вход, проверку при выполнении или
поддерживаемое доказательство. [Контракт модуля](../contracts/) проверяет экспорты.

**Гарантия:** контракты функций сегодня — описания с проверенными типами,
а не доказанные предусловия/постусловия и не проверки выполнения.
