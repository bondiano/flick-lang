В последней главе из частей тура собирается одно небольшое приложение —
список чтения. Оно начинается там, где стоит начинать программу: с данных
и чистых функций.

Вложенный модуль `Books` содержит тип `Book` и то, что может происходить
со списком книг: добавить книгу, закончить её, посчитать оставшиеся
страницы, описать книгу одной строкой. Ничего из этого не выполняется,
поэтому всё легко читать и проверять.

`main` соединяет шаги через `|>` и печатает результат.

**Попробуйте:** добавьте третью книгу и закончите её.
