При сопоставлении с образцом можно проверять не только конструктор.
Функция `describe` использует образцы для списков:

- `[]` соответствует пустому списку, а `[only]` — списку из одного
  элемента.
- `[0, ..._] | [1, ..._]` объединяет два альтернативных образца: достаточно
  совпадения с одним из них. `..._` обозначает остаток списка, который
  не используется.
- `when` добавляет условие к ветке, а `...rest` связывает имя `rest` с
  остатком списка.

Ветки проверяются сверху вниз. Выполняется первая подходящая ветка.

**Попробуйте:** удалите последнюю ветку. Компилятор сообщит `FLICK-T009` и
покажет список, которому не соответствует ни одна ветка. Ветка с `when`
не обеспечивает полноту сопоставления: её условие может оказаться ложным.
