Образцы умеют больше, чем назвать форму. В `describe`:

- `[]` — пустой список, а `[only]` — список из одного элемента.
- `[0, ..._] | [1, ..._]`: `|` между образцами подходит под любой из них, а
  `..._` — остаток списка, который не нужен.
- `when` добавляет к ветке условие, а `...rest` даёт имя остатку.

Ветки проверяются сверху вниз, и выигрывает первая подходящая.

**Попробуйте:** удалите последнюю ветку. Компилятор сообщит `FLICK-T009` и
покажет список, который не покрывает ни одна ветка: ветка с `when` может не
сработать, поэтому не считается.
