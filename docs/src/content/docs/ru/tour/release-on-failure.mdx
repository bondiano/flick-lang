<TourLesson locale="ru" id="release-on-failure">

`Resource.own` передаёт области исключительное владение значением с
экземпляром `Close`. `close_exit` фиксирует транзакцию при успехе и откатывает
её иначе. `Resource.make` и `Scope.defer` тоже получают `Exit`.

`check (-3)` завершается ошибкой. Освобождение идёт в обратном порядке:
flush, close, rollback, затем обработчик выводит `handled -3`.
Каждое действие выполняется ровно один раз.
См. [владение и результат](../../reference/resources/).

**Попробуйте:** вызовите `check 3`. Освобождение сообщит об успехе и зафиксирует транзакцию.
