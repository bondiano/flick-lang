<TourLesson locale="ru" id="release-on-failure">

Область владения ресурсами закрывает ресурсы независимо от способа
завершения. В этом примере вызов `check (-3)` завершается ошибкой `Invalid`
внутри `scope`. Сначала закрывается файл, затем ошибка передаётся
обработчику. После обработки программа выводит `handled -3`.

Для освобождения ресурса не нужно отдельно писать `finally`: область
владения выполняет очистку и при ошибке.

**Попробуйте:** замените `check (-3)` на `check 3`. Область владения
завершится успешно, а файл всё равно закроется.
