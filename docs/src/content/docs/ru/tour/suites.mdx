**Где запускается:** локально: модуль в `test/Main.fl` проекта, затем `flick test` (для компаньонов путь указан ниже). CI проверяет отчёт.

Набор группирует тесты; каждый случай получает свою область и живые сервисы
хоста. `.skip` никогда не выполняет тело. `.only` оставляет только отмеченные
случаи выбранных файлов; пропущенный случай остаётся пропущенным. Здесь выполняется
только `focus`.

`flick test --list` выводит `Main > names > focus`, ничего не запуская.
`flick test --forbid-only` завершается с кодом 1 из-за намеренного фокуса.
CI проверяет оба поведения. Уберите `.only` перед коммитом настоящих тестов.

Playground сейчас запускает `main`, а не `tests` модуля, и не имеет отчёта
`--list`. Эти уроки локальны: успешная компиляция не выдаётся за успешные тесты.

[Справочник](../../reference/testing/#полные-имена-skip-и-only).
