**Где запускается:** браузер и локально.

`let lazy` принадлежит своей функции, как `let mut`, и не требует `Async`.
Читать его можно только через `await name`. Присваивание до первого чтения
`let lazy mut` заменяет инициализатор, поэтому `counted runs 7` не выполняется.
Использование без `await name` — `FLICK-T003`.

**Попробуйте:** уберите чтения `answer`; ни один инициализатор не запустится.
