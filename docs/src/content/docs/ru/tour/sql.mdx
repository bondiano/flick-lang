**Где запускается:** локально, без базы данных: поместите модуль в `src/Main.fl`
и выполните `flick run src/Main.fl`. CI проверяет SQL и число параметров на JS
и Go. На JS модулю `Sql` нужен `@flick-lang/effect-ts` в зависимостях проекта
(`pnpm add @flick-lang/effect-ts`); песочница браузера его не предоставляет.

`sql table` объявляет таблицу и тип её строк; запрос `sql p { … }`
проверяется по ней при компиляции: несуществующий столбец или сравнение
`p.min` с текстом — ошибка типов. Построение и связывание запроса не делают
ввода-вывода, поэтому урок печатает SQL и его единственный параметр без базы
данных. Значение `p.min` никогда не подставляется в текст.
В настоящей программе `Database.query` выполняет связанный запрос в PostgreSQL.
