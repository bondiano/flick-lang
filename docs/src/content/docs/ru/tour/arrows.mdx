Сигнатуры различают два вида функций. У `double : Int -> Int` обычная
стрелка: функция чистая, она только вычисляет результат из аргументов, и
одни и те же аргументы всегда дают один и тот же результат.

У `announce : Int ->{} Unit` после стрелки фигурные скобки: функция
выполняется, а при выполнении может что-то делать, например печатать. В
скобках до `;` перечисляется, что ей нужно, а после — как она может
упасть, например `->{Users, Log; NotFound}`. Пустым скобкам ничего не
нужно. Чистая функция не может вызывать выполняемую.

Пока есть одно ограничение: вызовы хоста, такие как `Platform.stdout_line`
или часы, имеют тип `->{}` и в скобках не называются. Где обещание
заканчивается, сказано в разделе [Почему Flick](../../start/why/#ограничения).

**Попробуйте:** пусть `double` печатает строку перед тем, как вернуть
результат. Компилятор сообщит `FLICK-E001`: `double` чистая.
