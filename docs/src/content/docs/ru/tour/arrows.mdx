Сигнатуры различают два вида функций. У `double : Int -> Int` обычная
стрелка: функция чистая, она только вычисляет результат из аргументов, и
одни и те же аргументы всегда дают один и тот же результат.

У `announce : Int ->{} Unit` после стрелки указана строка эффектов в
фигурных скобках. Такая функция может выполнять побочные эффекты, например
выводить текст. До `;` перечисляются необходимые сервисы, а после —
возможные типизированные ошибки, как в `->{Users, Log; NotFound}`. Пустая
строка эффектов не содержит этих требований и ошибок. Чистая функция не
может вызывать выполняемую функцию.

В текущей версии вызовы среды выполнения, например `Platform.stdout_line`
и операции чтения часов, обозначаются стрелкой `->{}`, но не указываются в
строке эффектов. Это ограничение описано в разделе
[Почему Flick](../../start/why/#ограничения).

**Попробуйте:** добавьте в `double` вывод строки перед возвратом
результата. Компилятор сообщит `FLICK-E001`: `double` — чистая функция.
