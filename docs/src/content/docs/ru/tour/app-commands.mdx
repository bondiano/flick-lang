В этом примере приложение выполняет заранее заданный сценарий команд.
Список строк `script` содержит команды, которые последовательно
обрабатывает цикл в `main`.

Функция `run` разделяет строку команды на слова и сопоставляет полученный
список с образцами. Например, образец `["add", title, pages]` выделяет
название книги и количество страниц. Если команда неизвестна или количество
страниц не удаётся преобразовать в целое число, `run` завершается
типизированной ошибкой `BadCommand`.

Функция `pages_of` также может завершиться ошибкой `BadCommand`.
Эта ошибка указана в сигнатуре `run`, поэтому передаётся через `run`
вызывающему коду без отдельной обработки.

Цикл в `main` обрабатывает каждую ошибку `BadCommand` и переходит
к следующей команде.

**Попробуйте:** добавьте команду `"finish Emma"` перед `"report"`.
