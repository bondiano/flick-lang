Приложение принимает ввод. В этой песочнице нет клавиатуры, поэтому
`script` играет роль пользователя, который вводит команды.

`run` делит команду на слова и сопоставляет список: образец вроде
`["add", title, pages]` разбирает слова. Незнакомая команда или страницы,
которые не число, падают с типизированной ошибкой `BadCommand`.
`pages_of` падает внутри `run`, чья сигнатура разрешает эту ошибку,
поэтому сбой проходит через `run` без лишнего кода.

Цикл в `main` обрабатывает каждый сбой и переходит к следующей команде.

**Попробуйте:** добавьте команду `"finish Emma"` перед `"report"`.
