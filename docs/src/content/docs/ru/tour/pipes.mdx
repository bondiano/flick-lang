Если передать функции только часть аргументов, результатом будет функция,
принимающая оставшиеся. Например, `add 10` принимает ещё один аргумент типа
`Int`. Это называется частичным применением.

`fun n -> n * 3` — безымянная функция. Её можно передать аргументом другой
функции, например `List.map`.

`x |> f` означает `f x`. Цепочка операторов `|>` читается сверху вниз.
В примере каждое число списка умножается на 3, затем выбираются числа больше 5,
после чего вычисляется их сумма.

**Попробуйте:** замените `n > 5` на `n > 10` или добавьте перед `List.sum`
строку `|> List.map (fun n -> n + 1)`.
