<TourLesson locale="ru" id="pipes">

Дайте функции меньше аргументов, чем она принимает, и получите функцию от
остальных: `add 10` ждёт ещё один `Int`.

`fun n -> n * 3` — функция без имени. Её удобно передавать другой функции,
например `List.map`.

`x |> f` значит `f x`. Цепочка `|>` читается сверху вниз: взять список,
утроить каждое число, оставить те, что больше 5, сложить.

**Попробуйте:** замените `n > 5` на `n > 10` или добавьте перед `List.sum`
строку `|> List.map (fun n -> n + 1)`.
