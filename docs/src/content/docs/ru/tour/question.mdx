<TourLesson locale="ru" id="question">

Оператор `?` передаёт ошибку вызывающему коду. Функция `parse` возвращает
`Result`. Если сигнатура функции допускает соответствующую ошибку,
выражение `(parse a)?` извлекает число из `Ok` либо завершает вычисление
ошибкой из `Err`. Поэтому в `sum` можно записать обычное арифметическое
выражение, а в `summed` — обработать возможную ошибку в одном месте.

В функции, возвращающей `Option`, оператор `?` также применим к `Option`:
если значение равно `None`, он досрочно возвращает `None` из функции.

**Попробуйте:** уберите `?` после `parse b`. Компилятор сообщит
`FLICK-T003`: `Result Invalid Float` — это не `Float`.
