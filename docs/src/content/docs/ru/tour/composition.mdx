`f >> g` — функция, которая сначала применяет `f`, а затем `g`. Например,
`shout` удаляет пробелы по краям строки, а затем переводит её в верхний
регистр. `g << f` задаёт ту же функцию в обратном порядке записи: последний
шаг указывается первым, как в `List.length << String.split " "`.

Композиция — обычная функция, поэтому её можно передать в `List.map` без
обёртки. Операнды композиции вычисляются один раз, в месте её записи, и
композиция не дороже функции, написанной вручную.

Оператор `>>` связывает сильнее любого другого оператора, поэтому выражение
`List.map f >> List.filter p` записывается без скобок. Операторы `>>` и `<<`
нельзя использовать в одной цепочке без скобок.

**Попробуйте:** запишите `words` с оператором `>>` вместо `<<` или добавьте
`>> String.to_upper` к функции, которую принимает `List.map`.
