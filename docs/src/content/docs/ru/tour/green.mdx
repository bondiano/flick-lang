Упражнение главы. Два теста описывают, что должна делать `count_words`,
и не компилируются с ней: она возвращает `String`, а тесты ждут `Int`
(`FLICK-T003`). Исправьте `count_words`, не меняя тесты. Редактор
запускает `main`; локально `flick test` запускает оба случая.
