Закрепите материал главы в одной функции. `fizzbuzz` принимает целое число
и возвращает строку `Fizz` для чисел, кратных 3, но не 5, `Buzz` для кратных
5, но не 3, и `FizzBuzz` для кратных и 3, и 5. В остальных случаях функция
возвращает строковое представление числа.

В заготовке есть только проверка кратности 15. Выражение `if` без `else`
имеет тип `Unit`, поэтому компилятор сообщает `FLICK-T003`. Допишите функцию
и нажмите **Проверить**. Проверка компилирует код, проверяет сигнатуру
экспортированной функции и сравнивает вывод `main` с ожидаемым.

</TourLesson>
