Пора собрать главу вместе. `fizzbuzz` принимает число и возвращает `Fizz`
для чисел, кратных 3, `Buzz` для кратных 5, `FizzBuzz` для кратных обоим, а
для остальных — само число.

Заготовка останавливается после первого случая. `if` без `else` имеет тип
`Unit`, поэтому компилятор сообщает `FLICK-T003`. Допишите функцию и нажмите
**Проверить**: проверка компилирует код, смотрит на сигнатуру
экспортированной функции и сравнивает то, что печатает `main`.
