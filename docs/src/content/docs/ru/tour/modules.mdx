В проекте каждый файл — это модуль, и другой файл пользуется им через
`import`. На этой странице один файл, поэтому урок использует вложенный
модуль: правила у него те же.

`module Greeting exposing (greet) =` создаёт модуль внутри `Main`. Снаружи
можно использовать только то, что перечислено в `exposing`, с именем модуля
впереди: `Greeting.greet`. Остальное, как `mark`, остаётся закрытым.

**Попробуйте:** напечатайте `Greeting.mark`. Компилятор сообщит
`FLICK-R004`: `Greeting` не экспортирует `mark`.
