Каждый исходный файл проекта — модуль. Для использования одного модуля
в другом служит `import`. Пример на этой странице состоит из одного файла,
поэтому в нём используется вложенный модуль. Для него действуют те же
правила.

Объявление `module Greeting exposing (greet) =` создаёт модуль внутри `Main`.
Извне доступны только имена, перечисленные в `exposing`. К функции
обращаются с именем модуля: `Greeting.greet`. Остальные определения,
например `mark`, недоступны за пределами модуля.

**Попробуйте:** напечатайте `Greeting.mark`. Компилятор сообщит
`FLICK-R004`: `Greeting` не экспортирует `mark`.
