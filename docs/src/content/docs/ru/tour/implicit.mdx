Атрибут `@implicit` перед экземпляром `Into` разрешает компилятору
вызывать преобразование самостоятельно. Функция `clearance` принимает
`Feet`, поэтому в вызове `clearance (Meters 4.0)` метры сначала
преобразуются в футы, без явного `into`.

Неявное преобразование выполняется только между двумя именованными
типами, например `Meters` и `Feet`, всегда за один шаг и только если
подходит ровно один неявный экземпляр. Встроенные числовые типы неявно не
преобразуются: чтобы получить `Float` из `Int`, по-прежнему нужен `into`.

Полные правила приведены в [справочнике](../../reference/classes/#неявные-преобразования).

**Попробуйте:** удалите `@implicit`. Компилятор сообщит `FLICK-T003`:
`clearance` ожидает `Feet`, а получает `Meters`.
