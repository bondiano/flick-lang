Сигнатура функции указывает необходимые сервисы, поэтому тест может
предоставить ей другие реализации этих сервисов. Функция `greeting`
вызывает операцию `Clock`, чтобы получить текущий час. Выражение `at 9`
создаёт слой с реализацией часов, которая всегда возвращает 9. Тип
`Layer {} none {Clock}` описывает построение слоя: оно не требует
сервисов, не завершается типизированной ошибкой и предоставляет реализацию
`Clock`.

Один и тот же код можно использовать с реальными часами в рабочем
приложении и с фиксированным временем в тесте. Последние строки примера
проверяют приветствие в 11 часов. Если функции нужно несколько сервисов,
`Layer.merge` объединяет слои с их реализациями.

**Попробуйте:** вызовите `greeting ()` без `provide`. Компилятор сообщит
`FLICK-E002`: в строке эффектов `main` не указан `Clock`.
