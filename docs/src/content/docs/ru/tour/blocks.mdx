`let` связывает имя со значением. После этого присвоить имени другое
значение нельзя.

Блок состоит из строк с отступом под `let`. Значение последнего выражения
становится значением всего блока. Имена, объявленные в блоке, доступны только
внутри него: например, `height` доступно только в блоке, вычисляющем `area`.

Все промежуточные выражения блока должны иметь тип `Unit`, как вызов функции
вывода.

**Попробуйте:** поставьте `height` отдельной строкой над `width * height`.
Компилятор сообщит `FLICK-T011`: значение `height` было бы отброшено, а
отбрасывать можно только значения типа `Unit`.
