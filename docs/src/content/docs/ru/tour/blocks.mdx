`let` даёт значению имя. Имя сохраняет это значение: присвоить ему другое
нельзя.

Блок — это несколько строк с отступом под `let`. Его последняя строка — его
значение, а имена, созданные в блоке, остаются внутри него: `height`
существует, только пока вычисляется `area`.

Все остальные строки блока должны иметь тип `Unit`, как вызов, который
печатает.

**Попробуйте:** поставьте `height` отдельной строкой над `width * height`.
Компилятор сообщит `FLICK-T011`: это значение пропало бы, а отбросить можно
только `Unit`.
