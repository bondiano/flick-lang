`Host.Console` встречался в сигнатуре каждой функции `main`: вывод на
консоль — это сервис. Хост предоставляет ещё пять сервисов: `Host.Clock`
для чтения времени, `Host.Random` для случайных чисел, `Host.Environment`
для переменных окружения, `Host.Arguments` для аргументов программы и
`Host.Process` для дочерних процессов. Стандартная библиотека обращается
к хосту через них, поэтому `Random.next_boolean` требует `Host.Random`, а
`Platform.args` — `Host.Arguments`.

Сигнатура `greet` показывает, что функция читает аргументы и подбрасывает
монету. Если `main` указывает эти сервисы в своей строке эффектов, она
получает настоящие реализации от среды, в которой запущена. Здесь `main`
их не указывает и, как тест, предоставляет их сама: `ada` задаёт
аргументы, а `heads` и `tails` фиксируют результат броска, поэтому
результат известен заранее. Часы, консоль и окружение заменяются так же.

Какие сервисы предоставляет каждая среда, описано в
[справочнике](../../reference/effects/#явные-зависимости-от-хоста).

**Попробуйте:** напечатайте `greet ()` без `provide`. Компилятор сообщит
`FLICK-E002`: в строке эффектов `main` нет `Host.Arguments` и
`Host.Random`. Добавьте их, и программа будет работать с настоящими
сервисами: здесь — без аргументов и с монетой, которая от запуска к запуску
падает по-разному.
