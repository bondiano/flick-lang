Тесты в этом примере — обычные функции. Функция `left_after` выполняет
сценарий команд с новым хранилищем в памяти и возвращает количество оставшихся
страниц. Функция `check` выводит результат проверки условия.

У каждого теста своя ячейка `Ref`, поэтому тесты не изменяют списки книг
друг друга. В проекте эти проверки размещались бы в тестах и запускались
командой `flick test`. Принцип тот же: тест предоставляет тестовые реализации
сервисов, от которых зависит проверяемая функция.

**Попробуйте:** внесите ошибку в `Books.finish`, записав в ней `read = false`.
Второй тест выведет `FAILED`.
