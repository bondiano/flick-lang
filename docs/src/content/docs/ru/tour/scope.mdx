Ресурс, например файл или соединение, нужно закрыть после использования,
даже если что-то пошло не так. `scope s { … }` открывает часть программы,
которая владеет ресурсами, а `Resource.acquire_release` открывает в ней
ресурс: задача открывает его, а функция закрывает.

Когда scope заканчивается, он закрывает то, чем владеет, в обратном
порядке: сначала сокет, потом файл. Значение блока — это значение scope.

**Попробуйте:** перенесите строку, которая открывает файл, выше
`let result = scope s {`. Компилятор сообщит `FLICK-G004`: ресурсу нужен
scope, который будет им владеть.
