Ресурс нужно закрыть и при ошибке. `scope s { … }` владеет ресурсами,
а `Resource.make acquire release` получает ресурс и регистрирует освобождение.
Функция освобождения получает значение и `Exit` области.

Сокет закрывается раньше файла, в обратном порядке получения.
`Resource.acquire_release` — низкоуровневая форма без результата области.
См. [ресурсы](../../reference/resources/#получение-и-отложенная-очистка).

**Попробуйте:** вынесите получение ресурса за пределы области:
`FLICK-G004` сообщает, что у него нет владельца.
