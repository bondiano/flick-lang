Ресурс, например файл или соединение, нужно закрыть после использования,
в том числе при ошибке. Конструкция `scope s { … }` создаёт область
владения ресурсами. В `Resource.acquire_release` задача открывает ресурс,
а переданная функция закрывает его при завершении области.

Ресурсы закрываются в порядке, обратном открытию: в этом примере сначала
сокет, затем файл. Значение блока становится результатом выражения `scope`.

**Попробуйте:** перенесите строку, которая открывает файл, выше
`let result = scope s {`. Компилятор сообщит `FLICK-G004`: ресурс нужно
открыть внутри области владения.
