Упражнение главы. `count_coins` считает наименьшее число монет на сумму:
сколько поместится монет по 25 центов, затем по 10, по 5 и по 1. В ней есть
тип с вариантами, `match` и цикл `for`.

`match` в `cents` забывает одну монету, поэтому компилятор сообщает
`FLICK-T009`. Обработайте каждую монету и нажмите **Проверить**.
