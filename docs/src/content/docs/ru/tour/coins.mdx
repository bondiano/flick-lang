В упражнении этой главы функция `count_coins` вычисляет наименьшее число
монет для заданной суммы в центах. Сначала она использует максимально
возможное число монет по 25 центов, затем — по 10, по 5 и по 1. В функции
используются тип с вариантами, сопоставление с образцом и цикл `for`.

В функции `cents` выражение `match` не обрабатывает один из конструкторов
типа `Coin`, поэтому компилятор сообщает `FLICK-T009`. Добавьте обработку
всех конструкторов и нажмите **Проверить**.
