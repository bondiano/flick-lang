Задачу, завершившуюся типизированной ошибкой, можно запустить повторно.
Первые два запуска `flaky` завершаются ошибкой, а третий — успешно.
Вызов `Effect.retry (Schedule.recurs 5)` допускает до пяти повторных
запусков после исходной попытки. Конструкция `try … with` обрабатывает
ошибку, если все попытки завершились ошибкой.

В ячейке `Ref` хранится число выполненных попыток. Её значение
сохраняется между запусками задачи.

**Попробуйте:** замените `Schedule.recurs 5` на `Schedule.recurs 1`. Вторая
попытка также завершится ошибкой. После этого повторные запуски
прекратятся и ошибка будет обработана.
