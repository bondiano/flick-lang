Упавшую задачу можно запустить снова. `flaky` падает дважды, а потом
срабатывает. `Effect.retry (Schedule.recurs 5)` запускает её снова после
каждого сбоя, до пяти раз, а `try … with` обрабатывает ошибку, если
упадут все попытки.

`Ref` считает попытки между запусками задачи.

**Попробуйте:** замените `Schedule.recurs 5` на `Schedule.recurs 1`. Вторая
попытка тоже упадёт, и обработчик сдастся.
