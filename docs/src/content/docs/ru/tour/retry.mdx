<TourLesson locale="ru" id="retry">

`flaky calls` — прямой эффектный вызов. `Effect.retry` отмечает параметр
знаком `~`, поэтому вызов передаётся незапущенным, без `task { … }`.
`Schedule.recurs 5` допускает пять повторов после первой попытки.
Один `Ref` считает попытки; `try` обрабатывает окончательную ошибку.
См. [эффекты](../../reference/effects/#task-и-await).

**Попробуйте:** используйте `Schedule.recurs 1`: две попытки завершатся ошибкой.
