`type` с `|` перечисляет формы, которые принимают его значения. `Shape` —
это `Circle` с радиусом или `Rect` с двумя сторонами. `Circle` и `Rect` —
конструкторы, их вызывают как функции: `Circle 1`.

`match` разбирает значение. Каждая ветка называет форму и значения внутри
неё и даёт результат для этой формы.

`deriving Eq, Show` просит у компилятора сравнение на равенство и `show`;
что это значит, объясняет глава о классах.

**Попробуйте:** добавьте в тип `| Square Float`. Компилятор сообщит
`FLICK-T009`: `area` не обрабатывает `Square`. Добавьте для него ветку.
