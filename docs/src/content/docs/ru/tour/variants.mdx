В объявлении `type` символ `|` разделяет варианты значений типа. Значение
типа `Shape` — это `Circle` с радиусом или `Rect` с двумя сторонами.
`Circle` и `Rect` — конструкторы; их вызывают как функции: `Circle 1`.

`match` выполняет сопоставление с образцом. Образец в каждой ветке
указывает конструктор и связывает имена с его аргументами, а выражение
после `->` задаёт результат для этой ветки.

`deriving Eq, Show` включает автоматическое построение экземпляров
классов типов `Eq` и `Show` для сравнения на равенство и преобразования
значений в строки с помощью `show`. Подробнее об этом — в главе о классах
типов.

**Попробуйте:** добавьте в тип `| Square Float`. Компилятор сообщит
`FLICK-T009`: `area` не обрабатывает `Square`. Добавьте для него ветку.
