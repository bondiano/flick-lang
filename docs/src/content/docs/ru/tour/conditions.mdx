`if … then … else …` — выражение, которое возвращает значение. Результаты
обеих ветвей должны иметь один тип. `else if` добавляет ещё один случай.

Для передачи отрицательного числа в качестве аргумента нужны скобки:
`sign (-3)`.

Функция, которая вызывает саму себя, объявляется с помощью `let rec`.
В примере `factorial` возвращает `1` при `n <= 1`. Иначе она умножает `n`
на результат рекурсивного вызова для `n - 1`.

**Попробуйте:** уберите `rec`. Компилятор сообщит `FLICK-T017` и укажет
функцию, которая вызывает себя.
