`if … then … else …` — это выражение: у него есть значение, поэтому обе
ветки дают один тип. `else if` добавляет ещё один случай.

Отрицательное число в аргументе пишется в скобках: `sign (-3)`.

Функция, которая вызывает саму себя, объявляется через `let rec`.
`factorial` останавливается на 1, а иначе умножает `n` на факториал `n - 1`.

**Попробуйте:** уберите `rec`. Компилятор сообщит `FLICK-T017` и назовёт
функцию, которая использует саму себя.
