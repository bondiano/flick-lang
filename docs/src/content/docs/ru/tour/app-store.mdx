Объявление `service Shelf` задаёт операции для работы с книгами: добавление,
отметку о прочтении и получение списка. Функция `memory` строит слой
с реализацией `Shelf`, которая хранит список в ячейке `Ref` и использует
чистые функции модуля `Books` для его изменения.

В сигнатуре `report` запись `->{Shelf; none}` указывает, что функция
использует сервис `Shelf` и не завершается типизированной ошибкой. Функция
`main` предоставляет реализацию с хранением в памяти через `provide`.
Для хранения книг в базе данных потребовался бы другой слой с реализацией
того же сервиса. Функцию `report` при этом менять не нужно.

**Попробуйте:** вызовите `report ()` ещё раз перед `Shelf.finish "Dune"`.
