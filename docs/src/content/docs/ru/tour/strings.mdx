<TourLesson locale="ru" id="strings">

Оператор `++` соединяет две строки. Внутри строки конструкция `\{…}`
подставляет строковое представление значения. Для `Int`, `Float` и `Bool`
это обычная запись числа или логического значения.

Функция `show` возвращает представление значения в коде. Строка в нём
заключена в двойные кавычки, а перед каждой внутренней кавычкой стоит обратная
косая черта. Модуль `String` также содержит функции `String.length`,
`String.split`, `String.join` и другие.

**Попробуйте:** напишите `"Hello, " ++ 1`. `++` принимает две строки, поэтому
компилятор сообщит `FLICK-T003`. Вместо этого напишите `"Hello, \{1}"`.
