`++` соединяет две строки. Внутри строки `\{…}` подставляет текст значения:
`Int`, `Float` или `Bool` выглядят так, как их читают люди.

`show` даёт вид, который у значения в коде. Для строки это кавычки вокруг и
обратная косая черта перед каждой кавычкой внутри. Остальное — в модуле
`String`: `String.length`, `String.split`, `String.join` и другие.

**Попробуйте:** напишите `"Hello, " ++ 1`. `++` принимает две строки, поэтому
компилятор сообщит `FLICK-T003`. Вместо этого напишите `"Hello, \{1}"`.
