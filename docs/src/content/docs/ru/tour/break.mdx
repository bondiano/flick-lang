<TourLesson locale="ru" id="break">

`loop { … }` повторяет тело до выполнения `break`. Выражение `break value`
завершает цикл со значением `value`. В этом примере цикл возвращает
найденную позицию в `Some` или `None`, если значение не найдено. Результат
всего выражения `loop` имеет тип `Option Int` и служит результатом функции
`binary_search`.

На каждой итерации `let middle = …` создаёт новую локальную переменную.
Переменные `low` и `high` задают границы диапазона поиска и сужают его.

**Попробуйте:** напишите `break 0` вместо первого `break None`. Компилятор
сообщит `FLICK-T003`: значения во всех `break` одного цикла должны иметь
один тип, здесь — `Option Int`.

</TourLesson>
