Для каждого конструктора можно явно указать тип его результата. В `Expr a`
конструктор `Num` создаёт значение типа `Expr Int`, а `Yes` и `Less` —
`Expr Bool`.

Функция `eval : forall a. Expr a -> a` возвращает значение типа, указанного
параметром `a`: `Int` для суммы, `Bool` для сравнения. Проверка типа
результата во время выполнения не нужна. Попытку передать `Expr Bool`
конструктору `Add` компилятор отклонит.

Это самый сложный урок главы; при первом чтении его можно пропустить.

**Попробуйте:** напишите `Add (Num 1) (Yes true)`. Компилятор сообщит
`FLICK-T003`: аргументы `Add` должны иметь тип `Expr Int`, а не `Expr Bool`.
