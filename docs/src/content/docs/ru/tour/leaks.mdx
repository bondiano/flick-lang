Эта программа намеренно содержит ошибку. Функция `reader` открывает файл
в области владения ресурсами и возвращает функцию для его чтения.
При завершении области файл закрывается. Вызов возвращённой функции
привёл бы к чтению закрытого файла.

Параметр `s` в типе `File s` обозначает регион, связанный с областью
владения ресурсами. Компилятор сообщает `FLICK-G002`: возвращаемая функция
могла бы использовать ресурс за пределами времени жизни этого региона.

**Попробуйте:** прочитайте файл внутри области владения: измените тип
результата `reader` на `String`, а последнюю строку — на `Files.read file`.
Программа скомпилируется.
