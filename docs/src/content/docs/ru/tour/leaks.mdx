Эта программа не компилируется, и так задумано. `reader` открывает файл в
scope и возвращает функцию, которая его читает. Но scope закрывает файл,
когда заканчивается, и эта функция читала бы закрытый файл.

Тип `File s` принадлежит региону `s` своего scope, и компилятор сообщает
`FLICK-G002`: возвращённая функция использует регион, который уже не
живёт.

**Попробуйте:** прочитайте файл внутри scope: сделайте тип результата
`reader` равным `String`, а последнюю строку — `Files.read file`. Программа
скомпилируется.
