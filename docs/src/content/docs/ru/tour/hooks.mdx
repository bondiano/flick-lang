**Где запускается:** локально: модуль в `test/Main.fl` проекта, затем `flick test` (для компаньонов путь указан ниже). CI проверяет отчёт.

Подготовка идёт снаружи внутрь, освобождение — изнутри наружу.
`before_all` и `after_all` принадлежат набору; `before_each` и `after_each`
окружают каждый выбранный случай. Невыбранные и пропущенные случаи не запускают
хуки. CI проверяет порядок всех строк `hook:`, включая очистку после таймаута.

`timeout 5` прерывает бесконечное тело через 5 мс. Освобождение всё равно
выполняется; отчёт указывает `timeout`, код выхода — 1. Таймаут набора даёт
случаям значение по умолчанию и ограничивает хуки. `Test.timeout` оборачивает
тесты ручной сборки; `flick test --timeout 500ms` задаёт общий предел,
которого по умолчанию нет.
