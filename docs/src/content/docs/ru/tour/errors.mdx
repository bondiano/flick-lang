Типизированная ошибка описывает сбой, который должен обработать вызывающий
код. Объявление `type error NotFound = NotFound String` задаёт такой тип
ошибки. В сигнатуре `find : String ->{; NotFound} Float` имя `NotFound`
после `;` указывает, что `find` может завершиться этой ошибкой.

Вызов `from_result (Err …)` завершает вычисление типизированной ошибкой.
Конструкция `try … with` обрабатывает ошибки в соответствующих ветках.
В примере ошибка `NotFound` обработана, поэтому в сигнатуре `main` её нет.

**Попробуйте:** уберите `; NotFound` из сигнатуры `find`. Компилятор сообщит
`FLICK-E002`: тело `find` может завершиться ошибкой, не разрешённой сигнатурой.
