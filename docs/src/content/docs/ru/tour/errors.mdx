<TourLesson locale="ru" id="errors">

`type error` объявляет ожидаемую ошибку. `find` указывает оба варианта после
`;`. `try` ловит ошибку (постфиксный `expr catch | NotFound _ -> …` тоже подходит,
когда обрабатываются только типизированные ошибки); его ветка получает значение типа
`Errors {NotFound, Unavailable}`. Чистый `match` разбирает это значение.
Сам `match` ничего не ловит и не убирает ошибки из строки функции.

`to_http` возвращает отдельную ошибку там, где ожидается содержащая её строка.
`Exit.map_error` переводит результат с помощью этой функции.
См. [значения ошибок](../../reference/effects/#ожидаемые-ошибки).

```flick fail T009
type error NotFound = NotFound String
type error Unavailable = Unavailable
problem : Errors {NotFound, Unavailable} -> String
let problem err = match err with | NotFound name -> name
```

**Попробуйте:** добавьте недостающую ветку `Unavailable`.
