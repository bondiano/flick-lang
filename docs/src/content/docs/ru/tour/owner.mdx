Упражнение главы. В `main` вызов `open_res` находится вне области владения
ресурсами. Компилятор сообщает `FLICK-G004`, поскольку для освобождения
ресурса нужна такая область.

Поместите вызов `open_res` в `scope { … }` и нажмите **Проверить**.
Программа записывает сообщения об открытии и освобождении ресурса в список,
который `main` выводит одной строкой.
