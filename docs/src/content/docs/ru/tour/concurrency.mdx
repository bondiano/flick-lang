Функция `parallel` запускает две задачи конкурентно и ожидает завершения
обеих. В этом примере общее время ожидания примерно равно времени
медленной задачи, а не сумме задержек. Конкурентное выполнение не
гарантирует одновременного исполнения на разных ядрах.

Функция `race_first` запускает две задачи и возвращает результат той,
которая завершилась первой. Для другого файбера запрашивается прерывание.
Вызов `Effect.sleep` приостанавливает текущий файбер на заданное время, не
блокируя другие вычисления.

Эти операции могут приостанавливать текущий файбер, поэтому требуют
`Async` в строке эффектов.

**Попробуйте:** уберите `Async` из сигнатуры `main`. Компилятор сообщит
`FLICK-E002` и предложит исправление, которое добавляет `Async` в сигнатуру.
