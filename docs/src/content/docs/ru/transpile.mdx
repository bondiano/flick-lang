Слева — Flick. Справа — JavaScript. Редактируйте модуль и сразу смотрите настоящий результат компиляции. Переключайте **Отладку** и **Релиз**, чтобы изучить оба профиля сборки. Эта страница компилирует код, но не запускает его.

### Читайте результат компиляции

Выберите **Данные и образцы**, чтобы посмотреть на конструкторы данных и сопоставление с образцом, или **Типизированные ошибки**, чтобы увидеть преобразование runtime-функций для адаптера на Effect. Диагностика под панелями относится к выбранному профилю сборки; вместо результата для некорректного кода ничего не подставляется.

Предпросмотр показывает JavaScript вашего модуля, а не самостоятельный bundle. Сгенерированные импорты ссылаются на среду выполнения Flick и встроенные модули. Подробнее о преобразованиях — в [генерации кода](/ru/reference/codegen/), о границе с JavaScript — в [foreign-функциях](/ru/reference/ffi/).

Компиляция происходит в этом браузере с помощью WebAssembly-компилятора. Редактор исходного кода, выбор примеров и профиля, а также представление диагностики реализованы на самом Flick.

Чтобы выполнить программу и посмотреть вывод, перейдите в [Play](/ru/play/).
