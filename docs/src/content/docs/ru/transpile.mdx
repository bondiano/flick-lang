Изменяйте код Flick слева — справа появится сгенерированный JavaScript. Кнопки **Отладка** и **Релиз** переключают профиль сборки. Код на этой странице только компилируется, но не запускается.

<Playground mode="transpile" locale="ru" />

### Читайте результат компиляции

В примере **Данные и образцы** посмотрите, как компилятор представляет конструкторы и сопоставление с образцом. В **Типизированных ошибках** — как эффектные функции используют адаптер на Effect. Сообщения под редактором относятся к выбранному профилю сборки. Если код не прошёл проверку, сгенерированный JavaScript не показывается.

Результат содержит только ваш модуль, а не все его зависимости. Импорты ссылаются на среду выполнения Flick и встроенные модули: для запуска они тоже понадобятся. Подробности — в разделах [Генерация кода](/ru/reference/codegen/) и [Внешние функции](/ru/reference/ffi/).

Код компилируется в браузере с помощью WebAssembly. Редактор, выбор примеров и профиля сборки, а также вывод сообщений компилятора написаны на Flick.

Чтобы выполнить программу и посмотреть вывод, перейдите в [Play](/ru/play/).
