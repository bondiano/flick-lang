Выберите пример, измените код и нажмите **Запустить**. WebAssembly-компилятор проверяет код после каждого изменения. Программа выполняется в отдельном потоке браузера — Web Worker.

<Playground mode="play" locale="ru" />

### Что попробовать

- **Приветствие** выводит строку. **Данные и образцы** показывают алгебраические типы данных и сопоставление с образцом.
- **Типизированные ошибки**, **Повторные попытки** и **Конкурентность** используют среду выполнения Flick на Effect.
- **Ошибка типа** намеренно не проходит проверку: прочитайте диагностику и замените строки числами.

Вывод появится, когда программа завершится. Чтобы прервать её раньше, нажмите **Остановить**. Через 10 секунд выполнение прекращается автоматически. Программа может успешно завершиться без вывода. Для запуска модуль должен экспортировать функцию `main`.

Здесь можно работать с одним модулем. Файловая система Node.js, подключения к базам данных и произвольные сторонние npm-пакеты недоступны. Код компилируется в вашем браузере; устанавливать Flick не нужно.

В [Transpile](../transpile/) можно посмотреть результат компиляции. Чтобы создать локальное приложение, перейдите к разделу [Начало работы](../start/getting-started/).

Интерфейс этой страницы тоже написан на Flick с помощью [DSL `ui`](../reference/ui/). TypeScript связывает его с браузерными API, компилятором и Web Worker.
