Пишите на Flick и запускайте код прямо здесь. Выберите пример, измените исходный код и нажмите **Запустить**. Настоящий WebAssembly-компилятор проверяет каждое изменение; программа выполняется отдельно, в worker.

<Playground mode="play" locale="ru" />

### Что попробовать

- **Приветствие** выводит строку. **Данные и образцы** показывают алгебраические типы данных и сопоставление с образцом.
- **Типизированные ошибки**, **Повторные попытки** и **Конкурентность** используют среду выполнения Flick на Effect.
- **Ошибка типа** намеренно не проходит проверку: прочитайте диагностику и замените строки числами.

Вывод появится после завершения программы. Кнопка **Остановить** отменяет работающий worker; через 10 секунд запуск останавливается автоматически. Успешная программа может ничего не вывести. Чтобы запустить модуль, экспортируйте `main`.

Это среда для одного модуля в браузере, а не локальный проект Node.js. Доступ к файловой системе Node.js, подключения к базам данных и произвольные сторонние npm-пакеты здесь не предоставляются. Компиляция происходит локально; устанавливать Flick не нужно.

Хотите посмотреть результат компиляции? Откройте [Transpile](/ru/transpile/). Для локального проекта перейдите к [началу работы](/ru/start/getting-started/).

Сам интерактивный интерфейс написан на Flick с помощью [DSL `ui`](/ru/reference/ui/). TypeScript только связывает его с браузером, компилятором и worker.
