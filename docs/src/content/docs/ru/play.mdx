WebAssembly-компилятор проверяет код после каждого изменения, а программа
выполняется в отдельном воркере и останавливается через 10 секунд. Вкладки
JavaScript и `.d.ts` показывают, что пишет компилятор для выбранного профиля
сборки.

Здесь один модуль в браузере, а не проект на Node.js: файловой системы, баз
данных и npm-пакетов нет. Чтобы создать локальный проект, перейдите к разделу
[Начало работы](../start/getting-started/). Сама песочница написана на Flick с
помощью [DSL `ui`](../reference/ui/); TypeScript только связывает её с браузером,
компилятором и воркером.
