Во Flick есть базовые числовые типы (`Int`, `Float`, `BigInt`) и типы
фиксированной ширины — целые и числа с плавающей точкой одинарной точности
(`Int8`, `Int16`, `Int32`, `Int64`, `UInt8`, `Byte`, `UInt16`, `UInt32`,
`UInt64`, `Float32`), без неявных преобразований между ними (см.
[Schema и стандартные типы данных](../../spec/07-schema/)). Их правила
одинаковы в debug и release на JS и Go. Пользовательских операторов нет;
приоритеты встроенных приведены в [таблице операторов](../syntax/#таблица-операторов).

## Числовые типы

| Тип | Значения | Суффикс | Арифметика |
| - | - | - | - |
| `Int8` | 8-битные со знаком (`-128..=127`) | `i8` | по модулю 2⁸; `/` усекает к нулю; `/` и `%` на ноль дают `0i8`; `-128i8 / -1i8 == -128i8` |
| `Int16` | 16-битные со знаком (`-32768..=32767`) | `i16` | по модулю 2¹⁶; `/` и `%` на ноль дают `0i16`; `-32768i16 / -1i16 == -32768i16` |
| `Int` (`Int32`) | 32-битные со знаком (`-2147483648..=2147483647`) | нет или `i32` | `type alias Int32 = Int`; по модулю 2³² (`2147483647 + 1 == -2147483648`); `/` и `%` на ноль дают `0` |
| `Int64` | 64-битные со знаком (`-9223372036854775808..=9223372036854775807`) | `i64` | по модулю 2⁶⁴; `/` и `%` на ноль дают `0i64`; `min_value / -1i64 == min_value` |
| `UInt8` (`Byte`) | 8-битные без знака (`0..=255`) | `u8` | `type alias Byte = UInt8`; по модулю 2⁸ (`-(1u8) == 255u8`); `/` и `%` на ноль дают `0u8` |
| `UInt16` | 16-битные без знака (`0..=65535`) | `u16` | по модулю 2¹⁶; `/` и `%` на ноль дают `0u16` |
| `UInt32` | 32-битные без знака (`0..=4294967295`) | `u32` | по модулю 2³²; `/` и `%` на ноль дают `0u32` |
| `UInt64` | 64-битные без знака (`0..=18446744073709551615`) | `u64` | по модулю 2⁶⁴; `/` и `%` на ноль дают `0u64` |
| `BigInt` | целые произвольной точности со знаком | `n` | точная; `/` усекает к нулю; `/` и `%` на ноль дают `0n` |
| `Float32` | IEEE 754 binary32 | `f32` | `0.0f32 / 0.0f32` — NaN, `1.0f32 / 0.0f32` — `Infinity`; `==` — SameValueZero |
| `Float` | IEEE 754 binary64 | нет (дробные) | `0.0 / 0.0` — NaN, `1.0 / 0.0` — `Infinity`; `==` — SameValueZero |

`Int32` — прозрачный псевдоним для `Int` (`type alias Int32 = Int`), а `Byte` —
прозрачный псевдоним для `UInt8` (`type alias Byte = UInt8`). Они совпадают по
типам, ABI и представлению во время выполнения.

Целочисленный литерал без суффикса (`3`, `0xFF`, `1_000`) подстраивается под
любой числовой тип, которого требует контекст, а без ограничений становится
`Int`: `let ratio : Float = 3` и `3 + 0.5` дают `Float`, `3 + 4n` — `BigInt`, а
`let b : UInt8 = 255` — `UInt8`. Дробный или экспоненциальный литерал без
суффикса (`3.0`, `1e3`) подстраивается под любой тип `Floating` (`Float` или
`Float32`), по умолчанию — `Float`.

Литерал с суффиксом фиксирует свой тип сразу: `127i8`, `-32768i16`, `42i32`,
`-9223372036854775808i64`, `0xFFu8`, `0b1010_0101u16`, `0o77u32`,
`18446744073709551615u64`, `1.5f32`, `1e-3f32`. Литералы с префиксом системы
счисления поддерживают целочисленные суффиксы; в шестнадцатеричной записи
(`0x…`) `f` остаётся цифрой, поэтому `0x1f32` — это шестнадцатеричное целое без
суффикса (`7986`). Целочисленный суффикс у дроби/экспоненты и `f32` у не
десятичного литерала дают `FLICK-S006`. Любой целочисленный литерал вне
диапазона своего типа — включая отрицательный литерал для беззнакового типа,
например `-1u8`, — вызывает `FLICK-T003`. Если тип литерала без суффикса
определяет только ограничение класса, выбирается первый из `Int`, `Float`,
`BigInt` с подходящим инстансом.

Счётчики, размеры, индексы, хэши и части даты во всей стандартной
библиотеке — `Int` (`List.length`, `HashMap.size`, `Hash.hash`,
`Queue.size`, `Schedule.recurs`, части `DateTime`); миллисекунды, эпохи,
размеры в байтах и измерения остаются `Float`: в 32 бита они не помещаются.

## Переполнение, деление и преобразования

Выбирайте поведение при ошибке в месте вызова:

| Форма | Переполнение | Нулевой делитель |
| --- | --- | --- |
| Обычные операторы целых фиксированной ширины (`Int8`..`UInt64`, `Int`) | Циклическое переполнение по модулю 2^W (включая унарный `-`) | `/` и `%` дают `0` |
| `T.checked_add`, `checked_sub`, `checked_mul`, `checked_div`, `checked_rem`, `divide`, `remainder` | Возвращают `Err Int.ArithmeticError`, если результат не помещается (включая знаковое `min / -1`) | Деление и остаток возвращают `Err` |
| `T.unsafe_div`, `unsafe_rem` | Сохраняют обычное циклическое поведение | Вызывают дефект |
| Обычные операторы `BigInt` | Произвольная точность в пределах доступной памяти | `/` и `%` дают `0n` |
| `BigInt.divide`, `BigInt.remainder` | Произвольная точность | Возвращают `Err Int.ArithmeticError` |

Арифметический дефект подчиняется обычным правилам завершения и cleanup.
Это не типизированная арифметическая ошибка. Для ненадёжного ввода используйте
checked-форму, если вызывающему коду нужно обработать неверную арифметику как
данные.

```flick
import Int8
import UInt8

wrapped : Int
let wrapped = 2147483647 + 1

checked : Result Int.ArithmeticError Int
let checked = Int.checked_div (-2147483648) (-1)

ordinary : BigInt
let ordinary = 5n / 0n

byte_wrap : UInt8
let byte_wrap = 255u8 + 1u8

widened : Int64
let widened = into (-128i8)

clamped : Int8
let clamped = Int8.saturating_from_int 500

checked_u8 : Option UInt8
let checked_u8 = UInt8.from_int 256
```

`wrapped` равен `-2147483648`; `checked` содержит ошибку, поскольку
положительное `2147483648` не помещается в `Int`; `ordinary` равен `0n`;
`byte_wrap` равен `0u8`; `widened` равен `-128i64`; `clamped` равен `127i8`;
`checked_u8` равен `None`. `Int.checked_rem (-2147483648) (-1)` успешно
возвращает `Ok 0`.

Целочисленное деление усекается к нулю, а остаток сохраняет знак делимого:
`-7 / 2` равно `-3`, `-7 % 2` равно `-1`. Степени целых фиксированной ширины
переполняются циклически; отрицательные степени знаковых типов усекаются
(`2 ** -1` равно `0`, `(-1i64) ** -3i64` равно `-1i64`). Отрицательная степень
`BigInt` вызывает дефект. Побитовые сдвиги (`shift_left`, `shift_right`,
`shift_right_unsigned`) берут счётчик сдвига по модулю разрядности типа
(`n & (W - 1)`).

Преобразования между числовыми типами всегда явные:

- **Расширение без потерь (`Into`)**: `into` переводит целое в более широкое
  целое того же знака, беззнаковое — в строго более широкое знаковое, любое
  целое фиксированной ширины — в `BigInt`, `Int8`/`Int16`/`UInt8`/`UInt16` — в
  `Float32`, `Int8`..`UInt32` — в `Float`, а `Float32` — в `Float`.
- **Проверенное сужение или смена знака (`T.from_*`)**: возвращает `Some x`,
  если значение точно и помещается в диапазон, иначе `None` (`Int.from_float`,
  `UInt8.from_int`, `Int64.from_uint64`, `BigInt.from_number`, …).
- **Циклическое (`T.wrapping_from_*`, `T.truncate`)**: берёт значение по модулю
  2^W; усечение из дробного отбрасывает дробную часть и переводит неконечные
  значения (`NaN`, `±Infinity`) в `0`.
- **С насыщением (`T.saturating_from_*`)**: ограничивает значения вне диапазона
  границами `min_value`/`max_value`; `NaN` переходит в `0`.
- **Округление к плавающей точке**: `Float32.from_float`, `Float32.from_bigint`,
  `Int64.to_float`, `BigInt.to_number` округляют к ближайшему чётному (для
  `Float32.from_bigint` — однократное округление сразу к binary32).

`Int.parse` отбрасывает начальные и конечные пробельные символы и переводы
строк ECMAScript (`\t`, `\n`, `\v`, `\f`, `\r`, пробел, U+00A0, U+1680,
U+2000–U+200A, U+2028, U+2029, U+202F, U+205F, U+3000 и U+FEFF; но не U+0085),
затем требует необязательный ASCII-знак `+` или `-` и одну или более
десятичных ASCII-цифр в диапазоне `-2147483648..2147483647`. Отрицательный
ноль нормализуется к `0`. Пустая строка, строка только со знаком, внутренние
пробелы, недесятичный текст и значения вне диапазона возвращают `None`. Модули
`Int8`..`UInt64` и `Float32` предоставляют аналогичные `parse` и `to_string`;
`show` и `display` для `Int64`/`UInt64` выводят обычные десятичные цифры без
суффикса `n`.

## Числа с плавающей точкой

`Float` — IEEE 754 binary64, а `Float32` — IEEE 754 binary32; оба поддерживают
знаковый ноль, субнормальные числа, NaN и бесконечности. Структурное `==`
использует SameValueZero: NaN равен себе, а оба нуля равны. Числовые `<`, `<=`,
`>` и `>=` оставляют NaN неупорядоченным; `compare` задаёт полный порядок с NaN
в конце. `Float.same_value` и `Float32.same_value` отличают отрицательный ноль
от положительного. `show` сохраняет `-0`; `Float.round` и `Float32.round`
округляют половины к положительной бесконечности, поэтому `Float.round (-2.5)`
равно `-2`.

Эти правила обязательны и для оптимизаций, и для будущих бэкендов. Другое
представление или машинная инструкция должны сохранять результаты, дефекты и
cleanup.

## Операторы

| Операторы | Операнды | Результат |
| - | - | - |
| `+ - * / % **`, префиксный `-` | оба одного типа `Numeric` (`Int8`..`UInt64`, `Int`, `BigInt`, `Float32`, `Float`) | тот же тип |
| `++` | оба `String` или оба `List a` | тот же тип |
| `< <= > >=` | оба одного числового типа или `String` либо оба другого типа с `Ord` | `Bool` |
| `== !=` | одного типа | `Bool` |
| `&& \|\|`, `not` | `Bool` | `Bool` |
| `option orelse fallback` | `Option a` и `a` | `a` (вычисляет `fallback` только при `None`) |
| `x \|> f`, `f <\| x` | `f x` | результат `f` |
| `f >> g`, `g << f` | функции | функция, которая применяет `f`, затем `g` |

`x |> f` вычисляет сначала `x`, `f <| x` — сначала `f`, как и `f x`;
`f a <| x` — вызов `f a x`. Чтобы передать значение в другую позицию аргумента,
используйте дырку выражения `_`: `x |> f a _ c` означает `(fun h -> f a h c) x`,
вычисляя сначала `x`, а затем тело захвата; `f a _ c <| x` применяет тот же
захват к `x`. Композиция — это замыкание `let f' = f;
let g' = g; fun x -> g' (f' x)`: она вычисляет операнды один раз, слева
направо, там, где записана, и получает тип этого замыкания. В её стрелке
ряды вызовов, которые она делает: композиция двух чистых функций чиста,
а `show >> Platform.stdout_line` — функция времени выполнения. Композиция
удерживает то же, что её операнды ([регионы](../regions/)). В release-сборке
замыкания там, где композицию применяют, нет: `(f >> g) x` — это `g (f x)`.

`1.5 + 1n`, `1i8 + 1i16` и `"a" ++ 1` вызывают `FLICK-T003`. Если тип операнда
не следует из других условий, выбирается `Int`, а для `++` — `String`. Диапазоны
`a..b`, `a..<b` и `a..` считают в `Int`.

`left orelse right` — ленивый fallback для `Option`, эквивалентный
`match left with | Some value -> value | None -> right`. Левая часть
вычисляется один раз, а правая — не более одного раза и только если слева
оказалось `None`. Если левая часть завершилась типизированной ошибкой или
дефектом, правая часть не выполняется. Оператор снимает ровно один слой
`Option` (`Some None orelse Some 1` даёт `None : Option Int`), не запускает
холодные значения `Eff` и `Lazy` и позволяет правой части завершаться ошибкой
в строку ошибок функции (например, `opt orelse Fail.fail Missing`). В отличие
от `Option.with_default`, который энергично вычисляет значение по умолчанию
до вызова, `orelse` не вычисляет дорогой или эффектный fallback при `Some`.

```flick
fallback : Option String -> String
let fallback host = host orelse "localhost"

first_valid : Option Int -> Option Int -> Int
let first_valid a b = a orelse b orelse 8080

nested_layer : Option (Option Int) -> Option Int
let nested_layer value = value orelse Some 1
```

## Числовые классы

Одна функция для всех числовых типов пишется через закрытые классы модуля
`Numeric`:

- `Numeric a`: `Int`, `Float`, `BigInt`, `Int8`, `Int16`, `Int64`, `UInt8`, `UInt16`, `UInt32`, `UInt64`, `Float32`.
- `Integer a`: `Int`, `BigInt`, `Int8`, `Int16`, `Int64`, `UInt8`, `UInt16`, `UInt32`, `UInt64`.
- `Floating a`: `Float`, `Float32`.

На переменной типа с таким ограничением операторы и целочисленные литералы
используют его методы (`add`, `div`, `from_int`, …); литералу с дробной частью
нужен `Floating`. Все инстансы объявлены в самом модуле, программа не может
объявить свой (`FLICK-C012`).

```flick
import Numeric exposing (Floating, Numeric)

square : Numeric a => a -> a
let square x = x * x

mean : Floating a => List a -> a
let mean xs = List.sum xs / Numeric.from_int (List.length xs)
```

`List.sum` и `List.product` принимают любой `Numeric`. Без ограничения
`x + 1` на переменной типа вызывает `FLICK-C001`. `< <= > >=` на переменной
типа с числовым классом используют его `lt`, `le`, `gt`, `ge` и значат то же,
что эти операторы на её типе (NaN не упорядочен); если есть только `Ord a`,
сравнение идёт через `compare`. На любом другом типе, например `Bool`,
выведенном типе, записи или списке, они сравнивают через `compare` его
экземпляра `Ord`; тип без него вызывает `FLICK-C001`.
