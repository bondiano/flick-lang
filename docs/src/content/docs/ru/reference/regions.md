`scope` освобождает полученные ресурсы, когда его тело завершается.
Проверка регионов не позволяет сохранить доступ к этим ресурсам после
закрытия области владения (см. [Ресурсы](../../spec/05-errors-and-concurrency/#ресурсы),
[Статические регионы и захваты](../../spec/05-errors-and-concurrency/#статические-регионы-и-захваты)).
Она выполняется после проверки типов и эффектов. Досрочного закрытия
и линейности нет: ресурс можно использовать сколько угодно раз,
пока его область владения открыта.

## Области и владельцы

```flick
# import File exposing (Path, FileSystem, OpenError, ReadError)
#
read_config : Path ->{FileSystem; OpenError, ReadError} String
let read_config path =
  scope {
    let file = File.open_scoped path
    File.read_all file
  }
```

Каждый `scope { … }` создаёт новый регион с жёстким типом и владельца
получаемых внутри ресурсов. Тип региона нельзя упоминать в типах за
пределами этой области. Операции, которая получает ресурс региона `s`,
нужен сервис `Scope s` из `Prelude`. Каждый `scope` предоставляет `Scope`
только для своего региона, как `provide` предоставляет сервис.
Если регион вызова не определяется другими условиями, ресурс принадлежит
ближайшей области `scope`. Функция может возложить владение ресурсом
на вызывающий код: для этого требование указывается в сигнатуре:

```flick
# import File exposing (File, Path, FileSystem, OpenError)
#
open_two : forall s. Path ->{FileSystem, Scope s; OpenError} (File s, File s)
let open_two path =
  (File.open_scoped path, File.open_scoped path)
```

`scope s { … }` вводит имя региона `s` для типов внутри тела и значение
владельца `s : Fiber.Owner s`. Конструкция `scope` эффектная:
чистая функция не может открыть такую область (`FLICK-E001`).
Если вызову нужен `Scope s`, но он находится вне всех областей владения
и этого требования нет в сигнатуре, возникает `FLICK-G004`.

Если вызову нужен `Scope s` внешнего региона, ресурс получает владелец
этого региона, несмотря на внутренние области. Ресурс освободится при
закрытии области владельца. Компилятор передаёт владельца лексически:
выбор не зависит от того, какая область оказалась самой внутренней
во время выполнения вызова.

```flick
# import File exposing (File, Path, FileSystem, OpenError)
#
keep : forall s. Path ->{FileSystem, Scope s; OpenError} File s
let keep path =
  acquire : Unit ->{FileSystem, Scope s; OpenError} File s
  let acquire () = File.open_scoped path
  scope {
    let local = File.open_scoped path
    acquire ()
  }
```

В этом примере `local` освобождается по завершении внутреннего `scope`,
а файл, который возвращает `keep`, — при закрытии области вызывающего кода.

## Захваты

Регион ресурса виден в его типе: `File s`, `List (File s)` или
номинальная обёртка `Wrapper s`. Замыкание, `task` или конструктор может
также удерживать значения, регионы которых не видны в его типе.

| Тип | Граница |
| - | - |
| `T^{s, t}` | не более регионов `s` и `t` в квалифицированной части |
| `T^c` | не более строки захватов `c` (кинд `CaptureRow`) |
| `T^(c + d)` | не более объединения обеих строк |
| `T` | без дополнительных скрытых захватов; видимые в `T` захваты остаются |

Для обобщённого значения `a^c` ограничивает **всё значение**, а не только
захваты сверх `a`. На границе значения `(f a)^c` также ограничивает захваты
параметров, если `f` оказывается данными, хранящими лишь свои параметры.
У функций и типов со скрытым хранилищем, например `StateT`, сохраняется
квалификатор скрытых захватов. Явные квалификаторы хранимых типов — часть
идентичности типа, а не границы, которые можно отбросить.

`Ref.make : forall c a. a^c ->{} Ref (a^c)` сохраняет постоянную границу
допустимых захватов в инвариантном типе содержимого. Расширение внешней границы
значения у псевдонима ячейки не расширяет внутреннюю границу и не разрешает
запись значений с более короткоживущими захватами.
Это различие сохраняется в [схеме 2 `.iface`](../iface/#типы-и-кинды).

```flick
# import File exposing (File, FileSystem, ReadError)
#
read_later : forall s. File s -> (Eff {FileSystem} {ReadError} String)^{s}
let read_later file =
  task { File.read_all file }
```

Граница может быть шире реальных захватов; более узкая даёт `FLICK-G001`.
`a^none` означает отсутствие захватов у обобщённого значения, а не возможность
стереть при подстановке конкретный `File s` или хранимый квалификатор замыкания.
У конкретного типа видимые в нём регионы сохраняются даже под `^none`.
Само упоминание `s` в типе параметра не заставляет функцию удерживать `s`,
но использование значения этого региона — заставляет.
Например, `fun () -> file` имеет тип `Unit -> File s`.

Каждая стадия каррированной функции удерживает ранее переданные параметры,
включая захваты обобщённых значений. `File s -> String -> String` означает
`File s -> (String -> String)^{s}`; в `a -> b -> a` вторая стадия тоже
удерживает захваты первого значения. Эти проекции сохраняются в `.iface`.
Чтобы явно назвать границу, используйте `a^c -> (b -> b)^c`.

Для локальных значений захваты выводятся автоматически. Замыкание без
ожидаемого типа получает квалификатор по используемым значениям; локальная
сигнатура не обязана перечислять регионы, которые удерживает функция.
Квалификаторы её следующих стадий — границы в записанном виде:
`wrap : forall a. a -> (Unit ->{} Unit)` позволяет возвращаемому замыканию
удерживать только `a`, поэтому для ресурса области её надо назвать
(`scope s { … }`) и написать `(Unit ->{} Unit)^{a, s}`.
Сигнатура верхнего уровня проверяется в записанном виде, а `.iface`
сохраняет её квалификаторы для модулей, которые её импортируют.

| Конструкция | Что удерживает |
| - | - |
| `fun`, `task` | используемые локальные значения |
| стадия каррированной функции | захваты ранее переданных значений и используемых локальных значений |
| запись, кортеж, список, конструктор | захваты составляющих значений |
| переменная типа `a^c` | всё значение удерживает не более `c`, без стирания конкретных регионов и хранимых квалификаторов |
| переменная типа `a` без квалификатора | захваты подставленного типа; каррированные стадии удерживают их проекцию |
| `Errors e`, `Exit e a`, `Failure e` | то, что удерживают ошибки `e`; переменная строки ошибок `e` удерживается как переменная типа: каррированные стадии сохраняют её, а в остальных позициях её ограничивает `(Errors e)^c` |
| `Eff r e a`, функция | скрытые захваты из квалификатора и то, что показывает тип результата (и тип параметра функции): отброшенный результат не уносит захват |

Функция, которая принимает другую функцию, указывает её захваты в сигнатуре
и сохраняет их в возвращаемом значении. Пример — `map_effect`:

```flick
map_effect : forall c a b r e. (a ->{r; e} b)^c -> (List a ->{r; e} List b)^c
foreign sync map_effect from "./list.js" "mapEffect"
  retention call
```

Колбэки Prelude `map`, `map2` и `flat_map` квантифицируют границу захватов
входа **для каждого вызова**, независимо от границы контейнера `d`:
`(forall v. a^v -> b)^c` у `map`,
`(forall u v. a^u -> (b^v -> x)^(c + u))^c` у `map2` и
`(forall v. a^v -> (m b)^(c + v))^c` у `flat_map`.
Вторая стадия `map2` удерживает первый аргумент. Это важно для `StateT` и
`ReaderT`: состояние или окружение при запуске могут удерживать регионы,
которых не было при построении вычисления.
`pure : forall c a. a^c -> (f a)^c` тоже сохраняет границу входного значения.
См. [пользовательские экземпляры трансформеров](../../contributing/implementation-decisions/#экземпляры-пользовательских-типов).

Конструкторы сохраняют захваты полей. Сопоставление с образцом и проекция
записи, кортежа или списка передают границу целого извлечённым значениям,
включая поля-замыкания; вызов отложенного поля учитывает и захваты переданного
аргумента. Явные квалификаторы полей сохраняются, а не заменяются границей
целого. Примитивные поля, например `Float`, захватов не приобретают.

## Что не может покинуть область

| Как регион может выйти из области | Правило |
| - | - |
| результат области, напрямую или внутри данных | его тип не может упоминать регион (`FLICK-G002`) |
| возвращаемое или сохраняемое замыкание либо `task` | его квалификатор не может удерживать регион (`FLICK-G002` или `FLICK-G001` при проверке по записанному типу) |
| значение, полученное приобретением | `Resource.acquire_release` даёт `a^{s}`, значение региона `s` (`FLICK-G002`); функция, которой его передают, принимает `Conn^c` с некоторым `c` |
| номинальная или непрозрачная обёртка | видимый регион или скрытый захват поля нельзя стереть |
| ячейка или связывание вне области | в его типе не должно появиться упоминание региона; изменяемое хранилище и квалифицированные типы его элементов инвариантны (`FLICK-T003`), даже если границу значения иначе можно было бы расширить |
| ошибка | данные ошибки не удерживают регион, даже если её перехватывает обработчик внутри области (`FLICK-E005`); `type error E (s : Region) = E (File s)` отклоняется при объявлении |
| внешняя функция | её сигнатура задаёт условия удержания: захваты, которые она сохраняет, указаны в квалификаторе результата; при `retention owner` удерживаемой строке захватов нужно `Fiber.Outlives` (`FLICK-F002`) |

## Аренда

`ScopedRef`, `Resource` и `ScopedCache` владеют собственными ресурсами:
замена (`set`, `refresh`) или вытеснение освобождает ресурс, пока их регион
ещё открыт. Поэтому их значение доступно только в аренде: `use` вызывает
функцию с ним, а прежний ресурс освобождается, когда его больше не держит
ни один `use`.

```flick
# import ScopedRef exposing (ScopedRef)
#
use : forall c s r e a b. ScopedRef s a -> (forall t. a^{t} ->{r; e} b)^c ->{r; e} b
# let use = ScopedRef.use

from_acquire :
  forall c s r e a. (forall t. Eff {Scope t | r} e a^{t})^c ->{Scope s | r; e} ScopedRef s a
# let from_acquire = ScopedRef.from_acquire
```

Значение удерживает регион аренды `t`, поэтому функция не может ни вернуть
его, ни сохранить (`FLICK-T007`, `FLICK-G002`). Приобретение идёт в
собственный регион `t`, который заканчивается с освобождением ресурса:
значение типа, называющего свой регион, например `File t`, в них хранить
нельзя. `RcRef`, `RcMap` и `Pool` одалживают значение области вызова
(`Scope t`) до её закрытия, поэтому их `get` даёт `a^{t}`.

## Дочерние файберы

```flick
spawn :
  forall s c r e a.
  (Fiber.Outlives c s, Fiber.Provided r s, Detached r) =>
  Fiber.Owner s ->
  (Failure e ->{Scope s | r; none} Unit)^c ->
  (Eff {Scope s | r} e a)^c ->{r; none} Fiber.Fiber e a
# let spawn owner supervisor child = Fiber.spawn owner supervisor child
```

`Fiber.spawn owner supervisor task` регистрирует `task` у `owner`;
супервизор наблюдает за сбоем задачи. Время жизни дочернего файбера
ограничено областью владельца. Поэтому задача и супервизор могут удерживать
только регионы, которые живут не меньше этой области: регион владельца,
регионы окружающих областей и регионы, указанные в сигнатуре, если
владелец — локальная область. Это условие выражает `Fiber.Outlives c s`.
Компилятор разрешает ограничение; программа не может объявлять экземпляры
этого класса. Если дочерний файбер удерживает регион с меньшим временем
жизни, возникает `FLICK-G003`. Дочерний файбер исполняется с сервисами
того места, где его запустили, поэтому и они должны пережить владельца:
`Fiber.Provided r s` (см. [Эффекты](../effects/), «Сервисы»).

Дочерний файбер приобретает ресурсы в регион владельца: задача, которая
приобретает, называет `Scope s` своего владельца, а задача с другим регионом
даёт `FLICK-T008`. Так же `Fiber.Outlives` требует работа, удерживаемая до
закрытия владельца: финализатор (`Scope.add_finalizer`), освобождение у
`Resource.acquire_release`, обработчик событий (`Events.listen`), источник
фонового `Stream` или `Channel`.

## Пока не проверяется

| Конструкция | Сейчас |
| - | - |
| условия удержания внешних функций | сигнатуры пишутся и проверяются вручную; модуль проверки требует `retention`, а для удерживаемого при `retention owner` — `Fiber.Outlives`, но не исследует внешние тела |
| переменная региона, поздно унифицированная с другим регионом в строке захватов | регионы остаются раздельными, из-за чего допустимая программа может быть отклонена |
