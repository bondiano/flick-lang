title: "Регионы и захваты"
---

`scope` освобождает полученные ресурсы, когда его тело завершается.
Проверка регионов не позволяет сохранить доступ к этим ресурсам после
закрытия области владения (см. [Ресурсы](../../spec/07-errors-and-concurrency/#ресурсы),
[Статические регионы и захваты](../../spec/07-errors-and-concurrency/#статические-регионы-и-захваты)).
Она выполняется после проверки типов и эффектов. Досрочного закрытия
и линейности нет: ресурс можно использовать сколько угодно раз,
пока его область владения открыта.

## Области и владельцы

```flick
read_config : Path ->{FileSystem; OpenError, ReadError} String
let read_config path =
  scope {
    let file = File.open_scoped path
    File.read_all file
  }
```

Каждый `scope { … }` создаёт новый регион с жёстким типом и владельца
получаемых внутри ресурсов. Тип региона нельзя упоминать в типах за
пределами этой области. Операции, которая получает ресурс региона `s`,
нужен сервис `Scope s` из `Prelude`. Каждый `scope` предоставляет `Scope`
только для своего региона, как `provide` предоставляет сервис.
Если регион вызова не определяется другими условиями, ресурс принадлежит
ближайшей области `scope`. Функция может возложить владение ресурсом
на вызывающий код: для этого требование указывается в сигнатуре:

```flick
open_two : forall s. Path ->{FileSystem, Scope s; OpenError} (File s, File s)
let open_two path =
  (File.open_scoped path, File.open_scoped path)
```

`scope s { … }` вводит имя региона `s` для типов внутри тела и значение
владельца `s : Fiber.Owner s`. Конструкция `scope` эффектная:
чистая функция не может открыть такую область (`FLICK-E001`).
Если вызову нужен `Scope s`, но он находится вне всех областей владения
и этого требования нет в сигнатуре, возникает `FLICK-G004`.

Если вызову нужен `Scope s` внешнего региона, ресурс получает владелец
этого региона, несмотря на внутренние области. Ресурс освободится при
закрытии области владельца. Компилятор передаёт владельца лексически:
выбор не зависит от того, какая область оказалась самой внутренней
во время выполнения вызова.

```flick
keep : forall s. Path ->{FileSystem, Scope s; OpenError} File s
let keep path =
  acquire : Unit ->{FileSystem, Scope s; OpenError} File s
  let acquire () = File.open_scoped path
  scope {
    let local = File.open_scoped path
    acquire ()
  }
```

В этом примере `local` освобождается по завершении внутреннего `scope`,
а файл, который возвращает `keep`, — при закрытии области вызывающего кода.

## Захваты

Регион ресурса виден в его типе: `File s`, `List (File s)` или
номинальная обёртка `Wrapper s`. Но замыкание или `task` может удерживать
значения вместе с их регионами, не показывая эти регионы в основном типе.
Такие скрытые захваты указываются в квалификаторе:

| Тип | Что удерживает |
| - | - |
| `T^{s, t}` | не более чем регионы `s` и `t` сверх тех, что видны в `T` |
| `T^c` | не более чем захваты из строки `c` с киндом `CaptureRow` |
| `T^(c + d)` | не более чем захваты из объединения обеих строк |
| `T` | ничего сверх того, что видно в `T` |

```flick
read_later : forall s. File s -> (Eff none {ReadError} String)^{s}
let read_later file =
  task { File.read_all file }
```

Квалификатор задаёт верхнюю границу захватов. Он может быть шире того,
что значение действительно удерживает. Более узкий квалификатор вызывает
`FLICK-G001`. Само упоминание `s` в типе параметра не заставляет функцию
удерживать `s`, но использование значения этого региона — заставляет.
Регион, уже видимый в типе, не требует квалификатора:
`fun () -> file` имеет тип `Unit -> File s`.

Каждая стадия каррированной функции удерживает ранее переданные параметры;
это относится и к частичному применению. Сигнатура выражает такие захваты
без явного квалификатора: `File s -> String -> String` означает
`File s -> (String -> String)^{s}`, в том числе в `.iface`.
Так учитываются только регионы и строки захватов. Из переменной типа
неизвестно, что удерживает её значение, поэтому для стадии, которая скрывает
такое значение, нужна запись `a^c -> (b -> b)^c`.

Для локальных значений захваты выводятся автоматически. Замыкание без
ожидаемого типа получает квалификатор по используемым значениям; локальная
сигнатура не обязана перечислять регионы, которые удерживает функция.
Сигнатура верхнего уровня проверяется в записанном виде, а `.iface`
сохраняет её квалификаторы для модулей, которые её импортируют.

| Конструкция | Что удерживает |
| - | - |
| `fun`, `task` | используемые локальные значения |
| стадия каррированной функции | регионы ранее переданных параметров и используемые локальные значения |
| запись, кортеж, список, конструктор | захваты составляющих значений |
| `T^c` для переменной типа `a^c` | не более чем захваты из `c`, что бы ни обозначало `a` |
| переменная типа `a` без квалификатора | захваты, определяемые самим `a`; обобщённому коду, который скрывает такое значение в замыкании, нужно `a^c` |
| `Eff r e a`, функция | только захваты из собственного квалификатора |

Функция, которая принимает другую функцию, указывает её захваты в сигнатуре
и сохраняет их в возвращаемом значении. Пример — `map_effect`:

```flick
map_effect : forall c a b r e. (a ->{r; e} b)^c -> (List a ->{r; e} List b)^c
foreign sync map_effect from "./list.js" "mapEffect"
```

При сопоставлении с образцом части значения сохраняют собственные типы.
Поля конструктора проверяются по этим типам при создании значения.

## Что не может покинуть область

| Как регион может выйти из области | Правило |
| - | - |
| результат области, напрямую или внутри данных | его тип не может упоминать регион (`FLICK-G002`) |
| возвращаемое или сохраняемое замыкание либо `task` | его квалификатор не может удерживать регион (`FLICK-G002` или `FLICK-G001` при проверке по записанному типу) |
| номинальная или непрозрачная обёртка | регион остаётся среди её аргументов типа |
| ячейка или связывание вне области | в его типе не должно появиться упоминание региона; изменяемое хранилище сохраняет свои захваты в точности (`T003`) |
| ошибка | данные ошибки не удерживают регион, даже если её перехватывает обработчик внутри области (`FLICK-E005`); `type error E (s : Region) = E (File s)` отклоняется при объявлении |
| внешняя функция | её сигнатура задаёт условия удержания: захваты, которые она сохраняет, указаны в квалификаторе результата |

## Дочерние файберы

```flick
spawn :
  forall s c r e a.
  Fiber.Outlives c s =>
  Fiber.Owner s ->
  (Failure e ->{r; none} Unit)^c ->
  (Eff r e a)^c ->{r; none} Fiber.Fiber e a
```

`Fiber.spawn owner supervisor task` регистрирует `task` у `owner`;
супервизор наблюдает за сбоем задачи. Время жизни дочернего файбера
ограничено областью владельца. Поэтому задача и супервизор могут удерживать
только регионы, которые живут не меньше этой области: регион владельца,
регионы окружающих областей и регионы, указанные в сигнатуре, если
владелец — локальная область. Это условие выражает `Fiber.Outlives c s`.
Компилятор разрешает ограничение; программа не может объявлять экземпляры
этого класса. Если дочерний файбер удерживает регион с меньшим временем
жизни, возникает `FLICK-G003`.

## Пока не проверяется

| Конструкция | Сейчас |
| - | - |
| полиморфные по захватам сигнатуры стандартной библиотеки | записываются вручную в каждом модуле, пока библиотека не существует |
| переменная региона, поздно унифицированная с другим регионом в строке захватов | регионы остаются раздельными, из-за чего допустимая программа может быть отклонена |
