Плагин, загруженный по HTTP во время офлайн-запуска, `--offline` или с установленным `CI`,
и ни один снимок не содержит ответа. Онлайн-запуск сохраняет каждый ответ в
`.flick/plugin-snapshots/<package>/`, который проект коммитит, чтобы CI
и офлайн-сборки использовали одинаковые ответы; редактор тоже работает офлайн.

Запустите `flick check` один раз в онлайн-режиме и закоммитьте созданные снимки.
Снимок обновляется удалением.
