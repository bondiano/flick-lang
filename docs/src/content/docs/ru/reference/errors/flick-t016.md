Объединение двух типов потребовало бы тип, который содержит сам себя, например `a = List a`.
Обычно это означает, что функция применяется к самой себе или аргумент обернут
на один раз слишком много.

```flick ignore
wrap : a -> List a
let wrap value = [value]
```
