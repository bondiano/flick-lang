Inline-модуль доступен только внутри исходного файла. Его `exposing`
открывает выбранные имена родителю, но не создаёт импортируемый путь.
Используйте `Child.member` внутри родительского файла. Для импорта из другого
файла вынесите блок в отдельный `A/Child.fl` с заголовком модуля; приватные
зависимости родителя тогда нужно перенести или передать явно.
