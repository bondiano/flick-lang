Плагин запросил доступ к чему-то вне своих блоков, к чему проект не
позволяет ему обращаться: файл, переменную окружения или хост по HTTP.
Только проект, который собирается, предоставляет это в своём собственном `flick.toml`
для плагина каждого пакета; зависимость не может предоставить себе что-либо сама.

```toml
[plugins.sql]
fs-read = ["schema/", "db/extra.sql"]   # paths from the project's root
net = ["db.example.com", "localhost:8080"]  # a host at any port, or at one
env = ["SQL_TOKEN"]
```

В сообщении указана строка, которую нужно добавить. Блок собственного модуля библиотеки
ничего не открывает.
