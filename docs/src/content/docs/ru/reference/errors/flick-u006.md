React может повторно отрисовать представление в любой момент, а реестр вычисляет производный атом всякий раз, когда изменяется атом, который он читает. Атом, действие или представление, созданные там, являются новыми при каждой отрисовке: состояние начинается заново, подписчики его теряют, действие забывает задачу, которую выполняет, а заново созданное представление — это новый компонент, поддерево которого React монтирует снова. Отрисовкой считается любая функция, чьи сервисы — только `Atom.Read`: отрисовка `Ui.view`, вычисление `Atom.derived` или функция с такой сигнатурой; задача обработчика в ней запускается по событию и может создавать всё необходимое. Функция, которая создаёт такой элемент, в модуле или в импортируемом модуле, также создаёт его в отрисовке, независимо от того, вызывает ли её отрисовка напрямую или передаёт дальше.

Создавайте каждый элемент один раз с верхнеуровневым `let` и по одному на ключ с `Atom.family`:  
`Atom.at family key` возвращает тот же атом для равного ключа, что требует `Hash`, поэтому он не содержит функцию. Передавайте различия между элементами в действие как данные с помощью `Action.with`.

```flick ignore
drafts : Atom.Family Float (Atom.Writable String)
let drafts = Atom.family (fun _ -> Atom.make "")

note_view : Ui.View Float
let note_view = Ui.view (fun id -> ui { Ui.field { bind = Atom.at drafts id; placeholder = ""; on_input = None } })
```
