Внешний модуль библиотеки записывается в выходной файл сборки рядом с модулем, который его связывает, вместе с другими `.mjs` и `.cjs` библиотеки, и одно из условий не может быть выполнено: отсутствует файл с именем, указанным в `foreign`, ссылка ведёт за пределы библиотеки, или две библиотеки содержат разные файлы по одному и тому же пути. Поместите файл рядом с модулем и именуйте общие файлы через каталог самой библиотеки.

```flick ignore
foreign pad from "./pad.mjs" "pad"
```
