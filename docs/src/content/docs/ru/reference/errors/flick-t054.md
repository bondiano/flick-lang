Функция, написанная внутри другой функции и не использующая локальные переменные внешней функции, не обязательно должна находиться внутри неё: как функция верхнего уровня она создаётся один раз, может иметь сигнатуру и тест, а внешняя функция остаётся короткой.

```flick
double : Float -> Float
let double x = x * 2

total : List Float -> Float
let total xs = List.sum (List.map double xs)
```

`let rec` воркер и однострочный помощник не отображаются.
