Переменная `let mut` принадлежит объявившей её функции: `fun`, локальная функция, `task`, ленивый `for`, блок `do` или ветвь обработчика операций внутри неё могут выполниться позже, несколько раз или параллельно, поэтому не могут ни читать эту переменную, ни присваивать ей. Так функция остаётся чистой снаружи. Свяжите текущее значение через `let` и используйте это имя или верните новое значение из внутренней функции.

```flick
module App.Shift exposing (shifted)

shifted : List Int -> List Int
let shifted xs =
  let mut offset = 1
  offset = offset * 10
  let by = offset
  List.map (fun x -> x + by) xs
```
