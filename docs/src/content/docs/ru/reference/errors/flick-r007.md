title: "FLICK-R007"
source_hash: "7380f25596f36714"

Прозрачный алиас разворачивается в своё определение, поэтому алиас, который ссылается на самого себя напрямую или через другие алиасы, никогда не заканчивается. Рекурсия требует номинального типа: ADT или `opaque type`.

```flick
type Tree a = Node a (List (Tree a))
```
