---
title: "FLICK-F014"
source_hash: "163d495d7e84b39a"
---

Требование пакета к версии ABI значений в секции `[package] abi` (или
`[package.abi]`) файла `flick.toml` либо версия ABI в запросе внешней привязки
не совпадает с версионированной таблицей ABI значений, опубликованной выбранным
бэкендом.

Обновите требование к версии в `[package.abi]` в соответствии с активным
бэкендом, выберите совместимую версию бэкенда или ограничьте пакет конкретного
бэкенда с помощью `[package] when`:

```toml
[package]
name = "my-ffi"
version = "0.1.0"
when = "js"

[package.abi]
"flick.javascript-ffi" = "^0.1.0"
```
