Два пакета зависимостей проекта указывают один и тот же целевой пакет с разными версиями в `[target.<name>.dependencies]`, или один из них отличается от целевого манифеста проекта (например, `package.json`). Проект устанавливает одну копию целевого пакета, поэтому требования должны совпадать дословно: измените манифест проекта или используйте версии пакетов, которые согласованы.

```toml
[target.js.dependencies]
left-pad = "^1.3.0"
```
