Устарело. Компилятор проверял блоки `cli "name" { … }` самостоятельно и
сообщал об этом коде; теперь эти блоки являются плагином `cli` для `std`,
который сообщает то же правило, что и `std/L002`: см. `flick explain std/L002`.

Код остается зарегистрированным для исторической диагностики и никогда не используется повторно.
