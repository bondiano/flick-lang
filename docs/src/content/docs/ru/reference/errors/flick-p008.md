Команда требует проект, но в рабочем каталоге или любом родительском каталоге отсутствует `flick.toml`, либо `--project` указывает на отсутствующий каталог или файл.  
Запустите команду внутри проекта, выберите проект с помощью `--project` или укажите файлы напрямую.

```sh
flick check --project path/to/app
```
