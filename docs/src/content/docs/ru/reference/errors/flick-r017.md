Приватный модуль можно импортировать только из исходников и тестов его пакета.
Это правило действует и для зависимости, скомпилированной из исходников или
восстановленной из кэша. Импортируйте публичный фасад, который реэкспортирует
нужные имена, либо сделайте модуль публичным в пакете-владельце.
