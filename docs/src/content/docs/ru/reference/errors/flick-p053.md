Два контрибьютора, например бэкенд проекта и плагин, добавляют команду с одним и тем же именем, поэтому плоское имя не указывает ни на одну из них. Назовите нужную вместе с её контрибьютором, как их перечисляет сообщение:

```sh
flick literal:greet world
```
