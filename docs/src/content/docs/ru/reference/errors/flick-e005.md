title: "FLICK-E005"
source_hash: "0d11b784887c3b8c"
---

Полезная нагрузка ошибки — это данные, которые живут дольше кода, вызвавшего ошибку: она не может содержать ячейку (`Ref`), вычисление (`Eff`), слой, функцию времени выполнения, `Unknown`, которая могла бы скрыть это, или значение из региона, такого как локальный `File s`, даже если обработчик внутри области перехватывает ошибку. Вместо живого значения передавайте путь, идентификатор или копию данных.

```flick ignore
// was: type error ReadFailed = ReadFailed (Ref String)
type error ReadFailed = ReadFailed String
```
