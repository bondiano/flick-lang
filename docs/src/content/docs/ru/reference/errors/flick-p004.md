Не удалось записать отформатированный текст обратно в исходный файл `flick fmt`: файл доступен только для чтения, каталог недоступен для записи или диск заполнен. Файл сохраняет прежнее содержимое.

```sh
chmod u+w src/App/Main.fl && flick fmt src/App/Main.fl
```
