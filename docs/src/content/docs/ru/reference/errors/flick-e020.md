Выбранное окружение сборки должно давать корневой обработчик каждому
ограниченному эффекту, который всё ещё требуется достижимой программе.
У браузерных профилей нет корневого обработчика для сервисов только базы
данных или сервера, таких как `Db`, `Database` или `Server`, поэтому
достижимое использование — `unhandled effect … on js/browser` на месте
требования. Та же программа может собраться на `js/node`, когда у этого
окружения есть обработчик. Неиспользуемый неподдерживаемый код не ломает
проверку только по достижимости; публичные экспорты библиотеки проверяются
по политике экспорта. Отсутствие инструментов остаётся `FLICK-P015` /
`FLICK-P029`, а не этим кодом.

```flick
// flick.toml: [build] environment = "js/browser"
module App.Main exposing (run)

service Db =
  query : String ->{} String

run : String ->{} String
let run key =
  provide Db ({ query = fun value -> value }) {
    Db.query key
  }
```
