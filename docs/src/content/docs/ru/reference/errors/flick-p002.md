`flick fmt --check` обнаружен файл, текст которого отличается от его отформатированной версии.
Выделенный участок указывает на первую строку, которая будет изменена. Запустите форматировщик, чтобы исправить это:

```sh
flick fmt src/App/Main.fl
```
