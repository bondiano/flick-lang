Сигнатура описывает определение, расположенное непосредственно под ней. Сигнатура без определения или с определением в другом месте является ошибкой; сервисы, классы и объявления `foreign` — это места, где сигнатура стоит отдельно или над `foreign`.

```flick ignore
now : Unit ->{} Float
foreign now from global "Date.now"
```
