title: "FLICK-T080"
source_hash: "9087601b1cd545ca"
---

`proof` утверждает, что две стороны равны при любых значениях параметров. Здесь checker вычислил обе стороны и получил разные значения: разные конструкторы или разные литералы; или `same_type` сравнивает два разных конструктора типов. Утверждение ложно, и никакое доказательство его не закроет. Проверьте, что утверждение говорит то, что вы имели в виду.

```flick fail T080
proof always_some (x : Bool)
where equal (Some x) None =
  refl
```

это

```flick
proof always_some (x : Bool)
where equal (Some x) (Some x) =
  refl
```
