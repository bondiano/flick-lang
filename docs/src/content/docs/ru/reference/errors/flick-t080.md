---
title: "FLICK-T080"
source_hash: "0467b98ff68faf8e"
---

`proof` без посылок утверждает, что две стороны равны при любых значениях параметров. Здесь проверка нашла входные данные, на которых стороны различаются, или утверждение `same_type` сравнивает разные типы. Проверьте формулировку утверждения.

Для равенства, которое вводит шаг вроде `trans`, используется отдельная диагностика FLICK-T090. Такое равенство может оказаться ложным, даже если исходное утверждение верно.

```flick fail T080
proof always_some (x : Bool)
where equal (Some x) None =
  refl
```

это

```flick
proof always_some (x : Bool)
where equal (Some x) (Some x) =
  refl
```
