# Одна ячейка типа для каждого типа

Значение типа, помеченного `@cell`, держит одно значение: это состояние,
которое создаёт чистый вызов, например атом. Привязка, построенная чисто,
обобщается, поэтому ячейка, созданная без типа перед глазами, получила бы тип
с переменными: одна ячейка, которую один читатель принимает за список чисел,
а другой — за список строк, и каждый читает то, что записал другой. Поэтому
у значения, которое не является функцией, внутри типа ячейки нет переменных:
аннотируйте его типом того, что оно держит. В блоке ячейка без типа не
обобщается, а сигнатура, аннотация или аргумент высшего ранга, которые дают
ей переменные, отвергаются так же. Функция, создающая ячейку при каждом
вызове, может оставаться полиморфной.

```flick
@cell
type Slot a

empty : Unit -> Slot a
foreign pure empty from "./slot.js" "empty"

numbers : Slot Float
let numbers = empty ()
```

Плагин библиотеки формулирует этот отказ для своих ячеек: для атома это
`FLICK-U005`.
