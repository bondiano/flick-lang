title: "FLICK-T064"
source_hash: "6eb11d3a11173133"
---

Каждый `unpack` открывает нового свидетеля для абстрактного типа упакованного модуля. Значение, тип которого содержит этого свидетеля, не может покинуть область `unpack` как обычный тип. Верните значение, не зависящее от абстрактного типа, либо объявите результат как `exists K : Sig. K.T` и сохраните его свидетеля.
