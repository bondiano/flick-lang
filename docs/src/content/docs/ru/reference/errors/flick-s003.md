Исходный код содержит символ, который не начинает никакой токен Flick, например `#`, `~`,
`!` самостоятельно или не-ASCII букву вне строки или комментария. Имена состоят из
ASCII букв, цифр и `_`.

```flick ignore
// error: `user#name`
let user_name = "Ada"
```
