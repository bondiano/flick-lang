title: "FLICK-S005"

Строковый литерал содержит недопустимую escape-последовательность или неправильно оформленную многострочную строку.  
Escape-последовательности — это `\n \t \r \\ \" \0` и `\u{…}` с 1–6 шестнадцатеричными цифрами, обозначающими Unicode-скалярное значение (без суррогатных пар). `\0` не может быть за ним цифра. Многострочная строка начинается с `"""`, за которым следует перенос строки. Необработанные строки `r"…"` и `r#"…"#` не содержат escape-последовательностей.

```flick ignore
let path = r"C:\temp"
let smile = "\u{1F600}"
```
