Задача, которую выполняет `spawn`, `parallel` или `race_first`, находится в отдельном фибере. Обработчик эффекта с операцией `control` или `abort` находится в фибере, который его установил, и обе операции раскручивают или приостанавливают кадры до этого обработчика: дочерняя задача не может к нему обратиться. Обрабатывайте такой эффект внутри задачи или собирайте результаты дочерних задач с помощью `join` или `Channel`.

Работа, которую удерживает регион, требует того же: финализатор, освобождение ресурса, слушатель. Она выполняется при закрытии области видимости, когда обработчик мог уже отпустить тело. Ни `control`, ни `abort` не могут раскрутить стек до сохранённого обработчика, поэтому в удерживаемой работе допускаются только операции `tail`.

Инициализатор `lazy` устроен проще: он выполняется синхронно в том фибере, который его форсирует, поэтому операция `abort` может раскрутиться к обработчику в форсирующем фибере, тогда как операция `control` всё равно не может его разорвать. Поэтому `lazy` требует `NoControl r`, а не `Detached r` (и всякое `Detached r` влечёт `NoControl r`).

```flick
effect Emit a =
  control emit : a ->{} Unit

collect : forall a r e. (Unit ->{Emit a | r; e} Unit) ->{r; e} List a
let collect body =
  try
    body ()
  with
  | Emit.emit x -> [x] ++ resume ()
  | return () -> []

both : Unit ->{} (List Int, List Int)
let both () =
  // was: collect (fun () -> parallel (task { Emit.emit 1 }) (task { Emit.emit 2 }))
  parallel (task { collect (fun () -> Emit.emit 1) }) (task { collect (fun () -> Emit.emit 2) })
```

Функция, которая запускает или удерживает обособленную работу с сервисами переменной строки, указывает `Detached r` в своей сигнатуре; функция, которая лишь строит инициализатор `lazy`, указывает `NoControl r`.
