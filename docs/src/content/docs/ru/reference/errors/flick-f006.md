`flick ffi check` повторно импортирует пакет, так как заголовок сгенерированного модуля это фиксирует, и сравнивает результат с файлом: обновление зависимости изменило объявления, `policy.toml` изменился, или кто-то отредактировал сгенерированный файл. Запустите импорт снова; проверенные привязки живут в других модулях и не затрагиваются.

```text
flick ffi import lookup-lib --out src/Ffi
flick ffi check
```
