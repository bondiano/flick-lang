Параметр, переменная шаблона или локальная `let` связаны, но никогда не используются. Используйте их или начните их имя с `_`, чтобы указать, что они намеренно не используются; исправление предупреждения делает именно это.

```flick ignore
module App.Pairs exposing (first)

first : (a, b) -> a
let first (x, y) = x
```

Напишите `(x, _y)` или `(x, _)`. Поле шаблона записи без `=` связывает имя поля, поэтому исправление записывает `{ name = _name }`.
