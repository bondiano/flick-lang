Программа на Flick, запущенная шагом плана `run-flick` (например, `flick schema export`)
или командой `flick doc --check-examples`, завершилась с ошибкой во время выполнения,
превысила таймаут в 60 секунд, превысила лимит размера stdout либо не смогла
запуститься на выбранном бэкенде.

Изучите вывод среды выполнения в сообщении диагностики и исправьте падающий код
в подсвеченном диапазоне. Если пример в документации намеренно показывает ошибку,
а не должен выполняться, пометьте его блок кода как `fail` или `ignore`.

```sh
flick doc --out-dir api --check-examples
```
