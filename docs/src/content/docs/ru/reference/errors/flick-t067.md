# Публичному функтору нужна явная сигнатура результата

Объявите контракт результата: `module App.Make(K : Contracts.Input) : Contracts.Output`.
В нём можно указать зависимости от типов аргумента. Локальный функтор может
выводить результат; экспортируемый псевдоним наследует явную сигнатуру.
