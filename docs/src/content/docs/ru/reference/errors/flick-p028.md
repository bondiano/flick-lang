Сборка записывает свой выходной каталог, а `flick clean` удаляет его, поэтому выходной каталог не может быть корнем проекта, каталогом его исходников или тестов, или каталогом выше одного из них: сборка заменила бы `package.json` своим собственным, а `clean` удалил бы файлы проекта. При отказе в сборке ничего не записывается.

```toml
[build]
out-dir = "dist"
# was: out-dir = ".", the project's root
```
