`echo e` выводит `e` с указанием модуля и строки, на которой он находится, и возвращает его без изменений; `x |> echo` делает то же самое в конвейере. Это предназначено для отладки и не отображается в эффектах функции, поэтому предупреждение предотвращает его забывание.

```flick ignore
module App.Totals exposing (total)

total : List Float -> Float
let total xs = echo (Float.sum_all xs)
```

Исправление предупреждения удаляет `echo`. `flick pack` отклоняет пакет, в котором остался `echo`.
