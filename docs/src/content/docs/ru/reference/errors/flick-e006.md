Выполнение операции сервиса или эффекта подразумевает поиск соответствующего обработчика, поэтому операция является функцией времени выполнения: по крайней мере одна стрелка в её сигнатуре — `->{…}`.
Чистая вспомогательная функция должна находиться в модуле, а не в сервисе или эффекте.

```flick ignore
service Clock =
  // was: now : Float
  now : Unit ->{} Float
```
