# Недопустимое управление циклом

`break` и `continue` требуют окружающего `loop`, `while` или `for … do`
в той же функции (и совпадающей метки, если указана `'label`).
Метки циклов должны быть уникальны в пределах одной функции, и только `loop`
принимает значение в `break value`. Функция, задача, ленивая
последовательность или обработчик операции не передают управление в окружающий
цикл.
