title: "FLICK-D007"
source_hash: "d8b4b6cf8cbd8650"
---

Устарело. Компилятор проверял блоки `codec` самостоятельно. Теперь блок `codec` является плагином `codec` для `std`, который сообщает об этом как о `std/D007`.

Код остается зарегистрированным для исторической диагностики и никогда не используется повторно.
