Блоки ограничиваются отступами, и Flick использует для отступов только пробелы. Строка должна начинаться в том же столбце, что и блок, в котором она продолжает оператор (новый оператор) или глубже (продолжение). Столбец между двумя вложенными блоками не принадлежит ни одному из них; использование табуляции делает столбцы неоднозначными. Тело после `=` или `->`, расположенное на следующей строке, должно иметь отступ.

```flick ignore
let load_name id =
  let user = Users.get id
  user.name
```
