Сравнение с литералом слева, `0 == n`, читается в обратном порядке.  
Быстрое исправление ставит сравниваемое значение первым и превращает `<` в `>` и так далее,  
чтобы сравнение имело тот же смысл.

```flick
empty : Float -> Bool
let empty n = n == 0
```
