---
title: "FLICK-T010"
source_hash: "1f8b442fa619e4de"
---

Рука никогда не может выполниться: руки выше неё уже соответствуют каждому значению, которому соответствует она сама.  
Удалите её или переместите выше руки, которая её покрывает.

```flick fail T010
sign : Float -> String
let sign n =
  match n with
  | _ -> "other"
  | 0 -> "zero"
```
