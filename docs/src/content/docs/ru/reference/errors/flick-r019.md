Именованное статическое применение функтора создаёт путь модуля, который могут
импортировать другие файлы. Inline-модуль — приватное пространство имён внутри
одного файла, поэтому объявлять применение функтора в его теле нельзя.
Разместите применение в модуле-файле, а при необходимости импортируйте его
результат внутри inline-блока. Значения, типы, классы, экземпляры, сервисы и
контракты `type module` можно объявлять непосредственно в inline-модуле.
