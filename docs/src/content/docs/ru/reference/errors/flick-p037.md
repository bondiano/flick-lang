Устарело. Блоку плагина `std`, например `cli "name" { … }`, требовался импорт его заголовка, `import Cli exposing (plugin cli)`. Заголовки плагина `std` теперь начинают блок в каждом модуле, где его нет.

Код остается зарегистрированным для исторической диагностики и никогда не используется повторно.
