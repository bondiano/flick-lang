Модуль программы помечает объявление атрибутом `@lang` или `@ts`. Lang items — это то, на что полагается компилятор, например, `Option` для `?` или `flat_map` для `do`, и только встроенные модули их объявляют; `@ts` даёт встроенному типу его форму в TypeScript. Удалите этот атрибут: собственным типам и функциям программы он не нужен.

```flick
module App.Ids exposing (UserId)

type UserId = UserId Int
```
