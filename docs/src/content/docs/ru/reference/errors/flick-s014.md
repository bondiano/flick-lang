---
title: "FLICK-S014"
source_hash: "ebef42296cc6fc07"
---

Атрибут неизвестен, имеет неверные аргументы или расположен не на своём месте.
Допустимые атрибуты: `@lang`, `@derive`, `@maker` и `@implicit`.
`@lang` называет один lang item компилятора; `@derive` может назвать пакет
плагина; `@maker` не принимает аргументов; `@implicit` не принимает аргументов
и допустим только перед объявлением экземпляра класса.

```flick fail S014
@inline
double : Float -> Float
let double x = x * 2
```

Сообщается о неправильно написанном элементе, таком как `@lang integer`, или о неизвестном атрибуте, таком как `@inline`.
