---
title: "FLICK-F012"
source_hash: "617332b87649e290"
---

Два или более переопределения `@native` на одной и той же функции верхнего
уровня подходят под активное окружение, и ни одно из их условий `when` не
влечёт другое в известном словаре тегов окружения.

Когда под активное окружение подходят несколько строк `@native`, Flick выбирает
наиболее конкретную: ту, чьё условие `when` влечёт каждое другое подходящее
условие (например, `bun` влечёт `js`, а `js && rt` влечёт `js`). Если два
подходящих условия несравнимы или логически эквивалентны, Flick не угадывает и
указывает обе строки.

Сделайте одно условие строго более конкретным, чем другое, или разведите их
так, чтобы они не пересекались:

```flick
# import Float
#
hypot : Float -> Float -> Float
let hypot a b = Float.sqrt (a * a + b * b)
  @native "Math.hypot" when js && !bun
  @native "Bun.hypot" when bun
```
