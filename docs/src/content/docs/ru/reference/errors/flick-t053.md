source_hash: "27925f9cbec0906d"

Две строковые константы, объединённые с помощью `++` в одной строке, считаются одной константой. Быстрое исправление объединяет их. Константы, расположенные на отдельных строках и содержащие длинный текст, не вызывают предупреждений.

```flick
greeting : String
let greeting = "Hello, world"
```
