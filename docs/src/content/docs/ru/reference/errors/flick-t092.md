Доказательство прошло проверку, но посылка не используется ни в теле, ни в цели, ни в последующих посылках. Чтобы включить предупреждение, укажите `unused-proof-premises = true` в разделе `[lint]` файла `flick.toml`. Имя, которое начинается с `_`, обозначает намеренно неиспользуемую посылку. Список параметров входит в формулировку утверждения.

```flick
proof holds_anyway (h : holds true) where holds true = refl
```
