`name = value` присваивает переменной `let mut` той функции, в которой стоит. Имя, связанное обычным `let`, параметр, переменная шаблона, определение модуля или импорт присвоить нельзя. Объявите переменную через `let mut` (исправление добавляет `mut` там, где такое объявление допустимо) или свяжите новое имя через `let`.

Непосредственно в блоке `do` и в секции условий `for` объявлять `let mut` нельзя.
Для этих объявлений автоматическая вставка не предлагается; используйте обычное тело функции или цикла.

```flick
module App.Count exposing (next)

next : Int -> Int
let next n =
  let mut count = n
  count = count + 1
  count
```
