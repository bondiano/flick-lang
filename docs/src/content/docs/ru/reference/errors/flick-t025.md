`let assert` предназначен для шаблона, который может завершиться неудачей: он связывает значение, если оно совпадает, и останавливает программу, если не совпадает. Шаблон, который совпадает с любым значением, не может завершиться неудачей, поэтому `assert` ничего не говорит: используйте простой `let`.

```flick ignore
module App.Pairs exposing (sum)

sum : (Float, Float) -> Float
let sum pair =
  let (a, b) = pair
  a + b
```
