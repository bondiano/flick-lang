title: "FLICK-P054"
source_hash: "f0728f47e6dcf6ad"
---

Бэкенд или плагин объявляет команду, имя которой совпадает с командой самого `flick`, например `build`. Контрибьютор не может заменить команду ядра: объявление игнорируется, а команда ядра работает как прежде. Авторам следует переименовать команду.
