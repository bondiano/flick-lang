title: "FLICK-F013"
source_hash: "d2d7dcb5ed06f876"
---

Прямое объявление `foreign` или переопределение `@native` использует тип
параметра, результата или функции обратного вызова, которого нет в
версионированной таблице ABI значений активного бэкенда (либо он использован в
направлении, не разрешённом таблицей), и этот тип не является непрозрачным
дескриптором.

Каждый бэкенд публикует в своём дескрипторе таблицу ABI значений, сопоставляющую
lang items и структурные конструкторы типов (`tuple`, `function`) с типами
хоста, преобразованиями на границе (`none`, `copy`, `view`) и допустимыми
направлениями (`in`, `out`, `both`). Записи и пользовательские ADT не имеют
стабильной раскладки и в таблицы ABI значений не входят.

Передавайте значения типов, допущенных таблицей ABI значений бэкенда, оберните
неподдерживаемое значение в непрозрачный номинальный дескриптор `type` или
напишите явный адаптер:

```flick
type Handle

use_handle : Handle -> Int ->{} Unit
foreign use_handle from "./native.js" "useHandle"
  arity 2
```
