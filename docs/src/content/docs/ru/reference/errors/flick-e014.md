Операция `abort` никогда не возвращает управление: ветвь её обработчика завершает обработчик.
Поэтому её результат — это переменная типа, которую операция квантифицирует и которую
ничто другое в её типе не называет, и вызов подходит везде, где требуется значение.

```flick
effect Throw =
  // was: abort throw : String ->{} Unit
  abort throw : forall b. String ->{} b
```
