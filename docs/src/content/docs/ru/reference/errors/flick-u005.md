Атом содержит одно значение. Привязка, построенная чисто, обобщается, поэтому
`let items = Atom.make []` будет иметь тип
`forall a. Atom.Writable (List a)`: одно состояние, которое один читатель воспринимает как
список чисел, а другой — как список строк, каждый читая то, что
написал другой. Значение верхнего уровня, которое содержит атом (или их семейство),
следовательно, имеет тип без переменных внутри типа атома: аннотируйте его
типом его значения. В блоке атом без типа не обобщается, и сигнатура, аннотация или аргумент более высокого ранга, которые
дают ему переменные, отклоняются аналогичным образом. Функция, создающая атом при каждом вызове,
может оставаться полиморфной.

```flick
items : Atom.Writable (List Float)
let items = Atom.make []

make_list : Unit -> Atom.Writable (List a)
let make_list () = Atom.make []
```
