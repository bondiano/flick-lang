Устарело. Компилятор проверял запросы `sql { … }` самостоятельно и сообщал об этом коде; теперь запросы являются плагином `sql` для `std`, который сообщает то же правило, что и `std/Q002`: см. `flick explain std/Q002`.

Код остается зарегистрированным для исторической диагностики и никогда не используется повторно.
