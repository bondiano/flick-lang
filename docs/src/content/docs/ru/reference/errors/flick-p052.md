У `flick` нет команды ядра с таким именем, и ни бэкенд проекта, ни плагины его зависимостей её не добавляют. Вне проекта работают только команды ядра: добавленной команде нужен проект, чей бэкенд или зависимость её добавляет. Если такую команду добавляет официальный бэкенд или бэкенд либо плагин, уже известный хранилищу, сообщение называет его.

`flick --help` перечисляет команды ядра, а в проекте — и команды, которые добавляет каждый контрибьютор.
