---
title: "FLICK-D005"
source_hash: "d0cc89eb6160707f"
---

Устарело. Компилятор проверял блоки `codec` самостоятельно. Теперь блок `codec` является плагином `codec` для `std`, который сообщает об этом как о `std/D005`.

Код остается зарегистрированным для исторической диагностики и никогда не используется повторно.
