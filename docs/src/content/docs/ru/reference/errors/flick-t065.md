`instance Eq Key from equality` называет значение контракта модуля, которое предоставляет словарь. Объявите `equality : Eq.Dict Key` в том же контракте `type module`. Значение другого типа или имя, не объявленное контрактом, не может предоставить этот локальный экземпляр. Требование не создаёт глобальный экземпляр.
