У каждой функции верхнего уровня полная сигнатура указана прямо над её `let`, также функция, полученная частичным применением; рекурсивная локальная функция тоже имеет сигнатуру. Другая локальная функция может её опустить, а метод экземпляра использует сигнатуру своего класса. Сигнатура указывает тип каждого аргумента, результат и эффект каждого стрелочного типа; тело проверяется на соответствие ей.

```flick
greet : String -> String -> String
let greet prefix name =
  prefix ++ ", " ++ name

hello : String -> String
let hello = greet "Hello"
```
