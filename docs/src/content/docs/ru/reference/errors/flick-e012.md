Устарело. Компилятор проверял `server fn` самостоятельно и отклонял его при сборке без функции Cargo `server-stdlib`. Теперь `server fn` является плагином `server` для `std`, который есть в каждой сборке.

Код остается зарегистрированным для исторической диагностики и больше не используется.
