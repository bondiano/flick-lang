title: "FLICK-P066"
source_hash: "0e9f60bf6dfa64eb"

Условие среды в `@when`, `[package] when` или `[host] requires` упоминает тег,
который не объявлен ни в одном известном дескрипторе бэкенда и ни в одном
загруженном пакете `[host]`.

Теги среды проверяются по общему словарю, чтобы опечатки сразу приводили к
ошибке в месте условия, а не молча вычислялись как ложь. Проверьте написание
тега по тегам и осям бэкенда или добавьте пакет-хост, который объявляет этот
тег:

```flick
@when "js && !browser"
module App.Server exposing (start)

let start = ()
```
