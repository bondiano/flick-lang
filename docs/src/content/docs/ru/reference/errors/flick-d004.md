source_hash: "6dee83d890b0da37"

Устарело. Компилятор проверял блоки `codec` самостоятельно. Теперь блок `codec` является плагином `codec` для `std`, который сообщает об этом как о `std/D004`.

Код остается зарегистрированным для исторической диагностики и никогда не используется повторно.
