# Дети вызова записаны списком

Внутри блока, который собирает детей, например `ui { … }`, функция, чей
последний параметр — список детей, получает этот список поэлементно: каждый
ребёнок — аргумент вызова, на его строке в скобках или на отдельной строке
под ним, а вызов без детей получает пустой список. Литерал списка на этом
месте был бы одним ребёнком, который сам список.

```flick
view : Ui
let view = ui {
  div { class_name = "counter" }
    heading (text "count")
    paragraph
      text "one line"
      text "for each child"
    div { class_name = "spacer" }
}
```

`flick check --fix --only T073` переписывает каждый список, записанный
по-старому. Один аргумент, который уже список — значение или вызов вроде
`List.map row items`, — и есть список детей; среди детей, записанных по
одному, `Ui.each items row` даёт узел на каждый элемент.
