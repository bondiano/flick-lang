Достижимое использование из точки входа программы или публичных экспортов
библиотеки зависит от модуля, пакета или внешней привязки, чьё условие среды
не выполняется в выбранной среде.

Неиспользуемые импорты и недостижимые функции разрешены, чтобы модули для
разных сред могли разделять типы и сигнатуры. Диагностика указывает на место
использования и показывает путь от точки входа или публичного экспорта.

Либо переключите `[build] environment` (или настройки `[target.<backend>]`) на
среду, теги которой удовлетворяют условию, добавьте нужную зависимость
(например, `@flick-lang/effect-ts` для привязок адаптера Effect на JS `rt`),
либо вынесите код конкретной среды в модуль с подходящим условием:

```flick
@when "js && browser"
module App.Browser exposing (mount)

let mount = ()
```
