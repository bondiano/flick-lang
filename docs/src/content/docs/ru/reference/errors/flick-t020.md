`unboxed type` и `untagged type` обозначают, как значения вариативного типа представлены в JS для кода, который взаимодействует с ними через FFI. Несфокусированный тип имеет один конструктор с одним полем, и это поле является значением. Нетегированный тип — это одно поле каждого из его конструкторов, которые JS должен различать по типу: `Float`, `String`, `Bool`, `BigInt`, либо по списку или кортежу; ни два конструктора не могут иметь одинаковое представление.

```flick ignore
unboxed type UserId = UserId String

untagged type Key = ByNumber Float | ByName String
```

Перечисление (enum) — это нетегированный тип, конструкторы которого являются литералами, все строки или все `Int`, и каждый отличается; конструкторы не имеют полей, а тип не имеет параметров. Литерал появляется после `=` и только в `нетегированном типе`.

```flick ignore
untagged type Method = Get = "GET" | Post = "POST"
```
