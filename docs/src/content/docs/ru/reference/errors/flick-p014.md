Больше не сообщается: проект компилирует библиотеки Flick, от которых зависит, из их исходников и не читает скомпилированные модули других пакетов. Код остаётся зарезервированным.

`.iface` пакета фиксирует отпечаток каждой интерфейса, против которого был скомпилирован его модуль. Если установленная интерфейсная зависимость имеет другой отпечаток, тип, идентификатор конструктора, словарь или сводку, на которые опирается скомпилированный код, могли измениться, поэтому пакет не может быть использован с ней.

Установите версии, с которыми пакет был собран, или релиз пакета, собранный против установленной зависимости:

```sh
flick install
```
