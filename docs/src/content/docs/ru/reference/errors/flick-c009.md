---
title: "FLICK-C009"
source_hash: "15e56b5b40cb24ec"
---

Разрешение экземпляра имеет ограничение по определению: по умолчанию 100 000 шагов и 256 вложенных ограничений. Превышение этого лимита является ошибкой, а не успехом; сообщение показывает цепочку ограничений. Упростите типы или увеличьте лимиты в `flick.toml`.

```toml
[build]
solver-steps = 200000
solver-depth = 512
```
