Плагин, чей пакет указан как `hooks = ["emit"]`, изменил файл `.js` из `flick build`, но оставил его исходную карту `.js.map` такой, какой её создала сборка, либо удалил её. Карта будет указывать позиции кода на неправильные строки исходника, или скрипт потеряет её, поэтому сборка сохраняет файлы как есть и сообщает о плагине.

Плагин, который изменяет код скрипта, должен также предоставить его карту: сдвинуть сопоставления на величину вставленного кода или создать новую карту.
