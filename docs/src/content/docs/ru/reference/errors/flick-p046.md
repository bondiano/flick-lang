Плагин, чей пакет указан как `hooks = ["emit"]`, изменил выходной файл `flick build`, но оставил его исходную карту (файл `.map`) такой, какой её создала сборка, либо удалил её. Карта будет указывать позиции кода на неправильные строки исходника, или выходной файл потеряет её, поэтому сборка сохраняет файлы как есть и сообщает о плагине.

Плагин, который изменяет выходной код с исходной картой, должен также предоставить обновлённую карту: сдвинуть сопоставления на величину вставленного кода или создать новую карту.
