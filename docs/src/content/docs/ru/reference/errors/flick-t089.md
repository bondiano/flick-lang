title: "FLICK-T089"
source_hash: "4dbda4b810a4095e"

`Int` — это 32-битное знаковое целое (`-2147483648..=2147483647`), арифметика
которого во время выполнения переполняется по модулю. Чтобы рассуждения в
математических целых оставались корректными, `flick prove` проверяет, что
каждое `+`, `-` и унарное `-`, вычисляемое в теле функции с контрактом,
остаётся в пределах `-2147483648..=2147483647` при условиях пути. Добавьте
`require` или проверку ветвления, исключающую переполнение.

```flick fail T089
next : Int -> Int
let next x
where
  ensure (fun y -> y > x)
=
  x + 1
```

это

```flick
next : Int -> Int
let next x
where
  require (x < 2147483647)
  ensure (fun y -> y > x)
=
  x + 1
```
