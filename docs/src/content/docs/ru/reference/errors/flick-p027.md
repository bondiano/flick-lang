Больше не сообщается: проект компилирует библиотеки Flick, от которых зависит, из их исходников и не читает скомпилированные модули других пакетов. Код остаётся зарезервированным.

Библиотека, собранная с `[build] effect = "none"`, имеет Option и Result как простые данные, которые `==` на Effect не сравнивает с собственными Effect: приложение на Effect не может её импортировать. Соберите библиотеку на Effect: тогда она также записывает, под `_core/`, модули, которым Effect не нужен, которые приложение с `effect = "none"` импортирует.

```toml
# flick.toml of the library
[build]
effect = "effect"
```
