Форматировщик сгенерировал вывод, который не разбирается в ту же программу, что и исходный код, поэтому он отказался его записывать. Это ошибка в Flick: пожалуйста, сообщите о ней вместе с файлом. Исходный файл остается без изменений; пока ошибка не исправлена, пропускайте форматирование этого файла:

```sh
flick fmt --check src/App/Main.fl
```
