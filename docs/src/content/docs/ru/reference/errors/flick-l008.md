Устарело. Компилятор проверял блоки `cli "name" { … }` самостоятельно и отклонял их при сборке без функции Cargo `server-stdlib`. Теперь эти блоки являются плагином `cli` для `std`, который присутствует в каждой сборке.

Код сохраняется для исторической диагностики и больше не используется.
