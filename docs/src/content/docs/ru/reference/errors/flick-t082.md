`proof` относится к чистому тотальному домену `PureTotalV1`: каждое значение, которое он называет, вычисляется завершающейся программой без эффектов. Здесь утверждение или доказательство называет что-то вне домена: тип с эффектами, рекурсивный тип, примитивную операцию или определение, которое checker не допускает. Сама программа не ошибочна; не проверяется только это доказательство.

```flick fail T082
proof sum (x : Int)
where equal (x + 0) x =
  refl
```

это

```flick
proof same (x : Int)
where equal x x =
  refl
```
