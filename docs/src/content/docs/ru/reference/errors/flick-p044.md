Импорт раскрывает заголовок плагина `std`, который есть в каждом модуле без импорта, из плагина другого пакета:

```flick ignore
module App.Main exposing (..)

import Queries exposing (plugin sql)
```

Заголовки плагина `std`, `cli`, `server`, `codec` и `sql` начинают блок в каждом модуле, поэтому блок одного из них всегда принадлежит `std`.
Другой плагин присваивает своим блокам другие заголовки.

Удалите заголовок из импорта или переименуйте его в плагине, который его предоставляет.
