Имя ссылается более чем на одну сущность: два импорта предоставляют его по имени, два импорта `exposing (..)` оба предоставляют используемое имя, или два импорта используют один и тот же квалификатор. Повторный экспорт той же сущности не является неоднозначным. Уточните имя или импортируйте его по имени из одного модуля.

```flick ignore
import App.Users as Users exposing (..)
import App.Orders as Orders exposing (..)

let first = Users.find
```
