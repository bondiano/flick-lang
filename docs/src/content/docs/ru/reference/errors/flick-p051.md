Бэкенд или плагин попросил компилятор запустить инструмент хоста, который проект не разрешает. Инструменты хоста запускаются только с согласия проекта: `[tools]` в `flick.toml` перечисляет для каждого id бэкенда или пакета плагина инструменты, которые могут запускать его шаги сборки и команды.

```toml
[tools]
"flick/go" = ["go"]
```

Компилятор находит каждый разрешённый инструмент в `PATH` и закрепляет его хеш и версию на время сборки. Инструменту, которым бэкенд только запускает программу, например `node` для `flick run`, запись не нужна.
