# Статический параметрический модуль нельзя упаковать в runtime-модуль

`Module Sig`, `pack` и `unpack` передают структуры во время выполнения.
Параметрический модуль строит модули статически, в том числе когда он вложен в структуру.
Сначала примените параметрический модуль, затем упакуйте структуру с runtime-контрактом.
