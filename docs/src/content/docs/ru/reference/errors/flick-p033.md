title: "FLICK-P033"
source_hash: "550047843d34d6cb"

Требование `[package] flick` зависимости не включает эту версию компилятора: библиотека была написана для другой версии языка. Используйте релиз библиотеки, созданный для этого компилятора, или компилятор, включённый в её требования.

```toml
[package]
name = "geo"
version = "1.4.0"
flick = ">=0.1, <0.2"
```
