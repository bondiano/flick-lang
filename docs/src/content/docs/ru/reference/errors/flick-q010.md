Устарело. Компилятор проверял запросы `sql { … }` самостоятельно и сообщал об этом коде; теперь запросы являются плагином `sql` для `std`, который сообщает то же правило, что и `std/Q010`: см. `flick explain std/Q010`.

Код остается зарегистрированным для исторической диагностики и никогда не используется повторно.
