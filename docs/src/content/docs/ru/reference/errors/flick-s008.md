title: "FLICK-S008"
source_hash: "3d92c7b3c696abfb"
---

Открывающий `(`, `[` или `{` не имеет соответствующего закрывающего разделителя. Связанный диапазон указывает на открывающий элемент. Закрывающие разделители могут быть с отступом, но должны идти перед следующим объявлением.

```flick
# first : Float
# let first = 1.0
# second : Float
# let second = 2.0
let pair =
  (first,
   second)
```
