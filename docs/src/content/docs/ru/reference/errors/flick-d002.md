title: "FLICK-D002"
source_hash: "a0f0fac32f2b4495"

Устарело. Компилятор проверял блоки `codec` самостоятельно. Теперь блок `codec` является плагином `codec` для `std`, который сообщает об этом как о `std/D002`.

Код остается зарегистрированным для исторической диагностики и никогда не используется повторно.
