title: "FLICK-C005"
source_hash: "20c61782ed22a258"
---

Покрытие: каждая переменная типа в определённой части функциональной зависимости должна следовать из определяющей части заголовка экземпляра. Проверяющий начинает с этих переменных и многократно применяет функциональные зависимости из контекста экземпляра и его инстанцированных суперклассов. Правило применяется только тогда, когда все его определяющие переменные покрыты.

```flick
# type Set a = Set (List a)
class Collection c a | c -> a =
  empty : c

// not `instance Collection (Set a) b`
instance Collection (Set a) a =
  empty : Set a
  let empty = Set []
```

Покрытие с помощью контекста позволяет поднять capability через обёртку:

```flick
# type ReaderT r m a = ReaderT (r -> m a)
class State m s | m -> s =
  get : m s

instance State m s => State (ReaderT r m) s =
  let get = ReaderT (fun _ -> get)
```

Здесь заголовок определяет `m`, а `m -> s` из контекста определяет `s`. Несвязанные ограничения, обратные зависимости и неинициализированные циклы не покрывают переменную. Алиасы разворачиваются перед этой проверкой.

Покрытие не выбирает экземпляр: это делает только его заголовок. Конфликты перекрытия и функциональных зависимостей остаются ошибками, а контексты всё ещё должны удовлетворять структурным ограничениям `FLICK-C007`. Разрешение также ограничено существующими пределами шагов и глубины (`FLICK-C009`).
