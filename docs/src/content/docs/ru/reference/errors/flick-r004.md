title: "FLICK-R004"
source_hash: "6f66674d19166760"
---

Модуль не экспортирует имя, ни в списке `exposing` импорта, ни в квалифицированном имени `M.name`. Модуль экспортирует только те имена, которые указаны в собственном списке `exposing`. Экспортируйте имя из модуля или используйте экспортируемое имя.

```flick ignore
module App.Users exposing (User, load_user)
```
