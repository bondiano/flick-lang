Объявление `foreign` привязывает функцию JS к сигнатуре Flick (§8).
Сигнатура — контракт; режим задаёт способ выполнения вызова, а строки
метаданных под объявлением адаптируют вызов.

```flick
hypot : Number -> Number -> Number
foreign pure hypot from global "Math.hypot"
  arity 2

now_millis : Unit ->{} Number
foreign sync now_millis from global "Date.now"
  arity 0

read_text : Path ->{; FsError} String
foreign async read_text from "./fs.js" "readText"
  arity 1
  catch FsError.from_js
  cancel signal
```

## Режимы

| Режим | Вызов |
| - | - |
| `pure` | прямой вызов JS: считается чистым на доверии, в том числе при загрузке модуля |
| `sync` | выполняется при выполнении стадии среды выполнения; исключение — дефект |
| `async` | промис создаётся при выполнении вызова, а не при построении `task`; отклонение промиса — дефект, а самый внутренний владелец ждёт завершения промиса даже после прерывания |
| `effect` | фабрика JS вызывается при выполнении вызова (`Effect.suspend`), и её `Effect` выполняется в текущем файбере |

## Метаданные

| Метаданные | Значение |
| - | - |
| `arity n` | `n` позиционных аргументов JS с адаптацией `n` стадий; `arity 0` принимает `()` первого параметра типа `Unit` и вызывает JS без аргументов, предварительно вычислив этот аргумент |
| `this` | первый аргумент — получатель: `target.call(a0, a1, …)` |
| `catch f` | исключение или отклонение промиса становится типизированной ошибкой `f value`, где `f : JsValue -> E`, а `E` входит в строку ошибок; `E` не может содержать возможности области (`FLICK-F003`) |
| `cancel signal` | только для `foreign async`: последним передаётся `AbortSignal`, который отменяется при прерывании; владелец по-прежнему ждёт промис |
| `nullable` | результат — `Option a`: `null` и `undefined` становятся `None` |
| `optional i` | аргумент `i` (начиная с 0) имеет тип `Option a`: `None` передаётся как `undefined` |
| `variadic` | последний аргумент — `List a`, разворачиваемый в аргументы вызова |
| `retention call` / `retention owner` | как долго JS сохраняет аргумент, который может содержать возможности области: не дольше вызова либо до закрытия владельца региона |
| `reviewed "<pkg>@<ver> sha256:…"` | привязка проверена по этому объявлению экспорта пакета; `flick ffi check` сравнивает его с установленным |

Строка метаданных, не соответствующая сигнатуре или режиму, даёт `FLICK-F001`.
Результат типа `Unit` — `()` независимо от того, что возвращает JS. Параметру,
тип которого может содержать возможности области — регион, как в `File s`,
или квалификатор захватов `^c`, — нужна строка `retention` (`FLICK-F002`):
без неё компилятор не может знать, как долго JS его сохраняет. Тип функции
обратного вызова без квалификатора вообще не содержит захватов, поэтому замыкание
над значением области отклоняется в месте передачи (`FLICK-G001`).

## Функции обратного вызова

Функция Flick, передаваемая в JS, адаптируется к арности JS, определяемой её типом:
`(a -> b -> c)` поступает как `(a, b) => c`. Адаптируется только аргумент самой
привязки: функция внутри записи, списка или `Option` поступает каррированной,
как она представлена во Flick. Есть четыре семейства:

| Семейство | Что получает JS | Выполнение |
| - | - | - |
| чистые | `(a, b) => c` | напрямую при каждом вызове |
| Effect | `(a) => Effect<b, E, R>` для функции обратного вызова среды выполнения | когда принимающий код Effect запускает её, в своём файбере и окружении |
| Promise | `Js.promise_callback f`: `(a) => Promise<b>` | как дочерняя задача области, в которой она создана, с сервисами этой области; вызовы после начала закрытия области отклоняются, а область ждёт выполняющиеся вызовы |
| события области | `Events.listen owner policy supervisor handler` | каждый вызов ставит событие в очередь; один обработчик очереди, дочерняя задача `owner`, выполняет обработку по одной задаче за раз |

`Events.attach listener add remove` регистрирует слушателя и, когда владелец
его региона начинает закрываться, немедленно игнорирует последующие события и
вызывает `remove` с той же функцией, которую получил `add`; затем обработчик
очереди завершается, а ресурсы освобождаются. Событие, пришедшее при полной очереди
(`Events.queue capacity`), отбрасывается и сообщается супервизору, как и
каждый сбой обработчика. Обработчик никогда не выполняется внутри вызова
источника событий.

## Значения JS

`JsValue` — любое значение JS в том виде, в котором его передаёт внешний код.
`Js.snapshot` копирует поддерживаемые данные — примитивы, простые объекты,
плотные массивы — в замороженное значение `Unknown` с глубиной не более 64 и
не более 100000 значений (`Js.snapshot_with` задаёт оба ограничения). Свойства читаются
через дескрипторы, поэтому геттер никогда не выполняется; геттер, функция, цикл,
объект с другим прототипом, пропуск в массиве, прокси, выбрасывающий исключение,
или значение за пределами ограничений дают `SnapshotError` с указанием пути.
Поддерево, используемое в двух местах, копируется один раз.

## Импорт `.d.ts` пакета

`flick ffi import <package> --out <dir>` читает объявления установленного
пакета с помощью TypeScript (через вспомогательный инструмент Node
`@flick-lang/dts-importer` или скрипт, указанный в `FLICK_DTS_IMPORTER`) и
записывает `<dir>/<Pkg>/Generated.fl`, модуль `<Dir>.<Pkg>.Generated`
(`date-fns` → `DateFns`), с отчётом по каждому выбранному экспорту.
`--select a,b` импортирует только эти экспорты. Каждый экспорт получает один статус:

| Статус | Что генерируется |
| - | - |
| поддерживается | привязка `foreign` с `/// <pkg>@<ver> sha256:…` над ней |
| нужна политика | `foreign blocked name "needs policy: …"`: `.d.ts` не может выразить контракт |
| не поддерживается | `foreign blocked name "unsupported: …"`: вне поддерживаемого подмножества |

Использование значения `foreign blocked` даёт `FLICK-F005`; остальные экспорты
пакета остаются доступными, а запрос заблокированного экспорта через `--select`
тоже является ошибкой. Ничего, что нельзя увидеть в объявлении, не выводится:
вызов — `sync` (`Unit ->{} Number` для `nextId(): number`), но никогда не `pure`.

| TypeScript | Flick |
| - | - |
| `string`, `number`, `boolean`, `bigint` | `String`, `Number`, `Bool`, `BigInt` |
| результат `void`, `undefined` | `Unit` |
| `any`, `unknown` | `JsValue`; отклоняется при `strict = true` |
| `T[]`, `[A, B]` | `List T`, `(A, B)` |
| `x?: T`, `x: T \| undefined` | `Option T` с `optional i` |
| `...xs: T[]` | `List T` с `variadic` |
| `<T>` без ограничений | `forall t.`, если `T` встречается в параметре |
| экземпляр класса, `Date`, именованный объектный тип | непрозрачный `type` сгенерированного модуля |
| функция обратного вызова `(a: A) => B` | чистая `(A -> B)`; требуется `retention` |
| результат `Promise<T>` | `foreign async`; требуется `catch` |
| результат `T \| undefined` или `T \| null` | `Option T` с `nullable`; требуется `undefined = "none"` |
| перегрузки с разным количеством параметров | по одной привязке для каждой, `name_<n>` |

Объединения, литеральные типы, пересечения, параметры типов с ограничениями или
встречающиеся только в результате, параметры `this`, аргументы `null`, объектные
аргументы с неименованной структурой и возвращаемые функции не поддерживаются;
для каждого случая указывается причина. Завершающий необязательный параметр
такого типа опускается с примечанием.

Политики находятся в `<dir>/<Pkg>/policy.toml`, который импорт читает,
но никогда не записывает:

```toml
strict = false             # true: `any` and `unknown` are refused

[exports.lookup]
undefined = "none"         # an undefined or null result is None
catch = "JsError"          # a throw or rejection becomes JsError
cancel = "signal"          # an async call gets an AbortSignal
# mode = "pure"            # trust the call to be pure
# retention = "call"       # or "owner": how long JS keeps a callback
```

Для `export declare function lookup(id: string): Promise<string | undefined>`
эта политика даёт:

```flick
lookup : String ->{; JsError} Option String
foreign async lookup from "lookup-lib" "lookup"
  arity 1
  catch JsError.from_js
  nullable
```

`JsError.from_js` сохраняет то, что сообщает выброшенное значение, — `name: message`
для `Error`, — но никогда не само значение.

### Проверенные привязки и `ffi check`

Импорт записывает только `Generated.fl`. Привязка, проверенная вручную,
помещается в собственный модуль, обычно `<dir>/<Pkg>.fl`, реэкспортирующий остальные
имена, с `reviewed`, указывающим объявление, по которому она проверена, — строку,
которую сгенерированный модуль показывает над экспортом:

```flick
lookup : String ->{; JsError} Option String
foreign async lookup from "lookup-lib" "lookup"
  arity 1
  catch JsError.from_js
  nullable
  reviewed "lookup-lib@1.0.0 sha256:6fa1…"
```

`flick ffi check` (для корня исходного кода проекта или указанных путей) снова
импортирует каждый пакет и сообщает о сгенерированном модуле, отличающемся от
нового импорта (`FLICK-F006`), о проверенной привязке, чьё объявление изменилось
или исчезло либо у которой отсутствует необходимое для её формы — `catch` для Promise,
`nullable` для пустого результата, `retention` для функции обратного вызова (`FLICK-F007`), —
и о политике для экспорта, которого нет в пакете (`FLICK-F008`).
