title: "Внешние функции"
---

Объявление `foreign` связывает функцию JS с сигнатурой Flick
(см. [Генерация TypeScript и граница FFI](../../spec/08-typescript-and-ffi/)).
Сигнатура задаёт типы аргументов, результата, сервисов и ошибок.
Режим определяет, когда и как вызывается функция, а строки метаданных
описывают передачу аргументов и обработку результата.

```flick
hypot : Number -> Number -> Number
foreign pure hypot from global "Math.hypot"
  arity 2

now_millis : Unit ->{} Number
foreign sync now_millis from global "Date.now"
  arity 0

read_text : Path ->{; FsError} String
foreign async read_text from "./fs.js" "readText"
  arity 1
  catch FsError.from_js
  cancel signal
```

## Режимы

| Режим | Вызов |
| - | - |
| `pure` | прямой вызов JS; чистота принимается на доверии, вызов возможен в том числе при загрузке модуля |
| `sync` | JS вызывается на эффектной стадии функции; исключение считается дефектом |
| `async` | промис создаётся при выполнении вызова, а не при построении `task`; отклонение промиса считается дефектом; ближайший владелец ждёт завершения промиса даже после прерывания |
| `effect` | фабрика JS вызывается при выполнении вызова (`Effect.suspend`), а возвращённый ею `Effect` выполняется в текущем файбере |

## Метаданные

| Метаданные | Значение |
| - | - |
| `arity n` | адаптирует `n` стадий функции Flick к `n` позиционным аргументам JS; при `arity 0` первый аргумент `()` типа `Unit` вычисляется, но JS вызывается без аргументов |
| `this` | первый аргумент становится получателем вызова: `target.call(a0, a1, …)` |
| `catch f` | превращает исключение или отклонение промиса в типизированную ошибку `f value`, где `f : JsValue -> E`, а `E` входит в строку ошибок; `E` не может содержать значения, привязанные к области владения (`FLICK-F003`) |
| `cancel signal` | только для `foreign async`: последним аргументом передаётся `AbortSignal`, который отменяется при прерывании; владелец по-прежнему ждёт завершения промиса |
| `nullable` | результат имеет тип `Option a`: `null` и `undefined` превращаются в `None` |
| `optional i` | аргумент `i` (нумерация с 0) имеет тип `Option a`: `None` передаётся как `undefined` |
| `variadic` | последний аргумент типа `List a` разворачивается в аргументы вызова |
| `retention call` / `retention owner` | задаёт, как долго JS может хранить аргумент со значениями из области владения: до конца вызова или до закрытия владельца региона |
| `reviewed "<pkg>@<ver> sha256:…"` | указывает объявление экспорта пакета, по которому проверена привязка; `flick ffi check` сравнивает его с установленным объявлением |

Если метаданные не соответствуют сигнатуре или режиму, возникает `FLICK-F001`.
Результат типа `Unit` всегда равен `()`, что бы ни вернул JS.

Если тип параметра может содержать значения из области владения, нужна строка
`retention`; без неё возникает `FLICK-F002`. Это относится и к региону,
как в `File s`, и к квалификатору захватов `^c`. Без `retention` компилятор
не знает, как долго JS сохраняет аргумент.
Тип функции обратного вызова без квалификатора не допускает захватов.
Поэтому замыкание, которое удерживает значение из области владения,
отклоняется в месте передачи (`FLICK-G001`).

## Функции обратного вызова

Функция Flick, передаваемая в JS, адаптируется к арности, указанной её типом:
`(a -> b -> c)` передаётся как `(a, b) => c`. Это происходит только тогда,
когда функция — непосредственный аргумент внешней привязки.
Внутри записи, списка или `Option` функция остаётся каррированной,
как во Flick. Есть четыре семейства функций обратного вызова:

| Семейство | Что получает JS | Выполнение |
| - | - | - |
| чистые | `(a, b) => c` | напрямую при каждом вызове |
| Effect | `(a) => Effect<b, E, R>` для эффектной функции обратного вызова | принимающий код Effect запускает её в своём файбере со своими сервисами |
| Promise | `Js.promise_callback f`: `(a) => Promise<b>` | каждый вызов выполняется как дочерняя задача области создания с сервисами этой области; после начала закрытия области новые вызовы отклоняются, а область ждёт уже выполняющиеся |
| события области | `Events.listen owner policy supervisor handler` | каждый вызов ставит событие в очередь; события последовательно обрабатывает одна дочерняя задача `owner` |

`Events.attach listener add remove` регистрирует слушателя.
Когда владелец его региона начинает закрываться, слушатель сразу перестаёт
принимать события, а `remove` получает ту же функцию, которая была передана
в `add`. Затем завершается обработчик очереди и освобождаются ресурсы.
Если очередь `Events.queue capacity` заполнена, новое событие отбрасывается,
а супервизор получает сообщение об этом. Ему также передаётся каждый сбой
обработчика. Сам обработчик никогда не выполняется внутри вызова источника
событий.

## Значения JS

`JsValue` представляет любое значение JS в том виде, в котором его передал
внешний код. `Js.snapshot` копирует поддерживаемые данные — примитивы,
простые объекты и плотные массивы — в замороженное значение `Unknown`.
Глубина ограничена 64 уровнями, количество значений — 100000.
`Js.snapshot_with` позволяет задать оба ограничения.

Свойства читаются через дескрипторы, поэтому геттеры не выполняются.
Геттер, функция, цикл, объект с другим прототипом, пропуск в массиве,
прокси, выбрасывающий исключение, или превышение ограничения приводят
к `SnapshotError` с указанием пути.
Поддерево, используемое в двух местах, копируется один раз.

## Импорт `.d.ts` пакета

`flick ffi import <package> --out <dir>` читает объявления установленного
пакета с помощью TypeScript. Для этого используется вспомогательный инструмент
Node.js `@flick-lang/dts-importer` или скрипт из `FLICK_DTS_IMPORTER`.
Команда записывает `<dir>/<Pkg>/Generated.fl` с модулем `<Dir>.<Pkg>.Generated`
(`date-fns` → `DateFns`) и отчётом по каждому выбранному экспорту.
`--select a,b` ограничивает импорт перечисленными экспортами.
Каждому экспорту присваивается один из статусов:

| Статус | Что генерируется |
| - | - |
| поддерживается | привязка `foreign` с `/// <pkg>@<ver> sha256:…` над ней |
| нужна политика | `foreign blocked name "needs policy: …"`: нужны сведения, которых нет в `.d.ts` |
| не поддерживается | `foreign blocked name "unsupported: …"`: экспорт вне поддерживаемого подмножества |

Использование `foreign blocked` приводит к `FLICK-F005`.
Остальные экспорты пакета остаются доступными. Если заблокированный экспорт
явно запрошен через `--select`, импорт тоже завершается ошибкой.

Импортёр не выводит свойства, которых нет в объявлении.
Обычный вызов получает режим `sync` (`Unit ->{} Number` для
`nextId(): number`); чистота `pure` не выводится.

| TypeScript | Flick |
| - | - |
| `string`, `number`, `boolean`, `bigint` | `String`, `Number`, `Bool`, `BigInt` |
| результат `void`, `undefined` | `Unit` |
| `any`, `unknown` | `JsValue`; отклоняется при `strict = true` |
| `T[]`, `[A, B]` | `List T`, `(A, B)` |
| `x?: T`, `x: T \| undefined` | `Option T` с `optional i` |
| `...xs: T[]` | `List T` с `variadic` |
| `<T>` без ограничений | `forall t.`, если `T` встречается в параметре |
| экземпляр класса, `Date`, именованный объектный тип | непрозрачный `type` сгенерированного модуля |
| функция обратного вызова `(a: A) => B` | чистая `(A -> B)`; требуется `retention` |
| результат `Promise<T>` | `foreign async`; требуется `catch` |
| результат `T \| undefined` или `T \| null` | `Option T` с `nullable`; требуется `undefined = "none"` |
| перегрузки с разным количеством параметров | по одной привязке для каждой, `name_<n>` |

Не поддерживаются объединения, литеральные типы, пересечения, параметры
типов с ограничениями и параметры типов, встречающиеся только в результате,
параметры `this`, аргументы `null`, объектные аргументы с неименованной
структурой и возвращаемые функции. Для каждого случая указывается причина.
Завершающий необязательный параметр такого типа опускается с примечанием.

Политики задаются в `<dir>/<Pkg>/policy.toml`.
Команда импорта читает этот файл, но никогда не записывает его:

```toml
strict = false             # true: `any` and `unknown` are refused

[exports.lookup]
undefined = "none"         # an undefined or null result is None
catch = "JsError"          # a throw or rejection becomes JsError
cancel = "signal"          # an async call gets an AbortSignal
# mode = "pure"            # trust the call to be pure
# retention = "call"       # or "owner": how long JS keeps a callback
```

Для объявления `export declare function lookup(id: string): Promise<string | undefined>`
эта политика создаёт привязку:

```flick
lookup : String ->{; JsError} Option String
foreign async lookup from "lookup-lib" "lookup"
  arity 1
  catch JsError.from_js
  nullable
```

`JsError.from_js` сохраняет описание выброшенного значения
(для `Error` — `name: message`), но никогда не само значение.

### Проверенные привязки и `ffi check`

Команда импорта записывает только `Generated.fl`.
Проверенную вручную привязку нужно поместить в собственный модуль,
обычно `<dir>/<Pkg>.fl`, и реэкспортировать из него остальные имена.
В `reviewed` указывается объявление, по которому проверена привязка.
Нужная строка приведена над экспортом в сгенерированном модуле:

```flick
lookup : String ->{; JsError} Option String
foreign async lookup from "lookup-lib" "lookup"
  arity 1
  catch JsError.from_js
  nullable
  reviewed "lookup-lib@1.0.0 sha256:6fa1…"
```

`flick ffi check` проверяет корень исходного кода проекта или указанные пути.
Команда заново импортирует каждый пакет и сообщает об ошибках:

- Сгенерированный модуль отличается от нового импорта — `FLICK-F006`.
- У проверенной привязки изменилось или исчезло исходное объявление
  либо не хватает обязательных метаданных: `catch` для Promise,
  `nullable` для пустого результата, `retention` для функции обратного вызова —
  `FLICK-F007`.
- Политика ссылается на экспорт, которого нет в пакете, — `FLICK-F008`.
