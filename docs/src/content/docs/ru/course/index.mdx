Тур показывает, а в курсе вы решаете сами. В каждом уроке три упражнения:
вы правите или пишете код, а проверка компилирует его, смотрит на сигнатуру
экспортированной функции и сравнивает вывод. Подсказки открываются по одной;
в последнем уроке их нет. Прогресс хранится в этом браузере.

Если что-то незнакомо, загляните в [тур](../tour/): у большинства уроков есть
урок тура, который показывает то же самое.
