**Строки**, упражнение 3 из 3. Строки соединяются через `++` и принимают значения через `\{…}`; в этих упражнениях вы собираете и разбираете текст.

Напоминание есть в [уроке тура](../../tour/strings/).

Проверьте ответ кнопкой **Проверить** или сочетанием Ctrl+Enter в редакторе.
