Flick on the left. JavaScript on the right. Edit a source module to see the real compiler output, and switch between **Debug** and **Release** to inspect each build profile. This page compiles your code; it does not run it.

<Playground mode="transpile" locale="en" />

### Read the translation

Choose **Data and patterns** to inspect data constructors and pattern matching, or **Typed errors** to see runtime functions lowered to the Effect-based adapter. Diagnostics below the panes belong to the selected build profile; invalid code does not produce a substitute output.

The preview shows the JavaScript for your module, not a standalone bundle. Generated imports reference the Flick runtime and built-in modules. See [Code generation](/reference/codegen/) for the lowering contract and [Foreign functions](/reference/ffi/) for the JavaScript boundary.

Compilation happens in this browser using the WebAssembly compiler. The source editor, example selection, profile selection and diagnostic view are implemented in Flick itself.

To execute a program and inspect its output, switch to [Play](/play/).
