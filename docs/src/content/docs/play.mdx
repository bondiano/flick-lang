The real WebAssembly compiler checks every edit; a program runs in a worker of
its own and stops after 10 seconds. The JavaScript and `.d.ts` tabs show what the
compiler writes for the build profile you pick.

This is one module in a browser, not a Node.js project: no file system, database
or npm packages. For a local project, follow
[Getting started](../start/getting-started/). The playground itself is written in
Flick with the [`ui` DSL](../reference/ui/); TypeScript only connects it to the
browser, the compiler and the worker.
