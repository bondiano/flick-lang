A metadata line under a `foreign` declaration has a name that is neither a core
contract word nor an adapter word declared by the active package backend.

Core contract words (available on every backend): `arity`, `catch`, `retention`,
`nullable`, `optional`, `reviewed`, `owned`. Official backends additionally
declare adapter words in their descriptors (for example `this`, `cancel`,
`variadic` on `flick/js` and `flick/go`).

```flick ignore
read_text : Path ->{Async; FsError} String
foreign read_text from "./fs.js" "readText"
  arity 1
  catch FsError.from_js
  cancel signal
```
