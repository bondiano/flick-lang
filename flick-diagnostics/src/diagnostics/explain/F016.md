A `type` has `@native when <cond>` but no constructors.

`@native` on a type says where it is the backend's own type, whose values only
the backend's bindings make; elsewhere its constructors are its Flick
representation, which the Flick bodies of its functions build and match. A type
without constructors has no representation to fall back on: it is opaque
everywhere, and needs no `@native`.

Give the type the constructors its bodies use where the condition does not
hold, or drop the `@native`:

```flick
type Box a =
  | Box a
  @native when js || go
```
