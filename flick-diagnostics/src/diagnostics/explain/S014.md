An attribute is unknown, has invalid arguments, or is misplaced.
The core attributes are `@lang`, `@derive`, `@maker`, `@cell`, `@label`,
`@owner`, `@sync`, `@stores`, `@implicit`, `@when`, and `@export`; the active
backend may declare foreign type-form attributes (such as `@ts` on `flick/js`
or `@go` on `flick/go`), and active plugins may declare custom `@attributes`
(plain or namespaced as `@pkg.attr`) targeting declarations, variants, or
record fields via `PluginMetadata.attributes`. `@lang` names one compiler lang
item; `@derive` optionally names a plugin package; `@maker` takes no argument;
`@cell` takes no argument and belongs before a type declaration; `@label` names
one kind, as `@label atom`, and belongs before a type declaration; `@owner`
takes no argument and belongs before a service declaration; `@sync` takes
`reader` or nothing and belongs before a service declaration; `@ts` (declared
by `flick/js`) takes the TypeScript form of a type, as
`@ts "ReadonlyArray<{0}>"`, `none`, or `import` with a module and an export of
it, and belongs before the declaration of a type or a service, with one form
that can be written for the type; `@stores` takes no argument and belongs
before a type declaration without constructors or a body; `@implicit` takes no
argument and belongs only before an instance declaration; `@when` restricts a
module header to environments matching a tag condition; `@export` names a host
export before a top-level function.

```flick fail
@inline
double : Float -> Float
let double x = x * 2
```

A misspelled item, such as `@lang integer`, an unknown attribute, such as
`@inline` (or a type-form attribute belonging to another backend), or a
plugin-declared attribute placed on an unsupported target (such as a
record-field attribute placed on a declaration) is reported.
