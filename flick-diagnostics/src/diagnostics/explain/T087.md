Every `ensure` clause of a function's contract must hold for the result on
every path through the body, given the function's `require` clauses. When
`flick prove` finds an input that satisfies `require` while leaving `ensure`
false, it reports this error together with a counterexample.

```flick fail T087
consume : Int -> Int -> Int
let consume available used
where
  require (0 <= used && used <= available)
  ensure (fun remaining -> 0 <= remaining && remaining + used == available)
=
  available
```

is

```flick
consume : Int -> Int -> Int
let consume available used
where
  require (0 <= used && used <= available)
  ensure (fun remaining -> 0 <= remaining && remaining + used == available)
=
  available - used
```
