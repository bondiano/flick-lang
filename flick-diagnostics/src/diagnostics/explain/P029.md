`target = "go"` builds the program with the official Go backend: it writes
a Go module per entry under `go/<entry>/` in the output directory and asks
the host to run `go build` on it. The host has no `go` to give it: either
`go` is not on `PATH`, or the project does not allow the backend to run it.

Install Go (1.23 or later) and make sure `go version` works in the shell that
runs `flick`. Allow the tool in `flick.toml`, or with `--allow-tool go` when
building a file outside a project. A failure of `go build` itself is
`FLICK-P050`, with the end of its output.

```toml
[tools]
"flick/go" = ["go"]
```
