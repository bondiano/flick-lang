`flick new` or `flick init` asked for a template that the selected backend or
`--from` package does not provide, or omitted `--template` when the contributor
provides no default template.

The diagnostic lists the templates the contributor provides. Pass one of those
names with `--template`, select another `--target`, or load a third-party
template package with `--from`.

```sh
flick new my-app --target go --template app
```
