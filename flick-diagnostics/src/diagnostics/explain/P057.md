This CLI flag, `[build]` configuration key, or top-level backend table (such as
`[js]` and `[js.dependencies]`) belonged to a single backend and was removed
when backend-specific configuration moved out of the core CLI. There are no
compatibility aliases; replace it with `--target <name>` and the selected
backend's own options or `[target.<name>]` / `[target.<name>.dependencies]`
tables.

```toml
[build]
target = "js"

[target.js]
typescript = true
declarations = true
runtime = "rt"

[target.js.dependencies]
left-pad = "^1.3.0"
```
