The command line or `[target.<name>]` in `flick.toml` passed an option that
the selected backend does not declare for this command, gave a value of the
wrong type or outside the declared `choices`, or omitted a required option.

Run `flick <command> --target <name> --help` to see the options the selected
backend declares for that command, and check the spelling and types in
`[target.<name>]`.

```sh
flick build --target js --help
flick build --target go --help
```
