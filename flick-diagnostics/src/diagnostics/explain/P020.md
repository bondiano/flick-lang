`flick pack` checks that a package's release outputs are complete before
writing target artifacts: every emitted `.iface` must be readable and agree
with the fingerprints of dependency interfaces emitted beside it, and the
selected backend's optional `pack` command checks its own requirements (for
example, on `flick/js`, matching `.iface` and `.d.ts` companions, a valid
`package.json` whose `exports` exist, and `[target.js] typescript = false`
for npm packages).

```sh
flick build --profile release --declarations
flick pack --out-dir artifacts
```
